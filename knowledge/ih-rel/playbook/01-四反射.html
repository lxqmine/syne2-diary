四个动作

秒级，不用写下来，但每次都要过：

1. 分账

花精力之前问：这笔进哪本账？

答案只有两个，选不出来就说明这事不该做。

2. 复合

相处/交付之后问：能做的事变多了吗？

变多 = 有效；没变 = 保养（可以，但按成本算）；变少 = 消耗。

3. 显形

要交付之前问：这是在交割哪一档？

存在性 / 结果 / 机制。三档选好，不多不少。

4. 冻结

出现难受/冲动时问：我事前写的停止线是什么？

想不起来 = 没写过 = 现在补，别现在就动。

为什么是反射不是流程

四条都不产生文档，也不进任何系统。它们的作用是在动作发生前插入一个断点。

写成流程就死了——你不会每天填四张表，但你会每天问自己四句话。

怎么练

  • 第一周只练第一条（分账），贴在显示器边上。
  • 第二周加复合。
  • 第三、四周加显形和冻结。
  • 一个月后四条连着过，一句话的工夫。

失败形态：一开始就四条全上，三天后全忘。

和系统的接口

  • 分账 → 两本账
  • 复合 → 复合率
  • 显形 → 显示层三档
  • 冻结 → 冻结判据

这四条刚好是四个核心概念的最短版本。记不住概念，记这四句话就够了。
