专业性与打锚点：可复用的方法 v1

从 11-12 的股/金/英伟达那一轮里抽出来的。不是"怎么分析股票"，是"怎么在任何一个垂直里做出能被查的专业判断"。

0 一句话

专业性 = 年轮锚 × 本域读数 × 可反驳。 打锚点 = 找一个在你错的时候能否决你的东西，并让它的读数每周可查。

1 为什么借年轮

  • 一个框架的价值 ≈ 被使用次数 × 被反驳后存活的次数。这是注意力存量，不是真理等级。
  • 年轮的作用是边界：格雷厄姆的公式在"厂房 + 存货"的世界成立，在"排产位 + 生态 + 关键人"的世界失灵。年轮告诉你哪里他已经验过，哪里还没有人验过——后者才是你的位置。
  • 借三层，不借一层：

| 层 | 内容 | 借法 | |---|---|---| | 世界观 | 市场先生、周期、概率 | 直接借，不改 | | 判据 | 安全边际、能力圈、失效条件 | 直接借，这是核心 | | 公式 | PE<15、PB<1.5、PE×PB<22.5 | 只参考，按本域重写 |

套公式不拆层，是外行最常犯的错：用格雷厄姆筛 A股 会筛出一堆银行地产，用它看英伟达永远筛不进去——不是英伟达贵，是公式看不见它。

2 六步法（可移植到任何垂直）

1. 定域：这个垂直里谁付钱、谁承担后果。找"会付代价的对象"——找不到，这个域还没有锚。 2. 选锚：2–3 个，分层选——世界观一个、判据一个、时机或边界一个。每个都要有二十年以上的年轮。 3. 拆层：把每个锚拆成世界观 / 判据 / 公式，只借前两层。 4. 接读数：每条结论配 1–2 个读数。读数必须写清 来源 / 更新频率 / 失效阈值，三个缺一个，这条读数就是装饰。 5. 分期限：把本域的参与方按持有期排开。分歧先判"是期限错配还是真错误"——九成的专业争吵是前者。 6. 装否决器：每条结论写 falsifier。写不出 falsifier 的结论不许写，它不是判断，是抒情。 7. 签章：新东西标 v1 / own，借来的标出处。不改名——改名就失去可反驳性，也就失去继承者。

3 判据：什么时候算"专业"

五条全中才算，缺一条就降级为"看法"：

| # | 判据 | 反问 | |---|---|---| | 1 | 有年轮 | 这套东西最老的零件有多少年？ | | 2 | 有算式 | 每个结论旁边的数，别人能不能复算？ | | 3 | 有期限 | 这个判断在多久内有效？过期谁负责？ | | 4 | 有失效 | 什么读数出现，我就得改口？ | | 5 | 有自错 | 24 小时内，我有没有被自己的数据驳倒过？驳倒后改了没有？ |

第 5 条最贵。一个从不被自己数据驳倒的分析，不是稳，是没接数据。

4 反模式

  • 造新框架不接年轮 → 自说自话，没人能继承，也没人能反驳。
  • 套公式不拆层 → 用一把旧尺子量新东西，量不出来就说新东西不好。
  • 单期限 → 拿宏观做日内，拿五分钟图做三年。
  • 无 falsifier → 抒情，写得越顺越可疑。
  • 借名不改名 / 改名不借名 → 前者是剽窃，后者是失根。
  • 把注意力当正确 → 年轮多只说明被验得多，不说明它对；它只是更值得先信。

骨架一样，读数不同。这就是"可复用"的全部含义：不是搬结论，是搬骨架。

6 工作实例（11-12，英伟达与 A股）

  • 锚：格雷厄姆（安全边际）+ 马克斯（周期定位）+ 巴菲特（能力圈）。
  • 读数：盘前 -7%、Q2 营收 962 亿美元 / +106%、毛利率 74% → 71–72%、成交 1.95 万亿、两融 2.3 万亿。
  • 期限分层：跟随型（英伟达链，天–周）与替代型（国产算力，月–季），同一条新闻，相关性符号相反。
  • 自错记录：金的地板论被山金 -9% 驳掉（央行买实物，不接权益）；去杠杆论被两融企稳驳掉（改成拥挤度出清）。
  • 产出：两条改判，一条保留（期限错配）。

这一轮里，方法本身没被驳倒，被驳倒的是我的两条读数。方法的价值就在于让"被驳倒"这件事发生得足够快。

8 边界

  • 这套方法保证"判断可查"，不保证"判断对"。
  • 年轮锚跨域迁移会失灵，失灵处正是创新的位置——但要先证明失灵，再说创新，顺序不能倒。
  • 五个笃定点不是五个真理，是五个可查的读数。它们错了要改，改了要写进自错记录。
