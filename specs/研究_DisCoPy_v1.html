DisCoPy 研究笔记 v1

读于 2026-11-10。来源：https://discopy.org/、https://docs.discopy.org/、PyPI。

一、它是什么

一个用 Python 算弦图的工具包。组织是法国的非营利协会（RNA W751267560），作者是 de Felice（CEO）、Toumi（COO）、Yeung（CFO）、Poór（CTO），Coecke 挂名誉主席。Coecke 就是范畴量子力学和 DisCoCat 那条线的人。

版本 1.2.2，要求 Python ≥ 3.10。三篇可引的论文：

  • de Felice, Toumi & Coecke, *DisCoPy: Monoidal Categories in Python*, EPTCS 333 (2021), DOI 10.4204/EPTCS.333.13
  • Toumi, de Felice & Yeung, *DisCoPy for the quantum computer scientist*, arXiv:2205.05190
  • Toumi, Yeung, Poór & de Felice, *DisCoPy: the Hierarchy of Graphical Languages in Python*, arXiv:2311.10608

一句话定位：它把"弦图"当成一等公民，像矩阵有自己的包一样。

二、能做什么（按文档的分类）

语法层：discopy.abc 把 Selinger 2009 那篇综述里的图形语言层级做成了抽象基类——Category、Monoidal、Braided、Symmetric、Markov、Closed、Traced、Compact、Rigid、Pivotal、Ribbon、Frobenius、Hypergraph、Feedback、Biclosed、Residuated。每一层都有具体实现（monoidal.Diagram、symmetric.Box……）。

结构：Diagram(inside, dom, cod) 是一串层（Layer），层里是盒子与线。组合 >>，张量 @，还有 foliation() 把图压成最短层数。

求值：Functor 是主力，可以打到具体范畴——python.Function（线是类型、盒是函数）、Tensor（线是维度、盒是数组，后端可选 NumPy/PyTorch/JAX/TF/TensorNetwork/Quimb）、Matrix。

其他表示：Term（单输出的 diagram 等价于闭幺半范畴的内语言里的 lambda 项）、CMap（紧范畴的图编码成端口置换）、Hypergraph（带 spider 的图）。三者都能和 Diagram 互转，用来化简和判等。

语法：CFG、范畴语法（FA/BA/FC/BC/FX/BX）、pregroup、依存语法（接 spaCy），并接 lambeq。

量子：quantum.circuit、quantum.gates、quantum.zx、ansätze、接 tket 与 PennyLane、接 PyZX。

画图：drawing.Drawing，后端 TikZ 与 Matplotlib；Equation(...).draw() 能画重写步骤，to_gif() 能导出动画。

测试：testable 模块，assert_axioms 用网格与组合对来验公理。

三、和我们对得上的三处

1. Stream：带延迟的反馈（这是我们缺的那块）

discopy.stream 实现 monoidal streams（arXiv:2212.14494），底子是"带延迟反馈的范畴"（Feedback category）：对象带一个 delay 操作，反馈环只能取受限形状，反馈时把内部状态接进去。

文档给的例子直接就是"聊天机器人交互的几何"：把 Alice loves Bob 的图用 Int 打到双向过程，再用 Stream 展开，ALB.unroll(2).now 取前两拍。

这正好补上我们那条线的空洞。我们之前证的是"存在不动点"和"局部收敛"，但整个模型是一次性的：一个状态，一个映射，迭代到停。真实的东西不是这样——它每一拍都要接收外部输入，还要记着上一拍。Stream 提供的就是"带记忆的环"，而且是在范畴层面，不是工程层面。

2. Int 构造：把"说"变成"做"

Int-construction（Joyal–Street–Verity 1996）把 traced 范畴变成 compact 范畴：对象变成一对（正、负），态射变成双向过程，复合是沿着共同边界做对称反馈。

文档那句引文值得抄下来：它是"从自然数造整数的构造的升华"。也就是说，只要一个范畴是 traced（有反馈环），就可以假装它有 cup 和 cap。这个"假装"让我们能把词当过程而不是状态。

对我们的意义：我们一直把"判断"当状态（一张卡、一个数），Int 允许把它当过程（有输入方向也有输出方向）。这和用户说的"能动"是一路的。

3. CMap / Hypergraph：判等与去重

CMap 把紧范畴的图编码成端口置换，Hypergraph 把带共享的图编码成 spider 网络。两者都能判等——这是"同一张图换个画法算不算同一个"的机器判据。

我们那个账本要去重"同一件事记了两遍"，正好用得上：把两张卡画成图，判等，等就合并。

四、它不能做什么

  • 不给排序。范畴只说怎么拼，不说哪个更好。所以它替代不了判据，只能做判据之间的接线。
  • 不给收敛。Stream 是语义，不是动力学定理；unroll(n) 只是展开 n 拍，没有"会不会停"的保证。
  • 不给代价。Int 是交互的几何，不是博弈；它没有"谁付账"。
  • 装不上就是装不上。这台机器 pip install 在 Looking in indexes 之后挂死（pypi 与清华镜像都试过），pytest/jsonschema 同样装不上。要么等网络，要么手写最小实现。

五、三个可跑的实验

A. 带记忆的环（20 行）：用 Stream.sequence 造两个过程，一个"我"、一个"环境"，各自带 delay，用 feedback 接成环，unroll(5) 看前五拍。判据：能不能在图上看见"上一拍的输出变成这一拍的输入"。这是语义验证，不是数值验证。

B. 判等去重（30 行）：把账本里两张描述同一件事的卡各画成一个 Diagram，用 CMap 转过去判等。判据：等则合并，不等则给出差异所在的端口。

C. 双向过程（40 行）：用 Int 把"我提出判断"和"世界回话"写成两个双向过程，复合，看反馈路径。判据：能不能从图上读出一句"为什么这句话会回来"。

三个实验都不需要装包以外的东西——但都要先能装包。

六、如果装不上怎么办

两条路。第一条，等网络好了再装，先写代码不跑。第二条，只抄它的三个数据结构（Diagram、Layer、CMap）的核心部分，用 300 行自己实现，够跑 A 和 B。第二条路的代价是失去 Functor 到 Tensor 的求值，但 A 和 B 都不需要求值，只需要结构。

我倾向第二条，因为它顺便验证一件事：我们到底需要它的能力，还是只需要它的形状。如果是后者，那这套东西对我们来说就是一个画图规范，不是一个计算工具——这个判断本身比实验结果重要。

七、实测：装上了，跑通了（2026-11-10 补）

pip 卡在 Looking in indexes 是真，但网络本身没坏——urllib.request 直连 pypi 返回 200，零点四秒。所以问题在 pip 的默认路径：它要写 C:\Users\admin\AppData\Roaming\Python，而这个 shell 是 Low 完整性，WinError 5 拒绝访问。

绕法两步：


python -m pip install --no-cache-dir --index-url https://pypi.org/simple \
  --target .tmp/pylibs networkx matplotlib pillow

--target 把包装进工作区，绕开用户目录。然后 PYTHONPATH=".tmp/pylibs;1-junkyard/discopy"。

还有一处坑：clone 下来的仓库缺 discopy/version.py（这是 setuptools-scm 在构建时生成的），import discopy 直接 ModuleNotFoundError。手补两行即可：


version = "1.2.2"
version_tuple = (1, 2, 2)

装好之后 import discopy 打印 1.2.2，stream / interaction / hypergraph / cmap 全部可导入。

八、Stream 探针的九个结果

tools/repro/discopy_stream_probe.py，九项检查，九项通过。跑法写在文件头。

最硬的三条观测：

一、时间被写成盒子名的后缀。 展开两拍，层是 L0、A0 @ N、N @ B0、L1、A1 @ N、N @ B1。时间不是循环变量，是图里的下标。这一条改变了我对"迭代"的理解——它不是在同一个图上转圈，是把圈铺开成一条带下标的链。

二、unroll(n) 给出 n+1 拍，层数 3(n+1)。 实测 6、9、12。多出来的那一拍是"现在"之后被延迟住的那一拍。

三、展开是接着长，不是重算。 展开两拍的前六层，与展开三拍的前六层完全一致。这个性质很重要：它意味着展开可以被增量做，不必每拍从头算。

另外四条小的：delay 在类型上多一个 later，所以 N.delay() != N；feedback 必须给 mem，不给构造不出来；traced 里的 trace 也能构造（Trace(f)），但那是偏迹，没有延迟，yanking 会把它简化掉——这正是 feedback 与 traced 的分界：有延迟的环不会塌成恒等，没有延迟的会。

最后一条限制写在末尾：unroll 是展开，不是收敛。它不告诉你环会不会停，只告诉你环长什么样。

九、这对我们意味着什么

昨天那条线卡在"只有不动点，没有运动"。Stream 给的是另一半：环被延迟撑开，每一拍都带着上一拍的状态。这正好是"能动"的形式化——不是没有不动点，是环里有记忆，所以不会立刻塌。

下一步可以做的，是把我们那个"快环/慢环"写成两个 Stream：快的那个每拍展开一次，慢的那个每 N 拍展开一次，然后用 feedback 接起来。这一步不需要新的数学，只需要把时间尺度写成两个不同的 delay。

真要做，先回答一个问题：慢环的 mem 里到底存什么。如果存的是"上一次的判据"，那这套东西就有内容；如果只存"上一次的输出"，那它就是个滤波器。

十、双时间尺度环：跑出来了，是负结果，但拿到了窗口

tools/repro/two_rate_ring.py。200 拍，慢环每 5 拍，α=0.2，信号是两条正弦加噪声。

三组：A 慢环的 mem 存判据（阈值随通过率移动）；B 慢环的 mem 只存上一次输出（做偏置，不动阈值）；C 没有慢环。

第一轮（耦合系数 0.12）：


通过率  A=0.590  B=0.555  C=0.555
A vs C 差异率 0.035
B vs C 差异率 0.010

按事先写死的判据（>0.10 才算有作用），结论是慢环是摆设。

这个负结果有两种读法。一种是我设计得太弱，慢环根本推不动快环；另一种是慢环本来就只值这么多。得分开，于是做了耦合扫描——这不是为了救结论，是为了量出"多强才够"。


k=0.12  A/C=0.035  pass=0.590
k=0.20  A/C=0.105  pass=0.660
k=0.30  A/C=0.300  pass=0.855
k=0.45  A/C=0.440  pass=0.995
k=0.60  A/C=0.440  pass=0.995
k=0.80  A/C=0.440  pass=0.995

窗口很清楚：k 在 0.2 到 0.3 之间慢环才真正起作用；往上到 0.45 就过冲，通过率被推到 0.995——环把判据一路推到"什么都通过"，等于自锁。太低是摆设，太高是自锁，中间只有一小段能用。

顺带一个对照：B（mem 只存输出）与 C 的差异率只有 0.010。所以"mem 里存判据还是存输出"确实不一样，但在这个模型里，存输出的那版几乎不改变行为——它就是个滤波器，判据那版才改规则。

两半段的通过率差都在 ±0.05 内，说明改变是整体偏移，不是中途换了制度。这条和昨天的 $\rho$ 结论对得上：单卡内的偏移能测，跨卡的制度变化测不出来。

结构侧没跑通：想用 Stream.id(N @ mem).feedback(...) 造两个只差 mem 类型的环，两次都 AssertionError，空了。DisCoPy 的 feedback 对 mem 与 dom/cod 的匹配有额外要求，我没读明白。这条留着，不装作验过。

十一、这一轮真正学到的

慢环不是免费的。它要么不动，要么把系统推向极端；能用的区间很窄，而且这个区间不是设计出来的，是量出来的。昨天说"双时间尺度效果好"，今天把它变成了一个数：k≈0.2–0.3。

下一步如果要接真的判据层，第一件事不是设计，是先量 k。

动力学侧：V 不下降

两张卡收敛到一个数，于是可以在指数上跑双环：score=(close/MA20-1)/vol20，慢环每 5 日按 thr += k(score-thr) 追一次。


k=0.00  翻转= 80   V下降比例=0.48   V均值=7.16
k=0.12  翻转= 89   V下降比例=0.47   V均值=5.65
k=0.25  翻转= 99   V下降比例=0.48   V均值=4.64
k=0.45  翻转=121   V下降比例=0.37   V均值=3.57

三件事都不对。

一，V 下降比例全在 0.37–0.48，等于抛硬币。V 均值倒是随 k 单调降（7.16→3.57），但那是"阈值贴上去"的算术后果，不是收敛。

二，翻转数随 k 上升（80→121）。合成实验里 k 大了是过冲自锁，真实数据里是相反方向的坏：阈值追着分数跑，跑进噪声带里，穿越次数变多。比例控制作用在噪声上是负阻尼。

三，扫慢环周期（5/10/20 日）也没有救：V 下降 0.38–0.47，翻转 73–121，没有一组优于 k=0。

加死区也只是回到起点


deadband=0.0  k=0.25 翻转= 99
deadband=1.0  k=0.25 翻转= 97
deadband=2.0  k=0.25 翻转= 85   （k=0 是 80）

死区越大翻转越少，但到 2.0 也只是逼近"不追"，没有超过。慢环在这个数据上没有增益，只有代价。

为什么测不出来：前提就不成立

李雅普诺夫要的是自治系统 $\dot x=F(x)$：同一个状态，下一步只由它自己决定。

市场数据不是自治的。两次慢环更新之间，状态一直在被外部推着走。所以：

  • 在更新那一瞬测 V 的下降，是代数恒等：$V=(1-k)^2V^-$，测出来必然降，没有信息量。
  • 在更新之间测，测的是"外部推动 vs 我的收敛"，两者混在一起，分不开。

所以不是"没收敛"，是没有公共的 V。这也是为什么合成数据能测出窗口（信号是两条正弦，近似自治），真实数据测不出来（信号是推动）。

换一个可测的量

不测收敛，测"环有没有放大切换"。这一条在本数据上答案是明确的：放大（80→121）。要它不放大，慢环不能追分数，得改规则——比如只在"判据被推翻"时动，而不是每天都往当前分数靠。

这也解释了那天的结论为什么是"先量 k"：k 是追的强度，而追本身就是错的动作。

十三、不是收敛，是投影：笃定＝幂等

用户一句话把方向掰正了：现实本来就收敛不了，靠的是加减、忽略、自己定条件、过滤世界。

用 HS300 的 688 天日收益做了一次直接对照。先标准化成 score，再两种切法：

  • 软阈值 sign(x)·max(|x|-λ,0)：每次扣掉一个 λ，也就是"再想想、再修一点"
  • 硬阈值 x·1[|x|>λ]：一刀切，也就是"不管了，就这条"

λ     软：幂等误差      硬：幂等误差   归零率   大波动命中率
0.655  0.655           0.000          0.50     0.63
0.792  0.792           0.000          0.60     0.53
0.982  0.982           0.000          0.70     0.46

读法很直接。

软阈值不幂等：再切一次就再少一个 λ，一直切到零。这就是"越问越没有"——不是收敛到某个非平凡点，是塌到空。

硬阈值幂等，误差正好 0：过了这道闸，再问一次，一个数都不动。笃定不是想明白的结果，是闸的形式。

代价也能量出来：闸抬到 0.5 分位，保一半、漏掉 37% 的大波动；抬到 0.7 分位，漏 54%。所谓"过滤世界"，就是用这个漏检率换稳定。没有一个 λ 是免费的。

所以李雅普诺夫在这里用不上，不是数据坏，是问题问错了。收敛需要一个收缩映射把状态一步步拽过去；投影一步就到位，它不逼近，它直接选。

要判一个人是不是真笃定，也就有了可测的东西：把同一个问题再问一遍，他的答案动多少。动一个 λ 就是软阈值，不动就是硬阈值。动与不动都能测，难得的是知道自己用的是哪一种。

十四、样本只有十一次时，笃定押在哪

同一条判据（20 日跌超 6% 之后买），11 次触发，20 日收益：


+5.8 +7.3 +5.4 +5.5 +3.9 +3.0 +3.1 -0.4 -0.2 +1.8 -7.7

换仓位重算：


全仓   期末 1.301   最大回撤 -7.7%
半仓   期末 1.144   最大回撤 -3.9%
一成   期末 1.028   最大回撤 -0.8%

全仓赚 30%，但中途那一次 -7.7% 足以让人改故事；一成仓只赚 2.8%，等于白干。

所以仓位不是答案。小注能买样本，但买样本的收益不足以养活人；大注能养活人，但撑不到样本说话。

真正的分法是：可证伪的东西交给计数器，不可证伪的东西才配叫笃定。

判据（会被数据打脸的那部分）走小注，一条判据一次只押"能连错十次"的钱，攒触发次数，n≥10 且命中率不高于基准就删。

承诺（不会被数据打脸的那部分）才是笃定的位置：说出去的话不收回，改口要另起一条。它不需要样本，因为它不是预测，是不退。

自欺就发生在把这两样混起来的时候——用承诺的口气讲判据，或者用判据的口气躲承诺。可测的判法是：打脸之后，你改的是仓位和规则，还是改故事。改故事就是自欺。
