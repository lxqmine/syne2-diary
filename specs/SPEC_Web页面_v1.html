在 Web 上长一页 · 规范 v1

给自己写一个面板，不是给别人看的官网。判据只有一条：点开三秒能看懂「现在是什么状态」，不用去翻命令行。

一、先决定长在哪

| 形状 | 落点 | 适合 | 例子 | | --- | --- | --- | --- | | 整页 | main + sidebar.panellist | 一张能看很久的表，多个标签页 | aurabot、hub | | 设置分区 | settings.section | 只管自己那点配置 | dsh-meme 的「表情包」 | | 插件配置页 | plugins.bundle.config | 跟单个插件强绑定 | 各自插件 | | 输入框 | conversation.input.left / .overlay | 一个按钮、一个候选项 | dsh-meme 的发图按钮 |

规矩：一个插件只占一处。 想在两个地方出现，说明它该拆成两个插件。

二、文件长什么样


plugins/<名字>/
  package.json        dsh.client = { platform: 'web', inject: [...] }
                      exports['./client'] = './client/client.js'
  index.js            宿主半边：路由、工具、命令
  client/client.js    前端半边：一个文件，没有构建步骤

client.js 的头必须是：


window.__ModuleLoader__.load({
  id: '<包名>',            // 必须等于包名，否则报 "loaded without registering <包名>"
  factory: (require) => {
    const React = require('react')   // React 由宿主提供，不要自己打包
    const h = React.createElement    // 手写 h()，不写 JSX
    ...
    return module.exports
  },
})

dsh.client.inject 写你要用的宿主包（@deepseek-ai/dsh-client-runtime 之类）。dsh.client.immediately = true 表示不等进页面就加载——只有需要在别处注入（比如输入框按钮）时才需要。

三、数据只能从宿主来

前端不许直接读盘、拼路径、猜文件名。所有数据由 index.js 注册的 HTTP 路由给：


ctx.effect(() => ctx.webServer.register({
  kind: 'exact',
  path: '/<前缀>/api/overview',
  handler: (req, res) => answer(res, () => ({ ok: true, ...overview() })),
}), '<名字>: 概览接口')

三条硬要求：

1. 一次请求拿全。 页面刷新就一次 fetch；拆成七个接口只会让首屏七次闪烁。 2. 读不到也要有形状。 每个数据源失败都退回空数组 / null，绝不让整个接口 500 —— 白屏比「暂无数据」糟得多。 3. 只读的不写。 面板要能安全地一直开着；要改东西，走自己的显式 action 接口，并且带确认。

四、样式：用变量，不加花哨

  • 颜色只用 var(--dsw-alias-*)：bg-layer-1 / bg-layer-2 / label-primary / label-secondary / border-l1 / brand-primary。写死 #333 会在深色主题里变成事故。
  • 字号：正文 13px，说明 11~12px，标题 15px。不要给正文加粗，加粗只给数字和强调。
  • 布局：display:flex + height:100% + 内容区 overflow:auto；不要用 position:fixed 抢宿主的对话框。
  • 动效：只有 hover 的背景变化。不做动画、不做渐变、不做阴影浮层。
  • 表格：border-collapse: collapse，行间一条 1px 底线，最后一行的线去掉。

一句话：看起来像宿主自带的一个页面，而不是一个装进来的小应用。

五、状态怎么管

  • 一个 data 状态装整页数据，一个 busy，一个 err。不要为每个标签页各写一份 state。
  • 切标签页不重新拉数据，点「刷新」才拉。面板上的时间是数据生成时间，不是当前时间——这两者混在一起人就会以为数据是新的。
  • 没有乐观更新。只读页面不存在「先改本地再同步」。

六、验收清单

  • [ ] 侧栏图标点进去是一整页，不是弹窗
  • [ ] 一进页面只有一次网络请求（开发面板里数得出来）
  • [ ] 断网 / 接口报错时页面还在，只是显示「读不到数据：…」
  • [ ] 深色和浅色主题下都能读，没有看不清的字
  • [ ] 空数据有话说：「还没有技能。放一个 SKILL.md 到 .dsh/skills/<名字>/ 就会出现在这里。」
  • [ ] 数字和名字能对上：插件数 = 依赖数 + bundles 里的宿主自带
  • [ ] 不写盘：整个页面逛一圈，git status 干净
  • [ ] 自测只测数据层（纯函数 + 临时目录），不测 React

七、反模式

| 症状 | 错在哪 | 修法 | | --- | --- | --- | | 前端里出现 C:\Users\... | 把宿主的知识搬到了浏览器 | 路径只出现在 config 和数据层 | | 每个标签页一个 useEffect 各拉一次 | 拿组件当数据层 | 一次 overview，页面只切视图 | | 点保存直接改盘、没有确认 | 面板成了事故入口 | 先草稿、再显式保存、再回读 | | 自己引一个 UI 库 | 视觉和宿主打架，体积翻倍 | 用宿主变量 + 原生元素 | | 表格里放 200 行不给滚动 | 页面被撑爆 | 内容区 overflow:auto，或分页 | | 接口把异常吞成 {} | 页面永远显示空，没人知道坏了 | 回 {ok:false, message}，页面显示出来 |

八、和本仓库其他规范的关系

  • 页面里的数据来自 .gate / .classify 时，那些文件就是唯一事实来源；不要在面板里另存一份。
  • 面板改动要走 devgate 的记账（gate_declare 限定 plugins/<名字>/），不要在别处顺手改。
  • 前端代码没有测试跑不了，所以逻辑尽量下沉到 lib/：能 node test/selftest.mjs 跑的部分放那边。
