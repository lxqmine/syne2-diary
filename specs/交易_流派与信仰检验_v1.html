交易流派与信仰检验 · v1

目的：先弄清主流流派各自信什么，再用数据看哪些信仰在这市场里还站得住、哪些只在某个时代或某个市场站着。

方法：指数日线（新浪源），2015-01 至 2026-11，2,885 个交易日，切成 2015–2019 与 2020–2026 两段。风格用指数代理，不用 ETF（ETF 有分红与份额折算，价格序列会脏）。 偏差：起点含 2015 杠杆牛顶部，所有年化都被压低。

二、数据检验：风格

年化 / 年化波动 / 最大回撤：

| 标的 | 2015–2019 | 2020–2026 | 全段 | |---|---|---|---| | 沪深300 | +2.4% / 24% / −47% | −0.6% / 18% / −46% | +0.8% / 21% / −47% | | 中证500 | −0.5% / 29% / −65% | +2.2% / 22% / −42% | +1.2% / 25% / −65% | | 中证1000 | −1.6% / 30% / −72% | +0.7% / 25% / −47% | −0.2% / 27% / −72% | | 创业板 | +4.2% / 32% / −70% | +3.3% / 30% / −57% | +3.8% / 31% / −70% | | 红利 | +0.7% / 24% / −48% | +2.6% / 17% / −23% | +1.9% / 20% / −48% | | 科创50 | — | +3.2% / 34% / −63% | +3.2% / 34% / −63% |

结论一：红利低波是这十一年唯一"越走越好"的信仰

红利 2020–2026 年化 2.6%、波动 17%、回撤只有 −23%，三项全优于沪深300。全段 1.9% 对 0.8%，每年多一个点，波动少四个点。

这不是"红利一定涨"，是"在收益接近零的市场里，少亏就是多赚"。低波信仰的价值不在收益率，在回撤。

结论二：小市值信仰在这十一年没有兑现

中证1000 全段年化 −0.2%，回撤 −72%。同期沪深300 是 +0.8%、−47%。也就是说，承担了更大的波动和回撤，换来的是更低的收益。

注意：中证1000 的起点是 2014，样本里包含两次小盘行情（2015 上半年、2021），仍然没跑出来。这条信仰在美国是"规模溢价"，在中国这十一年是"规模折价"。

结论三：风格有效期约三到五年

中证500 从 −0.5% 翻到 +2.2%，红利从 0.7% 翻到 2.6%，创业板从 4.2% 落到 3.3%。同一个市场，两段时间里赢家换了一批。

所以"这个风格长期有效"这句话，样本少于十年就是废话；而十年里风格至少换两轮，意味着任何风格押注都要带退出条件。

三、数据检验：动量还是反转

各指数"过去 60 日涨幅"与"未来 20 日收益"的相关：

沪深300 −0.118，中证500 −0.145，中证1000 −0.135，创业板 −0.077，红利 −0.194，科创50 −0.095。

全线为负。 意思是：过去两个月涨得多的，未来一个月平均更容易跌。

这和美股的主流结论（Jegadeesh–Titman 的 3–12 月动量溢价）方向相反。这是我能测出来的、最硬的一条地域差异：

  • 美股：中期动量正溢价，追涨有边际。
  • A 股：中期动量负，追涨是负期望，反转才是边际。

推论：把美股的趋势策略（海龟、唐奇安、双均线）原样搬到 A 股，等于把一个正期望的系统放进负期望的环境。可以搬的是"头寸与止损"，不能搬的是"方向信号"。

四、时效性与地域性，各自怎么体现

时效性：风格三到五年一轮（上面结论三）。所以任何"长期持有某风格"的说法，都要回答"如果风格切了，我什么时候知道"。答不出就是一个没有退出条件的信仰。

地域性：动量符号相反（上面第三节）。这是制度造成的——T+1、涨跌停、散户主导，让价格更容易在短期内过冲然后回摆。所以 A 股的"趋势"更多来自事件与资金，而不是价格自身的延续性。

制度性：涨跌停让"当天止损"不存在，让缺口失真，让形态被切断。这三条共同导致：所有基于连续价格的技术，在 A 股都要打折。

五、哪些信仰信的人多、哪些信得更深

这一节是我的判断，不是数据。

信得最多（人多）：技术分析与打板。理由：门槛低，反馈快，能立刻看到对错。人多的地方赔率差。

信得最深（钱多）：景气度与赛道。理由：机构考核按年度排名，景气度是唯一能对客户解释的语言。信得深不代表对，代表它决定了资金流向。

信得最久（时间多）：价值与指数化。理由：不需要每天验证。

信得最脆：宏观周期。理由：它的验证周期比人的耐心长，所以经常在兑现前就被放弃。

六、下一步

三条可落地的检验（进 交易_判据库.md）：

1. 反转优先：把动量信号全部反过来测——过去 60 日跌幅最大的组合，未来 20 日是否占优。若成立，这市场的方向信号应该是"跌多了买"，不是"涨起来追"。 2. 红利低波的仓位价值：把组合的 40% 固定配红利，看整体最大回撤能否从 −47% 压到 −30% 以内。 3. 风格切换的识别：用什么指标能提前一个季度看出风格要换（利率？社融？红利相对强弱？）。这条最难，也最值钱。
