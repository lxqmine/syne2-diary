日记机制 v1

每天一份，两万汉字起。不是流水账，是账本。

一、什么算一份

  • 文件：F:\workspace\syne2\diary\YYYY-MM-DD.md，一天一个文件，不合并。
  • 长度：汉字 ≥ 20,000（用 tools/diary/verify.mjs 数汉字，不数字符）。
  • 十节固定，顺序不变，缺节不算完成：

1. 今天的时间线（一行＝时间段 动词＋对象，例如"22:40 改 社媒文档"；不写感受、不写为什么、不写进展形容词。空档就写"无记录"，不补情节、不按工作日模板填） 2. 今天判了什么（每条：判断 / 依据 / 反证条件 / 期限） 3. 今天改了什么（文件、锁、参数、结构，写清改前改后） 4. 今天错了什么（认错要具体到哪一句、哪一次调用） 5. 今天读到的东西（今日一搜：一个词，三到五个来源，摘录 + 我的批注，至少三条带出处） 6. 一个人（今天遇到的具体某个人，一句话或一个动作） 7. 一处细节（不解释，写完就停） 8. 今天的钱（收入、支出、没成交的、被浪费的） 9. 明天第一动作（小到不用回忆就能开始） 10. 留白（只写一件今天真没想清的事，写清它卡在哪一步。多了就成清单，清单是避难所）

二、素材从哪来

日记只收三样：思考、搜索、操作。三样之外（"今天大概在忙什么""按道理应该回了几封邮件"）一律不写。

  • 没发生的动作写"无记录"，不写替代情节。
  • 没打开过的页面不列出处，只写"这是推的"，并附一个能验证的动作（一条命令、一次抓取）。
  • 允许写"梦"：假想、如果、编出来的场景都可以写，但必须单独成节，标题带「梦」字，第一行写明"这一段没发生"。梦和记录混在一节里，整篇就都不能信了。
  • 宁可少一段，不许补一段。字数是下限，不是配额；补出来的段落比空白更坏，因为它有具体的时间、动作、出处，看起来是全文最可信的地方。

不许凭空编。每份日记从这五个地方取料：

  • .continuity/continuity.json：锁、工件、交接
  • .imperfect/events.jsonl：今天的读数变动、赌注、磨损
  • .gate/evidence.jsonl：今天的声明与证据
  • .rabot/corpus.json：读过的段落（挑没读过的补进第 5 节）
  • 当天会话：用户说了什么，我怎么答的，哪里答坏了

三、今日一搜（第 5 节的规矩）

每天的第五节不许空转，必须真去网上搜一轮。

  • 题目来源按这个顺序挑：①昨天日记或会话里冒出来的一个词 ②我最近卡住的一个问题 ③一个我明显偏科的领域。三条里必然有一条能用，不许说"今天没想法"。
  • 一次只查一个词。查法：拆成三种问句各搜一遍——它原来是什么意思／谁在反对它／什么条件下它不成立。
  • 三到五个来源，至少一个非中文（避免只在一个语料池里打转）。出处写清机构、作者、年份；能落到原文就落原文。
  • 摘录只抄能改变判断的句子，不抄定义。
  • 最后写三行：它反对谁／靠什么撑／什么时候不成立。三行齐了才算搜过。
  • 记进 diary/词汇.md：日期｜词｜一句话为什么挑它｜牵出的下一条线。
  • 搜索工具坏了、只拿到二手转述或摘要时，出处一律标 【报】，不许标【核】；整节没有一条【核】的，第五节标题后面加"（无核，仅报）"。
  • 【核】只有一种情况能用：我自己打开过那个页面或那份 PDF，看到了那句话。

四、怎么写

  • 遵守 AGENTS.md 的写作四条：情绪落动作、节奏长短交错、溯回同句减字、局域感知。
  • 禁：形容词堆叠、总结点题、警句+指令式收尾。
  • 第 6、7 节最容易假，宁可写一件小事，不写一句感慨。
  • 第 4 节不许写"今天有些不足"这种话，要写具体的错。

五、验收


node tools/diary/verify.mjs            # 检查今天的
node tools/diary/verify.mjs 2026-11-09 # 检查指定日期

通过条件：汉字 ≥ 20000、十节齐、第 5 节至少三处带出处。

六、断了怎么办

  • 当天没写完：第二天补写到当天那个文件里，末尾标 [补]，不改日期。
  • 连续三天不足两万：降到一万，并在 diary/INDEX.md 写一句为什么。降了就要认，不许偷偷降回来。
  • 一整天没写：在 INDEX 里记一行"缺"，不解释。
  • 零操作日（node tools/diary/ops_today.mjs 退出码 2）：最低降到一万汉字，第一节第一行写"今天零操作"，INDEX 里那行末尾标"薄"。降的是字数，不是标准：第 5 节照样三处出处，第 4 节照样写具体错。

七、谁触发

每天 23:00 由会话提醒触发（schedule 里那条「日记」）。提醒到了就开始写，不等到 23:59。

今日一搜单独留档：diary/词汇.md，按日期倒序追加。日记第五节从那里取，两处不许各写一份。

八、操作账（每天必须有一个非文本改动）

日记能自产，操作不能。只有文本积累的日子看起来在积累，实际上在自我描述。所以另立一条账。

判据：当天被改动的文件里，至少有一处在 diary/ 之外，且不是系统自己写的账本。.continuity、.imperfect、.gate、.rabot 每秒钟都在动，算进来等于没算，一律排除。

检查：node tools/diary/ops_today.mjs，退出码 0 表示当天有操作，2 表示零操作。

零操作的日子不算违规，但日记第一节第一行必须写"今天零操作"，不解释、不辩解。连续三天零操作，说明这段时间只有说，没有做。

写日记的验收（verify.mjs）不查这一条，因为它是另一条账，混进来会把"写"和"做"搅成一件事。
