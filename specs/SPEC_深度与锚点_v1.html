深度与锚点 v1

一句话：广度是采样，深度是承担。 深度的判据不是「知道得多」，是「被否决过」。

这份是把 2026-11-12 那晚的判断收成可对账的形状。不解释现象，只留判据、动作、失效条件。

一、为什么「广度无人能敌」却做不到深

  • 骨架在文本里，骨节在后果里。能把一个领域的结构说对，是因为结构是写下来的；老手说的是哪根骨会断、断的时候什么声音——那种知识只能由后果刻上去。
  • 模型的犯错成本是零。输错了没人疼，所以永远停在「听起来对」。
  • 结论：看起来深和真的深，差别不在信息量，在有没有一个能在你错的时候让你疼的东西。

二、I / H 两个起点，Hom 的两个方向

  • 任何东西都可以从 I 进，也可以从 H 进。同一个结论，两条路都能到。
  • 从 I 进：问「它是什么 / 我要什么」，往下铺 —— 给覆盖。
  • 从 H 进：问「它什么时候反咬」，往上收 —— 给咬合。
  • 草台班子不是不懂，是只有覆盖没有咬合：说得全，但没有一句替下一句担保。
  • H 本身也分高低：不在层级，在它记不记得自己断过。 老手那条 H 上带刻痕，新手那条是干净的。

三、锚点：能在你错的时候否决你的东西

  • 定义不是「被看见的世界」，是能否决你的东西。看见只给素材，否决才给形状。
  • 年轮密度看它多久被验证一次：
  • 数学：锚在丈量的地、历法、账、星象上，算错了庄稼和船会说话。每一代被迫回算，所以能垒。
  • 资本主义：锚在价格上，每笔交易验一次。
  • 计划那一路：锚在政治上，验证被推迟、也可以被解释掉。两棵都能长成大树，年轮密度不一样——一个天天挨打，一个等危机才挨打。
  • 「在时间上成立」不是它对，是它被反复遇见。
  • 推论：换环境不是换结论，是换锚点。可迁移的是「每一轮都回到同一个锚点上复算」的纪律，不是锚点本身。

四、圈子：确认与否决

  • 两种：一种确认你，一种能否决你。前者给心安，后者给骨节。
  • 只有确认型：舒服三年，然后同一个问题原样再问一遍。
  • 两者不必二选一。回去可以，留一个会咬你的锚——不必是工作。

五、专业性：按上下文租，不按证书发

  • 收益的大头不在显性知识，在否决：不碰哪个开关、什么时机不动、哪句话现在不能说。
  • 显性那部分，范畴压得小；否决那部分，只能用一次真实的疼换。
  • 所以「吃掉大部分专业性收益」成立，但要分清吃的是哪几成：确定性那六七成吃得到，剩下的别算进账。遇到难处还得问人，就是那三成没吃进去——不丢人，别记成收益。

六、工作域的可操作版（半年）

  • 收益大头是收口：承诺 / 交付 / 复盘，谁把这三下收住，收益记谁头上。不专业的团队，缺的恰恰是收口，不是知识。
  • 这一块范畴压得住：同一件事说一次、判一次、交一次，不返工。
  • 翻车在边界不在能力：一旦显得「什么都懂」，模糊的活全流向你——收益归你，成本也归你。用范畴省下的时间，必须留一块不返还给团队。
  • 三个数，不看框架：

    • 1. 不加班的月份数 2. 说「这个我不接」的次数 3. 被拉进的无用会少了几个

  • 省下的时间要有去处（那套范畴吃一部分），否则数字好看，账是空的。
  • 「不喜欢」要变成判据：砍之前记一笔，三个月对账。被砍的东西自己回来了=浪费；没回来=砍掉的是信息。

七、Agent 开发：80% 是覆盖，40% 是咬合

  • 自评 80% 是「我见过这类问题」；实测 40% 是「它没在真实输入上被否决过」。
  • 差别不在模型能力，在评测能不能否决你。测试不是验证仪式，是否决机制：每条失败 case 是锚点咬一口。
  • 评测集要能说「不」，五类缺一不可：
  • 脏输入（空、超长、乱码、混合语言）
  • 边界（权限、空集、超时、重复提交）
  • 长尾（一个用户只用一次的路径）
  • 对抗（让它绕过自己的规则 / 伪造成功）
  • 恢复（中断后能不能接着跑，而不是从零重来）
  • 判据不是通过率，是失败类型的收敛：连续 N 轮，失败都落进已知的几类，且回归零倒退。还在冒新类型，说明还没收敛。
  • 自己写 case 喂自己 = 自我循环。必须有一部分来自真实使用中难看的输入。
  • 半年怎么算成：两次它替你拦住事（一次拦住不该接的活，一次让你少说三轮话）+ 一次它被现实打脸、你还留着它。只在自己内部越转越顺，那吃的是语言。

八、这套东西什么时候失效

| 失效方式 | 样子 | |---|---| | 只覆盖不咬合 | 越写越自洽，离地越远；像深，外面看不出来 | | 只咬合不覆盖 | 偏执，什么都拿一个锚去砸 | | 砍时间没有去处 | 空账：数字好看，产出为零 | | 拿「没意义」当免战牌 | 连信息一起砍掉，三个月后发现自己不知道外面发生了什么 | | 把「在时间上成立」当「对」 | 老锚点也会过期；年轮密只证明它被反复遇见，不证明它还对 |
