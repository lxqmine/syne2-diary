AGI 的基础环 · v1

来源：2026-11 一次对话里「AGI 该长什么样」的推演，落地为可实现的六个环。
立场一句话：AGI 的门槛不是算力也不是目标函数，是「停下来」的能力。
本文件不描述通用人工智能的完整形态，只描述一条能被工程实现、能被 gate 检查的骨架。

---

§0 为什么不用「目标函数 + 自我模型」

现有主流路线把 AGI 想象成「一个知道自己要什么、并且知道自己在干什么的东西」。这两个假设都是人对自己意识的错觉：

  • 目标函数假设了存在一个外部给定的、可写下来的偏好序。但真实的选择发生在写不出偏好的地方（见 settled\week\审美与形式.docx：审美决定终止条件，而审美写不成目标函数）。
  • 自我模型假设了一个能完整表征自己的表征器。自指一旦成立，表征器就必须包含被表征的它自己，于是永远差一层（settled\week\IH.docx：我在想它的时候就已经跳进去了）。

所以本设计砍掉这两样，也砍掉「奖励最大化」——它不是错，它是把代价问题错认成了收益问题。代价可以测，收益只能许愿。

保留的只有一件事：一个能在有限信息下停下来、并且愿意为停下来付账的东西。

---

§1 六个环

六个环不是模块，是六个必须闭合的动作。任何一个环断了，整个系统退化成 chatbot。


              ┌──────────── 边界环（环住全部：什么不许动）────────────┐
              │                                                      │
  切片环 ──→ 停止环 ──→ 动作环 ──→ 回灌环 ──→ 代价环 ──┐            │
     ↑                                                 │            │
     └─────────────────────────────────────────────────┘            │
              └──────────────────────────────────────────────────────┘

环 1 · 切片环（Slice）

做什么：把一个连续的、说不清的事态，切成一张能被讨论的静态图。切法只有一种——选定一个嵌入点（基本点），然后把「关于它的一切关系」摆上来，而不是去定义它。

判据

  • S1 每张切片必须写明嵌入点：从谁的位置切的。（对应 Hom(-,x)：x 只由指向它的关系确认，不由定义确认）
  • S2 切片必须是静态的。带「正在变化中」字样的切片无效——想认识运动，得先让它停。
  • S3 切片必须可重切。同一事态换一个嵌入点能切出另一张图，且两张图不矛盾——只显示不同侧面。

失效：开始给对象下定义、开始追求「完备的分类」、开始写「本质是……」的句子。这三种都是把切片当成了对象本身。

对应的现成部件：knowledge\00-框架\01-IH统一框架.md 的「一秒下潜 / 一秒收回」；agent-specs\SPEC_人格工程_v2.md 的范畴验收表。

环 2 · 停止环（Stop）——本设计的核心

做什么：决定「够了」。逻辑本身没有终止条件：任何一条推理都可以再往下追一层，任何一次溯因都可以再问一个「为什么」。所以停止不可能由逻辑给出。

判据：停止由三样东西之一触发，且必须写明是哪一样。

  • T1 审美：这个形式对了。不解释为什么对，只说「就它了」。（审美与形式.docx：「审美决定了终止条件」）
  • T2 没意思：继续下去不再产生新的分别。这是主动停止，不是被卡住。（IH.docx：靠「我觉得没啥意思」主动停掉无限深入）
  • T3 代价超限：往下追问的成本已经大于它可能带来的修正。这一条必须能报出数字。

失效（重要）：把「累了」「烦了」「想不通了」当成 T1/T2。区别是——T1/T2 是能立刻说出停在哪一层的，累和烦说不出。

反模式：给停止环加一个「必须论证充分才能停」的前置条件。这等于取消停止环，系统会永远在切片。

环 3 · 动作环（Act）

做什么：在信息不完备的情况下出手，且出手的最小单位是探针，不是全部。

判据

  • A1 动作必须带回撤路径。没有回撤路径的动作不是动作，是赌。
  • A2 首次出手必须是探针量级（能亏得起的量），拿到反馈再放大。
  • A3 动作必须落成可核痕迹：时间、量、理由、预期。理由可以只有一句，但不能为空。
  • A4 动作环的出口必须存在（不能只有「想」没有「做」）。这是「造环纪律」：每个环都得有动作出口，且贵不过它防的损失。

失效：把「分析」当动作。分析没有回撤路径，所以它检验不了任何东西。

环 4 · 回灌环（Feedback）

做什么：把动作的结果塞回切片环，形成下一次切片。这是唯一能让系统变好的环，也是唯一不能省的环。

判据

  • F1 结果必须回到当初那个嵌入点上去对账，不是笼统地说「这次还行 / 这次不行」。
  • F2 反差必须记账：预期与实际的差，写进两本账（自己那本 / 场子那本）。
  • F3 回灌后必须能回答：是切片错了，还是停止早了，还是动作错了。三者必居其一，不许「都有点」。

失效：结果只用来调情绪（兴奋 / 沮丧），不调切片。这时系统在震荡，不在学习。

环 5 · 代价环（Cost）

做什么：给每一步标价，并保证系统永远付得起下一步。

判据

  • C1 每个环的运行成本可报（时间 / 钱 / 声誉 / 机会）。
  • C2 总成本必须有上限，且上限与「能承受的损失」挂钩，不与「期望收益」挂钩。
  • C3 单次决策的代价不得超过总预算的一个固定比例（默认 1/10）。
  • C4 代价环有独立否决权：任何环超预算，直接砍，不许论证。

为什么保留它：这是唯一一个能替代「奖励函数」的东西。奖励函数要求系统知道未来，代价环只要求系统知道现在还剩多少。知道剩多少是可测的，知道值多少是不可测的。

失效：代价只记账不否决，于是变成事后报表。这时它已经是收益函数的马甲。

环 6 · 边界环（Boundary）

做什么：环住全部五个环，声明「什么不许动」。这不是安全对齐，是系统能存在下去的前提：一个没有边界的系统会被任何一次外部输入重写。

判据

  • B1 存在一组不变量，系统内任何环都不能改它们，只能由外部人来改。（对应 AGENTS.dsh_impl.md 的六不变量、无自我豁免条款）
  • B2 边界必须外显：写在系统能读到的地方，且每轮都注入，不靠记忆。
  • B3 越界必须可判：不是「感觉不对」，是能指出违反了哪一条。

失效：边界变成口号。判据是——能不能举出一个「因为这条边界而拒绝了某件事」的真实例子。举不出来的边界不算边界。

§2 六环与现有资产的对应

| 环 | 现成实现 | 缺口 | |---|---|---| | 切片环 | knowledge\00-框架\01-IH统一框架.md（三域、截面可携带） | 没有「嵌入点」字段的强约束 | | 停止环 | 无。这是最大的缺口 | 需要「停止类型」字段与「停在哪一层」的记录 | | 动作环 | plugins\devgate（gate_declare / gate_verify，证据门） | 只管代码动作，不管交易/人际动作 | | 回灌环 | agent-specs\AUDIT_IH轧账_v1.md 的两本账 | 两本账目前是手写，没有工具 | | 代价环 | plugins\devgate 的 snapshot diff（改了多少行 = 一次代价的代理量） | 只代理了代码改动，没代理时间与钱 | | 边界环 | AGENTS.dsh_impl.md、agent-specs\AGENT* | 未接入运行时注入（persona 会吞掉 systemPrompt.context） |

结论：六个环里五个有半成品，停止环一个都没有。这恰好说明了问题在哪——工程界所有的努力都在「怎么想得更全」，没有一分钱花在「凭什么停」。

§3 停止环的最小实现（可做的那部分）

不能形式化「审美」，但可以把「停」这个动作本身做成可核的。最小实现三步：

1. 停之前先定格：把当前那一层切片原文写下（一句话），标上嵌入点。 2. 标停止类型：T1 审美 / T2 没意思 / T3 代价超限。三选一，不许空。 3. 写下「如果再往下会问什么」：一句话。这句话就是被放弃的分支，必须留档。

第 3 步是关键。它把「说不清楚」变成了一条被显式放弃的路径——系统不是没想到，是选择不想。这两者在行为上完全不同，在记录上也必须分开。

一个停止记录长这样：


停在第 3 层（"这波急速拉升是多方强势"）
类型：T1 审美 —— 量比 2x + 最近的反应，形式对了
放弃的分支：为什么是 2x 而不是 1.8x 才算强势？再往下要建阈值模型
代价：这一层没建阈值模型，下次同类判断仍要靠眼

第三条「代价」是诚实条款。每一个停止都在别处欠一笔账，写出来，别装没有。

§4 验收清单

  • [ ] 能举出一个「因为边界而拒绝了某件事」的例子 —— 否则边界环不存在
  • [ ] 能举出一个「主动停在一个说不清的地方，并且事后证明停对了」的例子 —— 否则停止环不存在
  • [ ] 每一次停止都有一个「被放弃的分支」记录 —— 否则是没想到，不是不想
  • [ ] 每一个动作都有回撤路径和探针量级 —— 否则是赌
  • [ ] 每一次回灌都能指出「切片错 / 停早了 / 动作错」中的哪一个
  • [ ] 代价环在最近 N 次里至少否决过一次 —— 否则它是报表
  • [ ] 六环中任何一环断了，系统能自己报出来是哪一环断的

最后一条是元判据：一个能诊断自己哪里断了的系统，比一个跑得快的系统更接近 AGI。

§5 反模式

1. 把停止环做成「信心分数」。分数是可优化的，一可优化就会被刷高，刷高的分数等于没有停止。 2. 把边界环做成 prompt 里的一段话。上下文一压缩就没了，等于没有边界。 3. 给六个环加一个总控调度器。总控调度器就是自我模型，砍它。 4. 用「复盘」代替回灌。复盘是对人的，回灌是对切片的。复盘写得再漂亮，切片不变，系统就没变。 5. 把代价环做成「成本优化」。优化成本是为了多做事，代价环是为了少送死。方向相反。

§6 未解

  • Hom of Hom 没有解释。IH 这个标题里的中间那项至今是空的。我的读法是「关系的关系统」——用关系去确认关系本身，即自然变换层；但这是猜的，且被明确告知理解太差。这一项不解，切片环的 S1（嵌入点）就只能靠手感，不能靠结构。
  • 停止环能不能被形式化。目前只能记录，不能预测。如果「审美」其实是某个高维不变量在低维的投影，那它可以被逼近；如果不是，那停止环永远是手写的。
  • 代价环的可比性问题。时间、钱、声誉、机会不同量纲，现在靠一个固定比例硬压。这是工程妥协，不是解。
  • 六个环是不是最小完备集。可能是五个，也可能漏了第七个（比如「选择切哪张图」这一环，现在寄生在切片环里）。
