写法：叙事四条的可调参数

工作区约定（AGENTS.md）里那四条是底线，这份文档写怎么调、怎么验、在哪儿会破。

一、四条各自在管什么

| 这条管 | 不写这个 | 写这个 | |---|---|---| | 情绪落动作 | "他心里轻松了一下" | "他把那句删了。删完又觉得空。" | | 节奏长短交错 | 连续五段同样长度的复句 | 一段长的，然后一行七个字 | | 溯回同句减字 | "如前所述""回到刚才那个问题" | 同一句话第三次出现时少一个字 | | 局域感知 | "我意识到这背后是一个结构性问题" | "账本最后一页的修改时间是三点零四" |

四条合起来只干一件事：把判断换成证据，把结论换成动作。 读者自己会得出结论，而且他得出的那个比作者写的那个更牢。

二、旋钮（写不同东西时拧的方向）

情绪强度 = 动作的密度，不是形容词的强度。

  • 强：三个连续动作，一个比一个小（删句 → 觉得空 → 空着吧）。
  • 弱：只有一个动作，而且不解释（他把杯子挪开半寸）。
  • 情绪越强，越要少写；写多了变成喊。

节奏密度 = 短句之间的间隔。

  • 紧：每段末尾给一行三五个字的。连用三次，读者会喘不上气。
  • 松：长段之间不插短句，靠标点和换行透气。
  • 一条经验：一段里如果有两个转折，第二个转折必须单独成行。

溯回次数 = 同一句话出现几次。

  • 两次：暗示。读者会觉得"这个又来了"，但不确定。
  • 三次：确认。第三次必须变，而且只变一个词。
  • 四次以上：变成主题句，开始油。

局域范围 = 你能看见多少。

  • 最紧：一张桌子（灯管、碗、便签）。
  • 中等：一间屋子（门口、收银台、窗）。
  • 放宽到城市就开始假。全局视角只能用一次，用在开头或结尾，而且必须是别人的转述，不是自己的判断。

三、三个测试（用来判真假）

1. 删末句测试。 把最后一句删掉，还成立吗？成立就删。删完不成立，说明前面没铺够，回去补，不要靠末句顶。 2. 抽形容词测试。 把所有形容词抽掉，句子还剩信息吗？剩，就是写对了；不剩，那些形容词在替内容干活。 3. 换人测试。 把"我"换成别人，还成立吗？成立，说明写的是处境不是感受；不成立，说明写的是私人经验——私人经验要留，但得给它一个能被外人看见的把手（一个物件、一句原话、一个时间）。

四、破口清单（我自己的，按出现频率排）

1. 警句 + 指令收尾。 "所以我想通的第一件事是……""记住：……"。这是对冲风险用的，删。 2. 术语当结论。 说"这是同构"就完了，等于没写。同构在哪两个动作之间，写出来。 3. 为了漂亮而漂亮。 排比、对仗、"不是 A，而是 B"。用一次是刀，用三次是套路。 4. 自我解释。 "我这样说是因为……"。解释是把读者当审稿人，不是当读者。 5. 结尾升华。 把具体的动作抽象成一句道理。道理留在文档里，故事里只留动作。

五、往别的体裁上搬

分镜：一格 = 一个动作 = 一句话。四条里的"局域"变成"这一格镜头里能看见什么"，"溯回"变成"同一个机位第二次出现"。

说明文/规范：四条反过来用——情绪不要，节奏要，溯回要（定义在开头出现，第三次出现时带一个新条件），局域要（每条规则配一个真实文件路径，不配例子就是空话）。

讲课/对话：只留"溯回"和"局域"。同一个比喻在开头和结尾各出现一次，中间所有抽象都换成这间屋子里的东西。

六、自检（写完扫一眼，三十秒）

  • 全文有没有一处"我意识到/我明白了/这说明"？有就换成动作。
  • 短句是不是集中在段尾？如果全篇都是长句，加三处断行。
  • 那句话出现了几次？两次以内别改，三次必须改一个字。
  • 有没有一个具体的钟点或页码？没有就加一个。
  • 末句删了还成立吗？

七、和"深沉"的区别

深沉不是词大，是知道多少不说多少。一段里能放十个信息，只放三个，剩下七个留在动作的缝里——读者摸得到缝，才觉得底下有东西。

反过来，把十个全写出来，读者只会觉得这人话多。
