每日机理报告 · 模板 v1

参照样本：agent-specs/分析_2026-11-27_机理与硬约束.md（9,981 汉字）。 那份比"三个世界"好在：每节都挂数、每条都落到"能不能做到"、缺口和自错都摆出来。 本模板把它的骨架固定下来，每天换数据不换结构。

零、硬规矩

1. 所有数字当场取，不许引用昨天的报告、不许凭记忆。取不到的写进缺口表，不估、不编。 2. 每个小节至少一个数。没有数的小节删掉。 3. 每条判断必须带失效条件（"如果……则本判断作废"）。写不出的，降级成"观察"，不算判断。 4. 禁止："值得注意的是""综合来看""众所周知""或将成为""有望"。 5. 不写宏观抒情。凡出现"时代""浪潮""叙事"这类词，删。 6. 汉字数下限 6,000，上限 12,000。超过 12,000 说明在灌水。 7. 结论只有两种：能算的清（给数）／算不清（进缺口表）。中间态不许有。

一、一句话结论（≤80 字）

今天这盘是"什么类型"＋"关键分界在哪"。例：

政策脉冲而非趋势反转；分界 4242（MA60），站上才改口。

二、今日读数表

一张表，不少于 20 行，四列：指标｜读数｜分位/对比｜来源。

必须覆盖：

  • 指数：沪深300、上证、创业板、科创50（涨跌幅＋成交额＋换手）
  • 估值：PE、E/P、股息率（有就写，没有标缺口）
  • 货币：M2/M1/M0 同比与环比、剪刀差
  • 利率：10Y、2Y、期限利差、中美利差
  • 汇率：中间价、离岸
  • 资金：主力/超大单/大单/中单/散户净额，5/10/20 日累计
  • 情绪：涨停数、涨跌家数、换手分位
  • 政策：当日关键表述（原文引号，不改写）

三、机理链（三条，每条给箭头）

格式：A → B → C → 结果，每条链末尾给"这条链的瓶颈在哪一环"。

  • 链一（政策→资产）：文件 → 谁执行 → 用什么钱 → 买什么 → 谁接盘
  • 链二（货币→信用）：央行 → 银行 → 企业/居民 → 需求
  • 链三（情绪→筹码）：成交结构 → 谁在买 → 能撑几天

每条链必须写出当前卡在第几环，并给一个可观测指标。

四、硬约束（四道，每道给上限）

1. 货币总量约束：M2 增速 / M1 增速 → 能放多少 2. 资金价格约束：利差 / 汇率 → 能降多少 3. 筹码约束：流通市值 / 换手 / 存量资金 → 能推多高 4. 制度约束：涨跌停 / T+1 / 维持担保比例 / 考核周期 → 能多快

每道写：上限是多少、现在用了多少、还剩多少。

五、可行性（三问，每问给算式）

  • 要托住某个点位，每天需要多少钱？（承接比例 × 成交额）
  • 要推动某个风格，需要多少增量？（市值 × 涨幅 ÷ 换手）
  • 要改变预期，需要多少时间？（传导系数 × 时滞）

三问都必须给算式和结果，不许只给形容词。
