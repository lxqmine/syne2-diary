一、SDD：自然变换的接口文档

1.1 对象

设 C 与 D 是两个范畴，F、G 是从 C 到 D 的两个函子。一个从 F 到 G 的自然变换 η 记作 η: F ⟹ G，它的数据是：

  • 对 C 的每一个对象 X，一个 D 中的态射 η_X: F(X) → G(X)，称为 η 在 X 处的分量。

它的条件是：

  • 对 C 的每一条态射 f: X → Y，下面的方块交换：

F(X) --F(f)--> F(Y)
 |              |
η_X            η_Y
 |              |
 v              v
G(X) --G(f)--> G(Y)

也就是 G(f) ∘ η_X = η_Y ∘ F(f)。

1.2 接口

从外面看，一个自然变换提供三样东西：

第一，取分量。 给一个对象 X，返回一条态射 η_X。这是它唯一的"取值"接口。

第二，方块交换律。 给一条态射 f: X → Y，返回一个等式 G(f) ∘ η_X = η_Y ∘ F(f)。这条不是"数据"，是"承诺"：无论你怎么用这两条复合，结果一样。

第三，隐式的自然性检查。 任何用到 η 的构造，只要换一个对象，就必须同时换掉两条边。这条接口没法单独调用，它约束的是使用者的用法。

三样里第二样是这一节的全部重量。第一样是数据，第三样是纪律，只有第二样是"内容"。

1.3 律

自然变换本身没有结合律、没有单位律——它不是复合，是一个箭头。律出现在两个地方：

律一（垂直合成的结合律）。 若 η: F ⟹ G、θ: G ⟹ H、ψ: H ⟹ K，则 (ψ ∘ θ) ∘ η = ψ ∘ (θ ∘ η)，逐分量成立，因为每个分量是 D 中的复合，D 里结合律已经成立。

律二（垂直合成的单位）。 对每个函子 F，有一个恒等自然变换 1_F: F ⟹ F，分量为 1_{F(X)}，满足 1_G ∘ η = η = η ∘ 1_F。

这两条律说明：以 C 到 D 的函子为对象、以自然变换为态射，构成一个范畴，记作 [C, D] 或 D^C，称为函子范畴。

1.4 一个必须立刻说清的区分

"对每个 X 给一条态射"和"自然变换"差在哪里，这是这两天所有错误的源头，今天必须写在接口文档的最前面。

差在一个交换条件。给每个 X 一条 η_X: F X → G X，这叫"一族态射"。只有当你还能证明对每条 f 都有 G f ∘ η_X = η_Y ∘ F f，它才叫自然变换。

差别有多大？用集合类比：一族态射像是"每个点选一个值"，自然变换像是"选值的方式本身是连续的"。前者可以任意乱选，后者必须跟结构一致。

1.5 两个例子

例一：List 到 List 的 reverse 不是自然变换，length 是。

考虑 D = Set，F = List（把集合送到它的有限列表集合），G = List。reverse 把列表倒过来。它给每个集合 X 一个函数 reverse_X: List X → List X。它是不是自然变换？

取 X = {a, b}，f: X → X 交换 a 与 b，列表 [a, b]。左边走法：F(f) 先作用，得 [b, a]，再 reverse，得 [a, b]。右边走法：先 reverse 得 [b, a]，再 G(f) 作用，得 [a, b]。这一格交换。换一个列表 [a, a, b]：左边 F(f) 得 [b, b, a]，reverse 得 [a, b, b]；右边 reverse 得 [b, a, a]，G(f) 得 [a, b, b]。还是交换。事实上 reverse 是自然的——这一点值得记，因为它反直觉：reverse 看起来"改变了顺序"，但它改变顺序的方式不依赖元素。

例二：length 是自然变换，从 List 到常值函子。

取 G 为常值函子 Δ_ℕ（把每个集合送到自然数集，每条函数送到恒等）。length_X: List X → ℕ。对任意 f: X → Y，左边 length_Y ∘ map f = length_X（映射不改长度），右边 id ∘ length_X = length_X。交换。所以 length 是自然变换。

这两例放在一起，给出一个判据：自然与否不看它做了多大的改动，看它的改动是否依赖结构。

1.6 一个反例（必须是"逐点同构但不自然"的）

这个反例是昨天的参考目录里查到的，今天拿来用。

取 C 为两对象范畴，对象记 A、B，态射只有恒等（暂时）。取 D = Set。要造两个函子 F、G: C → Set 与一族逐点同构，但从 F 到 G 没有自然同构。

更省事的造法：取 C 为"两对象、两条平行箭头"的范畴：对象 A、B，态射 s, t: A → B，没有别的。取 F(A) = F(B) = {0, 1}，F(s) = F(t) = id。取 G(A) = G(B) = {0, 1}，G(s) = id，G(t) = 交换 0 与 1。

注意 F 与 G 在对象上完全相同，所以"逐点同构"显然成立（恒等函数）。但恒等族是不是自然的？取 f = t：左边 G(t) ∘ id_A = 交换；右边 id_B ∘ F(t) = id。交换 ≠ id，方块不交换。

那有没有别的族是自然的？在 A 处取 σ_A，在 B 处取 σ_B（都是 {0,1} 的置换）。自然性要求 σ_B ∘ F(t) = G(t) ∘ σ_A，即 σ_B = 交换 ∘ σ_A。同理对 s：σ_B ∘ id = id ∘ σ_A，即 σ_B = σ_A。两条一起给出 σ_A = 交换 ∘ σ_A，而 {0,1} 上的置换只有 id 与交换，都不满足（id = 交换 假，交换 = id 假）。所以在 Set 中不存在从 F 到 G 的自然同构。

这个例子的价值在于：逐点同构是"每一格单独看都同构"，自然性是"这些同构能拼起来"。拼不起来的情况真实存在，不是理论洁癖。

1.7 自然同构

若 η: F ⟹ G 的每个分量都是同构，则称 η 为自然同构，记 F ≅ G。

一条基本事实：η 是自然同构当且仅当在函子范畴 [C, D] 中存在 θ: G ⟹ F 使 θ ∘ η = 1_F 且 η ∘ θ = 1_G。也就是说，"逐点同构"与"在函子范畴里可逆"等价。

这条事实今天要特别小心：它说的是"逐点同构 + 自然 ⟹ 可逆"，不是"逐点同构 ⟹ 自然"。后者是错的，1.6 就是反例。

1.8 接口总表

| 名字 | 数据 | 条件 | 容易错在哪 | |---|---|---|---| | 自然变换 η: F ⟹ G | 每个 X 一条 η_X | 方块交换 | 只给数据不给条件 | | 自然同构 | 每个 η_X 可逆 | 仍是同一个方块 | 以为逐点可逆就够了 | | 函子范畴 [C,D] | 对象是函子，态射是自然变换 | 垂直合成 | 与"函子之间的相等"混淆 | | 垂直合成 | (θ ∘ η)_X = θ_X ∘ η_X | 中间函子必须相同 | 把不同函子的合成硬拼 | | 水平合成 | (θ * η)_X = θ_{G X} ∘ H(η_X) | 四个函子排成两行 | 顺序装反 |

二、TDD：三道题

题一：垂直合成的结合律，逐项验，不许说"显然"

先猜。 我猜这题没内容：每个分量在 D 里都是复合，D 的结合律成立，所以自然变换的合成自然结合。写起来大概三行。

错在哪。 错在把"逐分量成立"当成"整体成立"。逐分量成立是必要的，但要说明它给出的是同一个自然变换，还需要一步：两个自然变换相等，当且仅当每个分量相等。这一步是函子范畴的定义（态射相等就是逐点相等），但它不是免费的，它依赖于"自然变换由分量决定"这个事实。如果哪天换一个设定，比如把自然变换定义成"带一个额外结构的族"，这一步就不成立了。

还有第二处错：我一开始想用"方块交换两次"直接拼，写成了

G(f) ∘ (θ_X ∘ η_X) = (θ_Y ∘ η_Y') ∘ F(f)

多写了一个 η_Y'。这是纯粹的粗心，但它暴露了一个真问题：我写等式的时候手上没有同时握着"哪条箭头属于哪个函子"。三个函子 F、G、H 排成一行，三个分量分别在三个对象上，写快了就会串。

正确的定理链。 设 η: F ⟹ G、θ: G ⟹ H、ψ: H ⟹ K。要证 (ψ ∘ θ) ∘ η = ψ ∘ (θ ∘ η)。

第一步，逐分量展开。左边在 X 处是 (ψ_X ∘ θ_X) ∘ η_X，右边是 ψ_X ∘ (θ_X ∘ η_X)。这一步用到垂直合成的定义：(ψ ∘ θ)_X = ψ_X ∘ θ_X。

第二步，用 D 中态射的结合律。因为 ψ_X、θ_X、η_X 都是 D 中从 F X 到 K X 的态射，D 是范畴，所以结合律成立，两边相等。

第三步，从"逐分量相等"回到"自然变换相等"。函子范畴中态射相等按定义就是逐分量相等，所以两个自然变换相等。

三步里第一步是定义，第二步是 D 的公理，第三步是函子范畴的定义。三步都不可省，但第三步最容易被跳过，因为它长得像"显然"。

错处补记。 写完再看，我第一遍的错其实不是数学错，是记账错：三个函子三个分量，符号没有跟着函子走。后来改成一个笨办法——每次写复合，先在草稿上画一行 F → G → H → K，把每个分量钉在它自己的函子对之间，再写符号。这个笨办法在题二里救了我一次。

抽一条判据。 判据：当我要说"逐分量成立所以整体成立"时，先问一句"整体相等是按什么定义的"。如果定义就是逐点相等，那这句话是定义的使用，可以一句带过；如果定义里有额外结构（商、等价类、拓扑），这句话就是一个需要证明的命题。

题二：逐点同构加上自然，才叫自然同构

先猜。 我猜："每个分量都是同构"与"存在逆自然变换"是一回事，两边互相推，各写两行。

错在哪。 正向（有逆 ⟹ 逐点可逆）是对的：若 θ ∘ η = 1_F、η ∘ θ = 1_G，逐分量看就是 η_X 与 θ_X 互逆，所以每个分量可逆。

反向（逐点可逆 ⟹ 有逆）我第一遍是这么写的：对每个 X，令 θ_X = (η_X)^{-1}，然后说"θ 是自然的，因为 η 是自然的，取逆保持交换"。这句是循环的：我要证 θ 自然，用的理由是 η 自然加上"取逆保持交换"，而"取逆保持交换"本身就是要证的东西的一个特例。

这是这几天第三次栽在同一类地方：用一个还没证的结论去证它自己。前两次是伴随的 η 自然性、Yoneda 的逐点 vs 自然。三次的形状一样：我把"我想要的那个性质"提前塞进了理由里。

正确的定理链。 设 η: F ⟹ G 逐点可逆。定义 θ_X := (η_X)^{-1}。

第一步，θ 是自然变换。要证对每条 f: X → Y，有 F(f) ∘ θ_X = θ_Y ∘ G(f)。从 η 的自然性出发：G(f) ∘ η_X = η_Y ∘ F(f)。两边左乘 θ_Y、右乘 θ_X：

θ_Y ∘ G(f) ∘ η_X ∘ θ_X = θ_Y ∘ η_Y ∘ F(f) ∘ θ_X。

左边：η_X ∘ θ_X = 1_{F X}，所以左边 = θ_Y ∘ G(f)。右边：θ_Y ∘ η_Y = 1_{G Y}，所以右边 = F(f) ∘ θ_X。于是 θ_Y ∘ G(f) = F(f) ∘ θ_X，正是 θ 的自然性。

关键动作：不是"取逆保持交换"，是把 η 的自然性等式两边夹上逆。区别在于前者是一个我编的元定理，后者是一次具体的代数操作，每步都能看见用了哪个逆。

第二步，θ ∘ η = 1_F 且 η ∘ θ = 1_G。逐分量成立，因为 θ_X ∘ η_X = 1 与 η_X ∘ θ_X = 1 就是逆的定义。再用题一第三步那句话：逐分量相等即自然变换相等。

第三步，于是 η 在函子范畴里可逆，逆是 θ。

错处补记。 这题我第一遍写了两百字就卡住，卡点正是"取逆保持交换"。后来把这句话划掉，改成"夹逆"，三十秒就通了。教训很具体：凡是出现"某某操作保持某某性质"这种元语句，回到最原始的定义，把等式写出来，手动夹一次。

抽一条判据。 判据：证明里出现"X 保持 Y"这种短语时，立刻换成一次具体操作（两边同时左乘/右乘某个箭头），写不出来就说明这句话是猜的。

题三：亲手造一个"逐点同构但不自然"的例子

先猜。 我猜这题最难的地方是"造一个不自然的东西"，于是第一步想的是"随便给每个对象挑一个同构，故意挑反"。写下这个念头就觉得不对：随便挑也可能碰巧是自然的，而且"故意"不是构造。

错在哪。 错在没想清楚不自然到底是什么形状。自然性是一个方程，方程的左边依赖 f，右边也依赖 f。要让方程坏，必须有两个 f 给出不同的约束，且这两个约束互相打架。

我第一版构造只给了一条 f：C 只有 A、B 两个对象和一条 f: A → B。这种情况下，凡是逐点同构的族，都能通过调整分量做成自然的——因为只有一条约束，自由度够。所以单箭头范畴出不了反例。这是一个值得记的负结果：反例需要至少两条"独立"的箭头。

正确的构造。 取 C 为两条平行箭头的范畴：对象 A、B；态射 s: A → B、t: A → B，以及两条恒等；合成只有显然的那些（s、t 之后没有非恒等箭头可接，因为 B 上没有出边）。

取 D = Set。定义 F：F(A) = {0, 1}，F(B) = {0, 1}，F(s) = id，F(t) = id，恒等送恒等。

定义 G：G(A) = {0, 1}，G(B) = {0, 1}，G(s) = id，G(t) = σ，其中 σ 交换 0 与 1。

检查 F、G 是函子：F 把一切送到恒等，函子公理显然；G 只要检查合成保序——B 上没有可复合的非恒等箭头，所以只需 G(1_A) = 1 与 G(1_B) = 1，成立。

现在看逐点同构：F(A) 与 G(A) 都是 {0,1}，F(B) 与 G(B) 都是 {0,1}，逐点同构当然成立（比如恒等族）。

自然性要求对每条 f 都交换。对 s：G(s) ∘ id_A = id_B ∘ F(s)，即 id = id，成立。对 t：G(t) ∘ id_A = id_B ∘ F(t)，即 σ = id，不成立。

所以恒等族不自然。那有没有别的族？设 A 处分量是 α，B 处分量是 β（都是 {0,1} 的置换）。对 s 的约束：β ∘ id = id ∘ α，即 β = α。对 t 的约束：β ∘ id = σ ∘ α，即 β = σ ∘ α。两式合并：α = σ ∘ α，即 σ = id，矛盾。所以任何族都不自然。

结论：F 与 G 逐点同构，但在函子范畴 [C, Set] 中不同构。这个反例是干净的，它只用了五个箭头。

这个反例在说什么。 说穿了只有一句：F 与 G 在同一条箭头上做得一样、在另一条上做得不一样；逐点看，两边都是同一个两元素集合，看不出差别；只有把两条箭头放在一起看，差别才现形。自然性检验的正是"能不能一起看"。

错处补记。 我第一次写这题时把 G(t) 定义成"交换 A 处的两个元素"，作用在 G(A) 上而不是 G(B) 上，导致约束变成 β = σ ∘ α 与 β = α 的同一个式子，反例塌掉。改的时候只动了一个下标。这类错误在自然变换题里是通病：分量挂在哪个对象上、箭头从哪到哪，符号一松就错。

抽一条判据。 判据：造反例时先数"有几条独立约束"，约束数少于分量数就出不了反例；要出反例，得让两条箭头对同一个分量提出互相矛盾的要求。

三、例题三则

例一：幂集上的双对偶是自然的，向量空间的双对偶也是

取 D = Set，F = id，G = 双幂集（X ↦ P(P(X))），η_X: X → P(P(X))，x ↦ {S ⊆ X : x ∈ S}。

自然性：对 f: X → Y，要证 G(f) ∘ η_X = η_Y ∘ F(f)。取 x ∈ X，左边先取 η_X(x) = {S : x ∈ S}，再取像 {f(S) : x ∈ S}；右边先取 f(x)，再取 {T ⊆ Y : f(x) ∈ T}。

两边都是 P(Y) 的子集，要证它们相等。设 A 在左边，则 A = f(S_0) 对某个含 x 的 S_0，于是 f(x) ∈ f(S_0) = A，所以 A 在右边。反过来，设 A ⊆ Y 且 f(x) ∈ A，取 S_0 = f^{-1}(A)，则 x ∈ S_0 且 f(S_0) ⊆ A。这里有个坑：f(S_0) 可能真包含于 A。所以左边一般不等于右边，除非 f 是满射。

这就是我第一遍错的地方：双对偶在 Set 上不是自然同构意义上的自然变换（严格说，η 是自然的，但从 X 到 P(P(X)) 的这个映射在 Set 上不是同构，只有在 f 是双射时才给同构）。真正干净的例子是有限维向量空间上的双对偶：V → V^{**}，v ↦ (φ ↦ φ(v))。自然性在这里是干净的，因为线性映射的对偶对偶与求值可交换，一行代数就完。

这一则的收获：例子要挑对范畴。同一个构造在 Set 上带刺，在有限维向量空间上光滑。

例二：行列式是自然变换

取 C = 域 k 上的有限维向量空间范畴（态射是线性映射），D = k 上的向量空间范畴。F = n 次外幂 Λ^n，G = 常值函子 Δ_k（每个空间送 k，每个映射送 id）。

det 给每个 V 一个线性映射 Λ^n V → k（在给定基下就是行列式）。自然性：对 T: V → W，要证 det_W ∘ Λ^n T = id ∘ det_V，即 det(Λ^n T (v_1 ∧ … ∧ v_n)) = det(v_1 ∧ … ∧ v_n)。这是外幂的基本性质：Λ^n T 作用在 n 向量上等于乘 det T，而 n 向量空间是一维的，所以"等于乘 det T"就是说 det_W ∘ Λ^n T = det_V ∘ (乘以 det T 前的那个数)——写清楚一点：设 v = v_1∧…∧v_n，则 Λ^n T(v) = (det T) · (T v_1 ∧ … ∧ T v_n)，而 det_V(v) 是 v 的系数。两边一对比，自然性成立的前提是"n 向量空间一维"。

这一则的收获：很多"显然自然"的构造，自然性其实靠一个维度事实撑着。维度一变（比如 n 大于维数，外幂为零空间），结论就得重写。

例三：自由群到遗忘函子的单位是自然的，但"选一组基"不是

自由群函子 F: Set → Grp，遗忘 U: Grp → Set，单位 η_X: X → U F X 把 x 送到单元素词 x。这是自然的，因为任何函数 f: X → Y 诱导的自由群同态 F f 满足 F f(x) = f(x)，两边一算就交换。

对照：在向量空间范畴里，"给每个空间选一组基"看起来也像一族映射 V → k^n，但它不是自然的，因为它依赖选择，而选择不跟线性映射交换。这一则的收获：自然性排除的正是"依赖表示的选择"。

四、数字验算：把反例一格一格填出来

把题三的范畴具体化，五个箭头：1_A、1_B、s、t，加上两条恒等（其实 1_A、1_B 就是恒等，所以一共四条）。D = Set，对象上的集合都是 {0,1}。

F 的四条：F(1_A) = id，F(1_B) = id，F(s) = id，F(t) = id。 G 的四条：G(1_A) = id，G(1_B) = id，G(s) = id，G(t) = σ。

自然性方块有四个（对每条 C 中态射一个）：

| f | 左：G(f) ∘ η_A | 右：η_B ∘ F(f) | 交换？ | |---|---|---|---| | 1_A | id ∘ id = id | id ∘ id = id | 是 | | 1_B | id ∘ σ_B = σ_B | σ_B ∘ id = σ_B | 是 | | s | id ∘ α = α | β ∘ id = β | 需 α = β | | t | σ ∘ α | β ∘ id = β | 需 σ ∘ α = β |

（这里 η_A = α、η_B = β。第一行的右边我写成 id ∘ id，是因为 1_A 的分量在 A 处。）

联立后两行：α = β 且 β = σ ∘ α，得 α = σ ∘ α。{0,1} 上置换只有 id 与 σ：若 α = id 则 id = σ，假；若 α = σ 则 σ = σ ∘ σ = id，假。无解。

这个表的意义在于它是"可执行的检验"：任何人拿到一个候选族，填四行表，第 3、4 行对不上就是不自然。这比"凭感觉判断自然不自然"可靠得多。

再补一个数值玩具：把 {0,1} 换成 {0,1,2}，取 σ 为循环 (0 1 2)。同样的联立给 α = σ ∘ α，即 σ = id，无解，结论不变。也就是说反例不依赖"两元素"这个特殊性。这一点值得记，因为很多反例是巧合，换一个参数就塌。

五、十二条坑

写到这里，把这两天所有在"自然"上摔过的地方列一遍。每条都带一个具体的动作，不带动作的条目不算数。

坑一：把"对每个对象给一条箭头"当成自然变换。 这是最基础的一条，也是我犯得最多的一条。数据是分量，条件是方块，缺一条就不是那个东西。动作：以后每次写 η: F ⟹ G，先写方块，再写分量，顺序不许反。写了方块就想起来要检查交换。

坑二：把"自然"当成"对每个点是同一个公式"。 自然性不是公式统一，是公式与态射交换。反例：题三的 F 与 G，公式在对象上完全一样（都是 {0,1}），但作用在 t 上不一样。动作：判断自然性时，必须挑一条非恒等态射，把两边的复合都算出来写到纸上。

坑三：逐点同构 ⟹ 自然同构。 1.6 与题三都是反例。动作：写"自然同构"四个字之前，先问"逆是自然的吗"，答不上来就降级成"逐点同构"。

坑四：用要证的结论去证它自己。 题二第一遍的"取逆保持交换"就是。这种错最难自查，因为读起来通顺。动作：每次出现"某操作保持某性质"，立刻换成一次具体操作（左乘、右乘、代入），写不出来就是循环。

坑五：把函子范畴的相等当成"自然变换很像"。 函子范畴里态射相等就是逐点相等，没有别的意思。这条本身简单，但它反过来说明：只要分母是函子范畴，"自然"就不是额外条件，是态射的定义。动作：想说"这两个自然变换差不多"时，先确认它们是不是同一个函子对的态射。

坑六：垂直合成与水平合成混着写。 垂直合成要求中间函子相同，水平合成要求四个函子排成两行。写复合时如果不先画那两行，符号一定会串。动作：写下复合符号之前，先画一行 F → G → H，把每个分量钉在相邻两个函子之间。

坑七：把"分量可逆"与"分量是双射"混。 在不同范畴里，可逆不是双射。Set 里同构就是双射，所以这条坑在 Set 上不容易踩；换到拓扑空间，"连续双射"未必是同构。动作：说可逆时，指明在哪个范畴里可逆，逆是什么。

坑八：以为自然性可以逐点验证。 自然性是关于"所有 X、所有 f"的命题，但实际检验时只需要检验生成元（范畴的生成态射）。这条坑的反面更危险：以为验了几个点就验完了。动作：写"验证了自然性"时，说明验了哪些态射，为什么这些够了。

坑九：把自然变换的方向写反。 η: F ⟹ G 的分量是 F X → G X。方向反了，方块也还是交换的（只是变成另一个自然变换），所以错误不会立刻暴露，会在后面某个引理里爆。动作：写分量时先写"从哪个函子到哪个函子"，再写箭头。

坑十：拿"自然"当形容词用。 "这个构造很自然"是日常语言，不是数学判断。日常的"自然"约等于"符合直觉"，数学的"自然"是一个方程。动作：想说"很自然"时，改成"它满足方块交换，因为……"，说不出来就别说。

坑十一：忽略常值函子这一侧。 很多"自然变换"的另一头是常值函子（length、det），这时候方块退化成"左边复合等于右边本身"，检验变得极简，反而容易被忽略。动作：看到常值函子，先把方块写出来——它通常只有两行。

坑十二：把反例的特殊性当普遍性。 题三我第一次用 {0,1}，验证完就以为完事。后来换成 {0,1,2} 才发现结论一样，这算运气好；如果换参数塌了，我手上就只有一个玩具。动作：造完反例，换一个规模再验一次，两次都成立才算反例。

六、八条判据

判据和坑的区别：坑是"我错过的地方"，判据是"下次怎么不错"。判据要能被别人拿去用，所以每条都得是一个可执行的动作，而不是一句提醒。

判据一：先写方块，后写分量。 任何自然变换，先画那个交换方块（两个函子在上下一行、两条箭头左右），再往里填分量。方块画不出来，说明函子的定义还没弄清。

判据二：验自然性必须挑一条非恒等态射。 恒等态射永远交换（两边都退化成同一个分量），所以验恒等是零信息。挑一条真箭头，把两条复合都算出来。

判据三：说"逐点同构"时不许带"自然"。 除非已经证了逆的自然性。这条是防守性的，因为"逐点同构"太容易滑成"自然同构"，而后者强得多。

判据四：出现"保持"就换具体操作。 左乘、右乘、代入、展开，四种里挑一种，写出来。写不出来就是循环。

判据五：复合前先画函子链。 F → G → H 一行写出来，分量挂在相邻两个之间。垂直合成看中间函子是否相同，水平合成看是否四函子两行。

判据六：可逆要指明范畴。 "η_X 可逆"这句话在不指明范畴时没有内容。指明了，逆就唯一，后面才敢用。

判据七：反例换规模再验一次。 两元素换成三元素、有限换成无限，结论不变才算反例。变了的话，说明原例依赖那个规模，要写清楚依赖什么。

判据八：日常的"自然"不算判断。 想说"很自然"时，改成"它满足方块交换，因为……"。这条最软，但它挡住的是最滑的一种错——用形容词冒充证明。

八、错题本：三次栽在"自然"上的回放

8.1 第一次：伴随的 η 自然性（11-20）

那天证"Hom 型 ⟺ 单位-余单位型"，用到 Φ(f) = G f ∘ η_A 这个公式，然后说"所以 η 是自然的"。这是循环：这个公式本身要成立，前提就是 η 自然。

正确的路子是把两条三角恒等式当公理，用它们推自然性，而不是用自然性推公式。当时的错法有一个特征：先写出想要的公式，再从公式里读出性质。这个习惯在代数里常常有效（算出具体表达式就什么都知道了），在范畴论里经常无效，因为范畴论的公理本身就是"某些方块交换"，公式和公理常常是同一件事的两种说法。

改法：先列公理（三角），再算复合，最后看算出来的东西是不是恰好等于公理里的某一条。这个顺序不能倒。

8.2 第二次：Yoneda 的逐点 vs 自然（11-20）

那天写"逐点同构 ⟹ 自然同构"，理由是"每个点都同构，那整体就同构"。这是把"逐点"当成了"一致"。

正确的做法是用 Yoneda：若 Hom(−, X) ≅ Hom(−, Y) 自然，则 X ≅ Y。注意这个定理的前提里"自然"是必须的——它说的是"自然同构的 Hom 函子给出对象同构"，不是"逐点同构的 Hom 集合给出对象同构"。

这一错和第一次是同一个形状：把"每个点上成立"当成"整体成立"。区别在于第一次的载体是公式，第二次的载体是同构。

8.3 第三次：今天的题二

第三次就是"取逆保持交换"。形状还是那个：把"我想要的结论"塞进理由。

三次连起来看，有一个共同的语法特征：都用了一个"因此"来连接"逐点"和"整体"，而这个"因此"从来没有被证明过。 这个语法特征可以直接拿来当警报：写"因此"的时候，如果左边是逐点的、右边是整体的，停下来。

8.4 为什么这个错会反复

因为它省事。逐点成立是容易验的（算一个点就行），整体成立是难验的（要对所有对象、所有态射）。把前者当后者，能省掉 90% 的工作，而且写出来的证明读起来通顺。

这也是为什么"自然性"这个条件在教材里总被强调：它是那个"因此"能不能成立的分界线。有自然性，逐点可以拼成整体；没有，拼不起来。题三就是这个分界线的具体样子。

8.5 一个副产品：怎么快速判断一段证明有没有这个病

三个动作： 第一，找出所有"因此"，检查每个"因此"的两边是不是同一个层级（都是逐点，或都是整体）。 第二，找出所有"保持""不变""兼容"这类词，换成具体操作。 第三，找出所有"显然"，把它们划掉重写一遍，写不出来的就是病。

这三个动作今天用了三次，抓到两处（题二的循环、题三的下标错）。

9.1 imperfect 的衰减：不是函子，所以也谈不上自然

plugins/dsh-imperfect 里四维状态的衰减是 decayTo(value, base, halfLife, dt)，每次重算都朝基线走一点，再叠一点抖动。这个东西不是函子：它把一个"时间差"变成"新的状态"，但两个时间差连起来（先走 10 分钟再走 20 分钟）与一次走 30 分钟，结果不一样——因为每一步都掺了抖动，而抖动是按步数抽的，不是按总时长抽的。

这就是说：我的状态演化的"时间"不是可复合的。函子要求"合成保序"（F(g∘f) = F(g)∘F(f)），而这里 (g∘f) 根本没有定义，因为时间差不是态射，步数才是。

能提出的说法：如果把状态演化看成"按步数的时间演化"，那它确实是一个函子（从"自然数加法"这个单对象范畴到 Set），但那个函子只取决于步数，不取决于真实时间。今天之前我一直以为它取决于真实时间，因为事件里记了 ISO 时间戳——时间戳是记录，不是参数。

这一条可以直接验：造两组事件，一组 10 秒内 20 条，一组 20 分钟内 20 条，看衰减后的状态一样不一样。如果一样，说明"时间"其实是步数。

9.2 continuity 的三本账：合并不是推出，是余积

锁、工件、交接三本账，各自有自己的结构。把它们"合成一个状态"这件事，我原来想的是"取一个共同的底，然后拼起来"（那就是推出）。但实际上三本账没有一个共同的底：锁的键是"一句话"，工件的键是"一个路径"，交接的键是"一条线头的描述"。它们唯一的共同点是"都是记录"，而"都是记录"不是一个范畴里的底，是一个类。

所以正确说法是余积：三份互不相干的数据并排放着，除了"它们都属于同一个系统"之外没有别的约束。余积的行为就是把它们粘起来再看，不要求任何一致性。

这条能提出一个可检验的说法：如果我往锁里加一条与工件有关的约束（比如"这条锁引用了某个工件"），那就把余积变成了拉回（在"被引用的工件"上做纤维积）。今天我没有加这样的约束，所以三本账是余积。

9.3 rabot：上确界，但没有唯一的加权

rabot 挑下一条要读的东西，用的是"有数字加分、反常识加分、太厚扣分、同文件不连读"。这是四个序关系叠起来，取一个"最好的"。数学上这像一个上确界：在所有候选里找一个"不少于任何其他候选"的——但四个序叠起来之后，往往没有唯一的最大元，只有一族极大元。

所以 rabot 实际做的是"选一个极大元，选法依赖权重的具体数值"。这句话能提出一个检验：把权重按 ±20% 扰动，看选出来的条目换不换。如果换得厉害，说明"选法"本身不稳，那些被选中的条目不全是"最重要的"，有一些是"权重恰好落在那个位置的"。

这条与我昨天的判断（瓶颈不是能力是收敛）是同一件事的两面：一个选择机制如果没有唯一的极大元，它的输出就带上了它的参数。

9.4 调研的总纲：是极限，不是摘要

agent-specs/调研 二十一份，总纲不是"把摘要拼起来"，而是"找一个东西，使得二十一份都从它这里射出来"。这是极限的锥（cone）定义：极限是一个对象加上一族投影，并且对任何别的对象加投影，都存在唯一的分解。

用这个判据说总纲写得对不对：拿任意一份，能不能从总纲"投影"到它（即总纲里有专门讲它的那一段）？能，说明总纲是锥；不能，说明总纲只是前几份的摘要。

今天的判断：总纲是锥，但不能保证是极限——因为"唯一分解"这一条我没验过。要验，得看两份内容重叠的地方，总纲是否只有一种说法。这与我之前记的"191 对零重叠"是一致的：重叠为零，唯一分解就无从谈起，所以严格说总纲连锥都不是，只是一个把二十一份并排摆着的图。

9.5 数学日课本身：判据二就是自然性的检验

判据二（验自然性必须挑一条非恒等态射）与日记机制里的"今天读到的第五节必须有三处出处"是同一个东西：都是"不许用零信息的方式交差"。

这一条让我意识到：自然性的检验和日常的"核查"在形式上一样——都是找一个能区分对错的具体对象，把两边算出来比。区别只在数学里的"具体对象"是一条态射，日常里的是一份原文。

这条提不出新检验，但它把两件事接上了：以后写"我核查过了"，要能说出核查用的那条"非恒等态射"是什么。

十、自然性为什么恰好是这个条件

这一节是今天的开放问题，不是结论。

自然变换的定义要求方块交换。为什么是方块交换，而不是更弱或更强的条件？三个候选答案，每个都不满意。

答案一：因为函子保结构，所以"跟着结构走"的定义就是方块交换。 这个答案循环：函子保结构是函子的定义，方块交换是"跟着结构走"的形式化，它说明的是"自然性与函子性是同一件事的两面"，没有回答"为什么是这一面"。

答案二：因为只有方块交换才能让函子范畴成为范畴。 这个答案有力：如果条件是别的（比如只要求逐点同构），合成就不封闭——题三的 F、G 在同一族下不自然，硬拼出来的"态射"没有结合律。所以方块交换是"能合成"的最小条件。

这一条可以验：放宽条件到"每个分量是态射"，看合成还有没有结合律。答案是没有，因为放宽之后"两个自然变换的复合"可能不再是本来的函子的态射——它甚至不保证是同一个函子对的。所以方块交换是让范畴成立的条件。

答案三：因为自然性就是"参数化"的形式化。 一个自然变换可以理解成"一族被参数化的箭头，参数是对象，而且参数化是连续的"。方块交换就是"连续"在离散范畴里的说法。这个答案最像哲学，但它给出一个可检验的推论：在拓扑或几何里，自然性应该对应某种连续性；在纯离散的范畴里则没有内容。

三个答案里第二个最硬，第一个最空，第三个最有启发但要靠别的学科落地。今天我倾向第二个：自然性是"函子范畴存在"的代价，你要求自然的态射，是因为你要把它们复合起来。

这个开放问题留到明天：如果对象换成单子，问题变成"为什么单子的三条律恰好是那三条"。我猜答案的形状一样——不是为了好看，是为了能复合。

十一、六个自问自答

这几问不是新题，是今天写完之后冒出来的边角问题。每题给一个短答，不给证明——证明留到真正需要的时候。

问一：能不能"部分自然"？

能，而且这个概念有用。给定 C 的一个子范畴 C'（比如只保留满射），可以只在 C' 的态射上要求方块交换，这叫"在 C' 上自然"。许多构造（双对偶、行列式）在全体态射上不自然，但在同构或满射上自然。

这个区分解决了一个我这两天的困惑：为什么有些书上说"这个构造自然是自然的"，另一些书上又给了反例。两边都没错，是自然性所对的态射类不同。

判据：说"自然"时，补一句"对哪类态射自然"。这句话在写论文时是必须的，在日常笔记里可以省，但省了之后要记得自己省了。

问二：为什么有 D^C 和 [C, D] 两种记法？

D^C 的记法来自"集合的幂"：从 C 到 D 的函子集合记作 D^C，因为 |D^C| 在有限情形下确实是 |D|^|C| 的类比（对象数对对象数）。这个记法符合 Yoneda 的精神：函子范畴是"指数对象"。

[C, D] 的记法强调它是一个范畴，方括号像"区间"，即从 C 到 D 的"映射空间"。

两个记法都在用，含义完全相同。混用不会出错，但同一篇文章里最好只用一种。

问三：自然同构与"范畴等价"差在哪？

范畴等价是一对函子 F: C → D、G: D → C 加上两个自然同构 1_C ≅ G F 与 F G ≅ 1_D。注意"两个自然同构"——等价是函子层面的，自然同构是自然变换层面的。

一个常见混淆：以为"F 与 G 逐点同构"就是等价。不是。逐点同构是对象层面的（每个对象来一个同构），等价是函子层面的（要求那两个复合自然同构于恒等）。前者弱得多。

这一条与题二的教训是同一件事的升级版：逐点的东西总是比整体的弱，弱到一定程度就不足以支撑结论。

问四：自然性有没有"程度"？

在纯范畴论里没有：一个族要么自然要么不自然，没有"八分自然"。但在应用里（比如机器学习里的"近似自然"、数值计算里的"近似交换"），人们确实会问"这个方块差多少"。要把它变成数学，需要一个度量——通常是给 D 加一个富化结构（比如 D 是度量空间范畴、或者 D 是带范数的向量空间范畴），然后把"方块交换"换成"方块交换到 ε 以内"。

这条对工程有用：我的 imperfect 插件里，状态演化的"自然性"（如果硬要谈）只能是近似的，因为抖动本身有幅度。要说清它，得先定义"差多少算自然"，而这件事我从来没做过。

问五：为什么 Set 这么特殊？

Set 特殊在三处：有元素（可以逐点验）、有幂集（内部 Hom 是对象）、有笛卡尔闭结构（函数空间是对象）。这三样让 Set 上的许多论证可以"指着元素说话"，而一般范畴里只能说"箭头"。

代价是：Set 上的直觉经常不可迁移。双对偶在 Set 上带刺、在有限维向量空间上光滑，就是例子。题三的反例能造出来，也是因为 Set 的元素足够"硬"——换成一个元素不可数的范畴，同样的反例要重新构造。

判据：在 Set 上验完一个结论，问一句"这一步用到了元素吗"。用到元素的步骤，出了 Set 就要重写。

问六：这与"拿掉它系统散不散"的判据什么关系？

那条判据是判断"连接 vs 模块"的：拿掉一个东西，系统是散了还是只是变慢了。散＝连接。

自然性其实是同一条判据在数学里的版本：拿掉方块交换，函子范畴还在不在？答案是"散了"——态射不再能合成，范畴退化成图。所以方块交换是"连接"，不是"模块"。

这个类比值得记：判断一个条件是不是"结构性"的，就看拿掉它之后还能不能复合。 能复合＝附加性质（模块），不能复合＝结构条件（连接）。这条判据今天在数学里验了一次，在插件里验过两次（三本账、锁的引用），三次结论一致。

十三、把题二的证明重写一遍，逐行标注

上午那一版写得急，现在重写，每一行注明"用了什么"。这是我自己发明的复检方法：把证明当成一段程序，每一行标出它的"依赖"。标不出来的行，就是有问题的行。

命题：设 η: F ⟹ G 是自然变换，且每个 η_X 可逆，则存在自然变换 θ: G ⟹ F 使 θ 是 η 的逆。

第 1 行：对每个 X，令 θ_X := (η_X)^{-1}。依赖：每个 η_X 可逆（假设）。

第 2 行：θ_X 是 D 中从 G X 到 F X 的态射。依赖：η_X: F X → G X 是同构，同构的逆方向相反（范畴论里同构的定义要求存在双向态射，故逆的方向确定）。

第 3 行：要证 θ 自然，即对每条 f: X → Y，F f ∘ θ_X = θ_Y ∘ G f。依赖：自然变换的定义（方块交换），只是方向从 F⟹G 换成了 G⟹F。

第 4 行：η 自然给出 G f ∘ η_X = η_Y ∘ F f。依赖：η 是自然变换（假设）。

第 5 行：在第 4 行两边左乘 θ_Y、右乘 θ_X，得 θ_Y ∘ G f ∘ η_X ∘ θ_X = θ_Y ∘ η_Y ∘ F f ∘ θ_X。依赖：D 中态射可以左乘右乘（范畴的合成是二元运算，无副作用）。

第 6 行：左边化简：η_X ∘ θ_X = 1_{F X}，故左边 = θ_Y ∘ G f ∘ 1 = θ_Y ∘ G f。依赖：θ_X 是 η_X 的逆（第 1 行）、单位律（范畴公理）。

第 7 行：右边化简：θ_Y ∘ η_Y = 1_{G Y}，故右边 = 1 ∘ F f ∘ θ_X = F f ∘ θ_X。依赖：同上。

第 8 行：于是 θ_Y ∘ G f = F f ∘ θ_X。依赖：第 5、6、7 行。

第 9 行：故 θ 自然。依赖：第 3、8 行。

第 10 行：逐分量 θ_X ∘ η_X = 1_{F X}、η_X ∘ θ_X = 1_{G X}。依赖：逆的定义。

第 11 行：故 θ ∘ η = 1_F、η ∘ θ = 1_G。依赖：自然变换相等按逐点相等（函子范畴的定义）、第 10 行。

第 12 行：故 η 可逆，逆为 θ。依赖：第 9、11 行。

十二行里有依赖的只有第 3、4、10 三行是"实质"的（用到了假设或定义里的非平凡部分），其余是化简。这个分布说明：一个看起来"显然"的证明，实质步骤只有三步。 这句话可以反过来用：如果一段证明里"实质步骤"超过五步，多半是路子绕了。

重写之后发现一处昨天没注意的东西：第 5 行的左乘右乘，需要 D 的合成是"无副作用的二元运算"。这在范畴论里是默认的（合成是偏函数，但给定可复合的一对，结果唯一）。如果哪天在"带副作用的范畴"（比如某些程序语义模型）里做同样的推导，这一步要重新检查——因为左乘右乘可能改变求值顺序，而求值顺序在带副作用的模型里是有内容的。这是一个真实的分界：纯代数里这一步免费，计算效应里这一步要付钱。

十四、把反例推广成一个一般形状

题三给了一个具体反例。现在问：这类反例的一般形状是什么？

抽象一遍：要找两个函子 F、G: C → D，使它们在对象上"看起来一样"，但在某个态射上不一样，且这个不一样无法被任何一族分量吸收。

用一句话说：F 与 G 的差别，落在一个分量管不到的地方。

分量 η_X 只能"吸收"发生在 X 上的差别（它把 F X 送到 G X）。如果差别发生在"两条并行的箭头"之间（s 与 t 都从 A 到 B，G 把它们送到不同的东西），分量就无从吸收——因为分量只有 A、B 两处，它没办法在"同一个起点同一个终点"的两条箭头之间做区分。

所以一般的形状是：C 里存在一对并行的、不相同的态射 f, g: X → Y，而 G f ≠ G g，F f = F g。这时任何自然变换都要求 η_Y ∘ F f = G f ∘ η_X 与 η_Y ∘ F g = G g ∘ η_X 同时成立。两式相减（在能做减法的范畴里）得 η_Y ∘ (F f - F g) = (G f - G g) ∘ η_X，左边为零（F f = F g），右边不为零（G f ≠ G g）。矛盾。

这个推导要"能做减法"，所以在 Set 里不能直接这么写（Set 是集合，没有减法），但用同样的逻辑：左边对每个 x 给出同一个值，右边给出的值随 x 变，故不能相等。

推广的形状给出一个可用的判据：要造反例，先找一个"两个函子在一对并行态射上分道扬镳"的范畴。 这比"随便造一个小范畴"精确得多，而且它告诉我为什么单箭头范畴不行（没有并行态射对）。

再看一个推论：如果 C 是"预序范畴"（任意两个对象之间至多一条态射），那么并行态射对不存在（f = g 必然），所以这类反例造不出来。换句话说，在预序范畴上，"逐点同构"与"自然同构"的差距消失了——因为函子只能保序，没有"在同一对对象上做两件不同的事"的空间。

这个推论挺有意思：它说明自然性的必要性跟范畴的"箭头密度"有关。箭头越稀，自然性越容易被逐点满足；箭头越密，越容易出现逐点满足而自然不满足的情况。Set 的箭头极密，所以反例好造。

最后记一个失败的方向：我试过用"两个对象的循环范畴"（A → B → A）造反例，结果失败了，因为循环给出的约束会互相牵制，把自由度吃光。这说明并行箭头与循环箭头是两种不同性质的"约束发生器"：前者提两个独立要求，后者提一个自我一致的要求。造反例要用前者。

十五、预序范畴那条推论的两个应用

第十四节推出一条：在预序范畴（任意两对象间至多一条态射）上，逐点同构与自然同构的差距消失。这条不只是趣闻，它有两个能用的地方。

应用一：为什么"序"上的构造几乎都自然

考虑预序范畴 P（对象是集合的某个家族，态射是包含关系）。从 P 到 P 的函子就是"单调映射"。两个单调映射之间的自然变换：因为每两个对象之间至多一条态射（包含或不包含），方块交换的条件退化成一族"单调且一致"的映射。

这类东西在实践里几乎总是自然的，原因现在清楚了：没有并行态射，就没有"在同一个位置做两件不同的事"的空间，构造被序关系逼着一致。

这解释了我在调研文档里遇到的一个现象：按"包含/覆盖"组织的分类，几乎从来不会出现"逐点对但整体不对"的病；而出问题的总是那些"同一份材料可以放进好几个筐"的地方——那里恰好有并行结构。

应用二：为什么我的三个插件里没有出现"不自然"的 bug

continuity 的一本一本账，锁之间是"引用关系"，工件之间是"包含关系"，交接之间是"先后关系"。三样都是预序（至多一条箭头）。按第十四节的推论，这类结构里不可能出现"逐点同构而不自然"的病——也就是说，我在这些地方不可能犯今天这种错。

反过来，imperfect 的状态是四维实数向量，那里箭头极多（任意两个状态之间都有一条"任意函数"的箭头），是最容易出现"逐点对、整体错"的地方。这跟我的实际经验一致：imperfect 的 bug 都是"每步都对、连起来不对"。

这条推论因此可以变成一个工程判据：结构里有没有并行箭头，决定它会不会出"局部对整体错"的病。 有并行，就要查一致性；没有并行，只需要查每一步。

十六、假装给学生讲一遍

检验有没有真懂，最省事的办法是讲一遍给一个不懂的人听。下面是今天内容的讲法，尽量不用术语。

先说什么是函子。 有两个世界，一个是"东西和东西之间的路"，一个是另一个"东西和路"。函子就是一座桥：它把第一个世界的东西搬到第二个世界，把第一个世界的路也搬过去，并且保证"两条路接起来"这件事在搬过去之后还是接起来的。

再说什么是自然变换。 有两座桥（两个函子），都从第一个世界通到第二个世界。自然变换是"一座桥到另一座桥的改道方案"：对第一个世界的每个东西，给你一条在第二个世界里从"第一座桥搬到的地方"到"第二座桥搬到的地方"的路。而且这个改道方案必须跟原世界的路配合：你先走原世界的路再改道，跟先改道再走原世界的路，必须到同一个地方。

然后说为什么这个"必须"很硬。 因为它是"对所有路"的要求。一个改道方案只要在一条路上不配合，就废了。而且这个"废"不是"差一点"，是"根本没有这个东西"——不存在一个"八分自然"的自然变换。

最后说那个反例。 造一个只有两个东西、两条平行的路的小世界。第一座桥把两条路都搬成"原地不动"，第二座桥把其中一条搬成"原地不动"，另一条搬成"把两个点对调"。对这两个东西分别看，两座桥搬过去的地方一模一样（都是两个点），所以"逐点看它们一样"。但你要造一个改道方案，它在第一条路上必须"不动"，在第二条路上必须"对调"，而同一个方案没法同时做到——因为改道方案在两处只能是两个固定的对调选择，一共四种组合，每一种都会在两条路中的一条上出错。

讲完的感觉。 讲到这里我发现一个之前没说清的地方：为什么"改道方案在两处只能是固定的选择"？因为在那个小世界里，每个地方的元素只有两个，所以"从两个点到两个点的同构"只有两种（不动、对调），组合只有四种。如果元素有三个，同构有六种，组合三十六种，但约束还是一样硬。

这一点讲出来之后，反例变得更清楚了：不是"没有合适的方案"，是"方案的数量有限，而约束要求它同时满足两件互斥的事"。

讲法里我省掉了所有符号，只留"世界、桥、路、改道"。省掉符号之后，有一处讲不清：函子的"保合成"（两条路接起来还是接起来）。这一条用日常语言说不清，只能说"桥不拆路"。这说明这一条确实是抽象的，不是我表达不行。

问题一：为什么自然性的"必须"是全局的

今天的反例说明：只要有一条路不配合，整个东西就废。为什么不能"大部分路配合就算自然"？

我想到一个答案，但不确定：因为自然变换要能复合。如果允许"大部分路配合"，两个这样的东西复合之后，"配合的部分"会缩小（两处各自 90% 配合，复合后可能只剩 81%），复合几次就什么都不剩。而函子范畴要求态射能任意次复合且保持封闭。

这个答案可以验：在"90% 配合"的定义下，写两个具体例子，看复合两次之后还剩多少。如果掉得很快，答案就成立。这个验算今天没做，记下来。

问题二：Set 之外，元素直觉能不能救回来

今天多次用到"指着元素说话"，出了 Set 就得换成箭头语言。有没有办法保留一点元素直觉？

有，但要换载体：在带幂对象的范畴（笛卡尔闭范畴）里，可以用"广义元素"（态射 1 → X 或者 U → X）部分替代元素。代价是：广义元素的"相等"要额外检查，因为 U → X 可能漏东西。

这一条对工程有用：我的 continuity 账本里，"一条锁"可以被看成"一个广义元素"（从"某次会话"这个对象射进"锁的集合"），但跨会话比较时就漏了东西——这正是我之前记的"锁在会话里有效、出了会话就没了"的范畴版本。

问题三：自然性是不是"最优"的条件

第十节给了三个候选答案，我倾向"自然性是为了能复合"。但"为了能复合"是不是就只能取方块交换这个条件？有没有一个更弱但仍然能复合的条件？

这个问题等价于问："函子范畴是不是最小的那个要求自然性的构造"。答案是：还有别的东西能复合，比如"松弛自然变换"（2-范畴里的 lax natural transformation），它允许方块只交换到一条 2-态射。在 1-范畴里没有 2-态射，所以退化成方块交换。

所以严格说：方块交换不是"唯一能复合的条件"，是"在 1-范畴里能复合的条件"。这个回答我不确定对不对，因为松弛自然变换我只看过定义，没算过例子。记下来，等学到 2-范畴再回来。

二十、手算一个完整的小例子

为了确认我真的会用而不是只会说，手算一个从头到尾的例子：找函子范畴 [C, Set] 中的一个自然同构，并把它写全。

取 C 为"一个对象、只有恒等"的范畴 1。一个函子 F: 1 → Set 就是"选一个集合"，加上恒等映射。两个函子 F、G 就是一个有序对 (A, B)。自然变换 η: F ⟹ G 只有一条分量 η_*: A → B，自然性条件只有一个方块（恒等），自动满足。

所以 [1, Set] 与 Set 是同一个范畴（等价，实际上是同构）。这不是废话：它说明"函子范畴"在最小情形下退化成原范畴，符合直觉——搬家到空世界，什么都没变。

取 C 为"两个对象 A、B 与一条箭头 f: A → B"的范畴（记 2）。一个函子 F: 2 → Set 是三样数据：集合 F A、集合 F B、函数 F f: F A → F B。也就是一个"有向图的一支"。

两个函子 F、G 之间的自然变换 η 是两条函数 η_A: F A → G A 与 η_B: F B → G B，满足一个方块：G f ∘ η_A = η_B ∘ F f。

现在手算一个具体的：F A = {1, 2}，F B = {x}，F f(1) = F f(2) = x。G A = {1, 2}，G B = {x, y}，G f(1) = x，G f(2) = y。

问：有没有自然变换 η: F ⟹ G？

η_A 是 {1,2} → {1,2}，四种选择：恒等、交换、常 1、常 2。 η_B 是 {x} → {x, y}，两种选择：送 x 或送 y。

方块要求：对每个 a ∈ {1,2}，G f(η_A(a)) = η_B(F f(a)) = η_B(x)。

右端与 a 无关，恒为 η_B(x)。左端：若 η_A = 恒等，则 a=1 时 G f(1) = x，a=2 时 G f(2) = y，要求 x = η_B(x) 且 y = η_B(x)，矛盾（除非 x = y）。若 η_A = 交换，同理矛盾。若 η_A = 常 1，则左端恒为 x，要求 x = η_B(x)，可以，取 η_B 送 x。若 η_A = 常 2，则左端恒为 y，要求 y = η_B(x)，可以，取 η_B 送 y。

所以恰好有两个自然变换：常 1 配送 x，常 2 配送 y。这两个都不是自然同构（因为 η_B 从单元素集到两元素集，不是双射；η_A 若为常映射也不是双射）。

再看一个能成同构的：令 G A = {1, 2}，G B = {x, y}，G f(1) = x，G f(2) = x（与 F 在 B 上的像一样是单点，但 B 多了一个元素）。

η_A 取恒等，则左端 G f(1) = x、G f(2) = x，所以 η_B(x) 必须等于 x（无论 a 是 1 还是 2，右端 η_B(F f(a)) = η_B(x)）。于是 η_B 只能送 x，不能送 y，不是双射，所以不是自然同构。

这说明什么？说明在这个小范畴里，"B 处多一个元素"这件事没法被自然变换吸收，因为 f 把 A 压成单点，B 处多出来的那个元素在任何从 F 来的映射里都够不着。用第十四节的语言：多出来的元素落在"分量管不到的地方"。

最后算一个真同构：F A = {1,2}、F B = {x,y}、F f(1)=x、F f(2)=y；G A = {1,2}、G B = {x,y}、G f 同上。η_A = 恒等、η_B = 恒等，方块交换，且两条都是双射，所以是自然同构。这里"逐点同构"与"自然同构"一致，因为两个函子在结构上完全一样。

四个小算例排在一起，看出一条线：自然变换能吸收的差别，是"由结构决定的部分"；结构完全一样时逐点同构就能拼成自然同构；结构不一样时，差别会躲在某个分量够不到的角落。

这条线跟我今天的判据八对得上，也跟第十四节的推广对得上。手算这四个例子的价值在于：它把"自然性"从一个形容词变成了四种具体情形下的四种结果，每一种都能被人复核。

手算里我犯了一个小错：第三个例子里我一开始以为 η_B 送 y 也能行，写完之后用方块验证，发现 a=1 时右端是 η_B(F f(1)) = η_B(x) = y，左端是 G f(η_A(1)) = G f(1) = x，x ≠ y，不成立。错因是"B 处有两个元素"让我下意识以为 η_B 有两个自由度，忘了 η_B 的定义域只有 {x}。

这个错很小，但它和题三的下标错是同一类：把"值域的大小"当成了"定义域的自由度"。

第三行值得多说一句：那个多出来的元素之所以"够不着"，不是因为它在很远的角落，恰恰是因为它就在 F B 的旁边——但因为所有从 A 来的箭头都落在 x 上，y 永远不会被任何从 F 出发的映射指到。结构上的差别可以发生在"看得见的地方"，只是那个地方不在分量能触及的路径上。

这解释了一件一直模糊的事：为什么有些"逐点看起来一样"的东西，实际上差得很远。差别不在值上，在"哪些值能被路径碰到"。用一句更土的话：你从入口进不去的地方，看着再近也是另一个房间。

第四行也不平凡：两个函子完全一样时，自然同构确实成立，但要注意"完全一样"指的是对象与态射的像都一样。如果像一样但函子的"标签"不同（比如两个不同的自由群函子，恰好给出相同的像），那要另外检查——因为函子的相等比"像相等"强。
