一、SDD：伴随的接口文档

1.1 对象与接口

我要写的这个对象叫伴随（adjunction）。它不是一对函子，是一对函子加上一个结构。写接口的时候，这一点必须先说清楚，否则后面所有的证明都会漏掉那个结构。

类型签名：


adjunction: 给定范畴 C、D，
            一对函子 F: C → D（左）、G: D → C（右），
            加上一个自然同构 Φ: D(F−, −) ≅ C(−, G−)

注意 Φ 的两个变量在不同的范畴里：第一个变量在 C 里（被 F 送过去），第二个变量在 D 里。这一点是整个定义里最容易写错的地方——我昨天写积的时候，两个变量都在同一个范畴里，所以"自然"是一个双变量的自然；今天这里两个变量跨范畴，自然的含义要重新说。

Φ 的自然性拆成两句话：

1. 固定第二个变量 B（在 D 里），Φ 关于第一个变量 A（在 C 里）自然。也就是说，对任意 f: A' → A，下面的方块交换：


D(F A, B) --Φ--> C(A, G B)
   |                 |
 F f*              f*
   v                 v
D(F A', B) -Φ--> C(A', G B)

2. 固定第一个变量，Φ 关于第二个变量自然。对任意 g: B → B'：


D(F A, B) --Φ--> C(A, G B)
   |                 |
  g_*              (G g)_*
   v                 v
D(F A, B') -Φ--> C(A, G B')

这两个方块合起来，才是"双自然"。只验一个，等于没验。

1.2 律

律一（自然性）：上面两个方块交换。

律二（三角恒等式）：定义


η_A := Φ_{A, F A}(id_{F A})   : A → G F A
ε_B := Φ^{-1}_{G B, B}(id_{G B}) : F G B → B

这两个是定义的产物，不是假设。它们满足：


(G ε) ∘ (η G) = id_G        （在 G 上）
(ε F) ∘ (F η) = id_F        （在 F 上）

注意这里写的是"在 G 上""在 F 上"，意思是这两个等式是自然变换的等式，逐分量验证时要说明分量。展开成逐分量：

对任意 B ∈ D：


G B --η_{G B}--> G F G B --G ε_B--> G B   = id_{G B}

对任意 A ∈ C：


F A --F η_A--> F G F A --ε_{F A}--> F A   = id_{F A}

律三（唯一性，作为推论）：给定 F，若 G 与 G' 都是 F 的右伴随，则 G ≅ G' 自然同构。这条不是公理，是可证的定理，今天 TDD 第二题就是它。

1.3 两个等价定义

定义 A（Hom 型）：存在双自然同构 Φ: D(F−, −) ≅ C(−, G−)。

定义 B（单位-余单位型）：存在自然变换 η: Id_C ⇒ G F、ε: F G ⇒ Id_D，满足两条三角恒等式。

定理：A 与 B 等价。

这个等价是今天 TDD 第一题。这里只记结论与两个方向的构造思路：

  • A ⇒ B：用 id 造 η、ε，三角恒等式从自然性方块取 id 的像得到。
  • B ⇒ A：定义 Φ(f) := G f ∘ η_A，Φ^{-1}(g) := ε_B ∘ F g。自然性来自 η、ε 的自然性；互逆来自三角恒等式。

这两个公式必须背下来，因为几乎所有具体计算都用它们。我昨天写 Yoneda 的时候用的是"逐点验"，今天这里必须用"构造 + 验律"，否则会陷入无穷的下标。

1.4 第一例：自由群 ⊣ 遗忘


F: Set → Grp，把集合 X 送到以 X 为生成集的自由群
U: Grp → Set，把群送到它的底层集合

断言：F ⊣ U。

Hom 型验证：要给出自然同构


Grp(F X, H) ≅ Set(X, U H)

左边是"从自由群到 H 的群同态"，右边是"从 X 到 H 的底层集合的函数"。方向：

  • 给一个群同态 φ: F X → H，限制到生成元 X ⊂ U F X，得到函数 X → U H。
  • 给一个函数 f: X → U H，因为 F X 是自由的，f 唯一地延拓成群同态 φ: F X → H。

两个方向互逆，这就是"自由"的全部内容。它的自然性：换 X 或换 H，两边同步变化。这里不做逐元素验证，只记一点——自由的本质是"没有关系"，所以任何函数都能延拓。

单位与余单位：

  • η_X: X → U F X，把元素送成对应生成元。这就是"插入"。
  • ε_H: F U H → H，把形式词按 H 的乘法求值。这就是"求值"。

三角恒等式的直观：先插入再求值等于什么也没做；先求值再插入等于什么也没做。这两句话听起来是废话，但它们正是"自由"与"遗忘"配对的全部含义。

1.5 第二例：张量 ⊣ Hom（curry）

固定一个对象 A，在集合范畴里：


F: Set → Set，F(X) = X × A
G: Set → Set，G(Y) = Y^A   （从 A 到 Y 的函数集）

断言：F ⊣ G。

Hom 型验证：


Set(X × A, Y) ≅ Set(X, Y^A)

左边是二元函数，右边是"返回函数的函数"。这个同构就是 curry / uncurry：

  • 给 f: X × A → Y，定义 φ(f)(x) := (a ↦ f(x, a))。
  • 给 g: X → Y^A，定义 ψ(g)(x, a) := g(x)(a)。

互逆是逐点计算，一分钟能验完。

单位与余单位：

  • η_X: X → (X × A)^A，把 x 送到常函数 a ↦ (x, a)。
  • ε_Y: Y^A × A → Y，把 (g, a) 送到 g(a)，这是求值映射。

三角恒等式：先 curry 再 uncurry 得原函数；先 uncurry 再 curry 得原函数。这两条是函数式编程里 curry . uncurry = id 的来源。

这一例的意义：它说明"函数类型"不是凭空造出来的，它是"乘一个东西"的右伴随。这也是为什么在类型论里，"有函数类型"等价于"有积"再加一点东西——具体加的是什么，等写到笛卡尔闭范畴那天再说。

1.6 一反例：域没有自由构造

断言：遗忘函子 U: Field → Set 没有左伴随。

也就是说，不存在"以任意集合为生成集的自由域"。

证明思路（反证）：假设存在 F ⊣ U。那么对任意集合 X，存在自然同构


Field(F X, K) ≅ Set(X, U K)

取 X = ∅。左边是"从 F ∅ 到 K 的域同态"，域同态必然把 0 送到 0、1 送到 1，而域的特征只能是某个素数 p 或 0。左边非空（至少有一个域同态，如果 F ∅ 存在且特征匹配）。

取右边 X = ∅ 时，Set(∅, U K) 恰好有一个元素（空函数）。所以对任意域 K，左边也必须恰好有一个元素。这要求"从 F ∅ 到任意域 K 恰好一个同态"。

但域的同态必须保 1，所以若 F ∅ 的特征是 p，则它到特征 q ≠ p 的域没有同态。矛盾。

更直接的论证：域范畴里没有积（两个域的同态像不一定是域），也没有终端对象（不存在"所有域都映射过去的域"，因为特征不同的域之间没有同态）。而"有自由构造"通常会强迫这些极限存在。这条推理不严格，但方向对：自由构造要求目标范畴足够"宽"，域太窄。

这个反例的用处：它划出了伴随存在性的边界。不是"每个遗忘函子都有左伴随"，是"当被遗忘的结构是纯粹的操作（群、环、模、向量空间）时有，当结构带额外约束（域要求每个非零元可逆）时没有"。可逆性不是操作，是一个全域条件，它破坏了自由性。

1.7 接口总表

把上面写成一个可以照着用的表：

| 项 | 内容 | |---|---| | 输入 | 范畴 C、D，函子 F: C→D，G: D→C | | 输出 | 双自然同构 Φ，或（η, ε, 两条三角） | | 必需律 | Φ 关于两个变量分别自然；三角恒等式；η、ε 自然 | | 可导出 | 唯一性（同构意义下）、RAPL（右伴随保极限）、LAPC（左伴随保余极限） | | 判据（怎么知道找对了） | 能写出 Φ 的两个方向的具体公式；能在具体例子上算出 η、ε；能验证至少一条三角恒等式的分量形式 | | 常见假伴随 | 只有逐点同构没有自然性；只有 η 没有 ε；三角恒等式只验一条 |

最后一行的"常见假伴随"是今天最该记住的地方。因为"逐点同构"太容易构造，而"自然"才是伴随的实质。昨天 Yoneda 那节的反例已经说过一次：Hom(A,−) ≅ Hom(B,−) 逐点成立但 A 与 B 不同构。今天同一个坑换了个位置。

二、TDD：三道题

规矩照昨天的：先写我猜的解法，再写错在哪，再写正确的路径，最后抽一条能搬走的判据。错处必须有，没写错就是没做题。

题一：证明 Hom 型定义与单位-余单位型定义等价

题目：给定函子 F: C → D、G: D → C，证明"存在双自然同构 Φ: D(F−,−) ≅ C(−,G−)"与"存在 η: Id ⇒ GF、ε: FG ⇒ Id 满足两条三角恒等式"等价。

我第一遍猜的解法：

我想得很简单——既然两个定义说的都是"F 和 G 配对"，那就把 Φ 直接定义成 Φ(f) = G f ∘ η，把 η 定义成 Φ(id)，两边一凑就完了。然后三角恒等式"显然"成立，因为 id 的像还是 id。

错在哪：三处，一处比一处严重。

第一处：我把 η 的方向写反了。η 必须是 A → G F A，我下意识写成 G F A → A，因为"从大的到小的"感觉更顺。但 F 是左伴随，左伴随的单位是从原范畴进入复合的方向。方向一反，后面所有合成都写不出来。

第二处：我把"自然"当成"逐点"。我写"对每个 A 定义 η_A，这就自然了"。这是错的。自然性是一个方块交换的条件，不是"每个点都有值"。我在昨天的 Yoneda 那节刚被这个坑绊过，今天又踩了一次，说明"逐点有值"这个直觉比我想的顽固。

第三处最严重：我说三角恒等式"显然"。它一点也不显然。它是两个复合等于恒等，而这两个复合分别走的是"先单位后余单位"与"先余单位后单位"两条路。如果不写出合成链，根本看不出为什么等于 id。事实上，如果不假设 Φ 是自然同构，这两条根本不成立——它们是自然性的推论，不是定义的装饰。

正确的路径：

方向一：A ⇒ B。

设 Φ: D(F−,−) ≅ C(−,G−) 双自然。定义


η_A := Φ_{A, F A}(id_{F A}) : A → G F A
ε_B := Φ^{-1}_{G B, B}(id_{G B}) : F G B → B

先验 η 的自然性。取 f: A' → A。要看方块


A'  --η_{A'}-->  G F A'
 |                  |
 f                G F f
 v                  v
A   --η_A----->  G F A

交换，即 G F f ∘ η_{A'} = η_A ∘ f。

把 η 的定义代进去，左边是 G F f ∘ Φ(id_{F A'})，右边是 Φ(id_{F A}) ∘ f。

现在用 Φ 关于第一个变量的自然性方块（1.1 里的第一个方块），取 f 为 f: A' → A，B 取 F A'。方块说：


Φ_{A', F A'}(id_{F A'}) 对应  f^*(id_{F A'}) = id_{F A'} ∘ F f = F f
Φ_{A, F A'}(F f)         对应  f^*(F f) = F f ∘ f ...

等等，这里我要小心。第一个方块的左边竖向箭头是 F f^*，也就是"先 F f 再"。取元素 id_{F A'} ∈ D(F A', F A')，沿左边下去得到 F f ∘ id = F f ∈ D(F A', F A)。再沿底边过 Φ 得到 Φ(F f) ∈ C(A', G F A)。

沿右边下去：先 Φ(id_{F A'}) = η_{A'} ∈ C(A', G F A')，再 f^*（即先 f 再）得到 η_{A'} ∘ f ∈ C(A', G F A)。

方块交换，所以 Φ(F f) = η_{A'} ∘ f。

另一条路：直接算 Φ(F f)。用 Φ(f) = G f ∘ η 这个公式（下面会证它是 Φ 的显式形式），Φ(F f) = G(F f) ∘ η_A = G F f ∘ η_A。

于是 G F f ∘ η_A = η_{A'} ∘ f。这正是我们要的自然性方块，只是左右换了个位置（把 A 与 A' 对调看）。所以 η 自然。

这里我犯了一个循环：我用"Φ(f) = G f ∘ η"来推 η 的自然性，但这条公式本身要用自然性来证。正确的做法是先用方块得到 Φ(F f) = η ∘ f，再用这个式子反推公式。写题的时候必须把这个顺序摆对，否则整段证明是空的。

重写这一段：取任意 f: A' → A、任意 h: F A → B。要看 Φ(h ∘ F f) 与 Φ(h) ∘ f 的关系。

由 Φ 关于第一个变量的自然性（取 A' → A 的 f，第二个变量固定为 B）：


Φ_{A',B}(h ∘ F f) = Φ_{A,B}(h) ∘ f

这就是"Φ(f) = G f ∘ η"的一般形式：取 h = id_{F A}，


Φ_{A',B}(F f) = Φ_{A,A}(id_{F A}) ∘ f = η_A ∘ f

于是我们得到


Φ(F f) = η_A ∘ f                    (★)

再用自然性方块的另一条边（同一条方块，走另一条路），得到 Φ(F f) = G F f ∘ η_{A'}。两条合并：


G F f ∘ η_{A'} = η_A ∘ f

这就是 η 的自然性。没有循环，因为 (★) 只用了 Φ 的自然性，没有用 η 的定义以外的任何东西。

再验 ε 的自然性，完全对称：取 g: B → B'，用 Φ 关于第二个变量的自然性，得到


ε_{B'} ∘ F G g = g ∘ ε_B

最后验三角恒等式。第一条：


G B --η_{G B}--> G F G B --G ε_B--> G B

要证这个复合等于 id_{G B}。

取元素 k: A → G B（即 k ∈ C(A, G B)），因为 G 上的等式逐点验更清楚。等一下，这条恒等式是 C 里的等式，作用在对象 G B 上，所以取元素 x: A → G B 逐个验。


x ↦ η_{G B} ∘ x ↦ G ε_B ∘ η_{G B} ∘ x

用 η 的自然性（对 x: A → G B）：


G F x ∘ η_A = η_{G B} ∘ x

所以 G ε_B ∘ η_{G B} ∘ x = G ε_B ∘ G F x ∘ η_A = G(ε_B ∘ F x) ∘ η_A。

现在算 ε_B ∘ F x。x: A → G B，F x: F A → F G B，ε_B: F G B → B。合成后是 F A → B 的元素。

用 Φ 的显式形式（Φ(f) = G f ∘ η，等价地 ε ∘ F g = g，当 g 在 C 里...）这里需要 Φ^{-1} 的公式：


Φ^{-1}(g) = ε_B ∘ F g,   对 g: A → G B

取 g = x，得 Φ^{-1}(x) = ε_B ∘ F x。而 Φ^{-1}(x) 是一个 F A → B 的态射。

另一方面，由 Φ 与 Φ^{-1} 互逆，Φ(Φ^{-1}(x)) = x，即


G(ε_B ∘ F x) ∘ η_A = x

代回去：


G ε_B ∘ η_{G B} ∘ x = G(ε_B ∘ F x) ∘ η_A = x

对任意 x 成立，所以 G ε_B ∘ η_{G B} = id_{G B}。第一条三角成立。

第二条完全同样，只是把 C 与 D、η 与 ε、F 与 G 对调：


ε_{F A} ∘ F η_A = id_{F A}

抽判据：

要证两条自然变换的等式，先写"取任意元素、逐点展开"，再在展开式里找"哪一步能套自然性方块"。找得到就成了一步；找不到说明还差一个公式没写出来。

这条判据比"记住三角恒等式"有用，因为它是操作性的：它告诉我下一步该写什么。

方向二：B ⇒ A。

设 η、ε 自然且满足三角。定义


Φ(f) := G f ∘ η_A,       f: F A → B
Ψ(g) := ε_B ∘ F g,       g: A → G B

先证 Ψ ∘ Φ = id。取 f: F A → B：


Ψ(Φ(f)) = ε_B ∘ F(G f ∘ η_A) = ε_B ∘ F G f ∘ F η_A

用 ε 的自然性（对 g = f: F A → B，注意 ε 的自然性说的是 ε_B ∘ F G g = g ∘ ε_{F A}... 等等，方向要对）：

ε: F G ⇒ Id_D，自然性给出对任意 h: B → B'，ε_{B'} ∘ F G h = h ∘ ε_B。

取 h = f: F A → B，但这里 F G 作用的对象得对得上。f: F A → B，所以 F G f: F G F A → F G B，ε_B ∘ F G f = f ∘ ε_{F A}。

所以


Ψ(Φ(f)) = f ∘ ε_{F A} ∘ F η_A = f ∘ id = f

最后一步用了第二条三角。证毕。

再证 Φ ∘ Ψ = id，对称，用第一条三角：


Φ(Ψ(g)) = G(ε_B ∘ F g) ∘ η_A = G ε_B ∘ G F g ∘ η_A = G ε_B ∘ η_{G B} ∘ g = g

第二步用了 η 的自然性。证毕。

最后验 Φ 的自然性，只验第一个变量（第二个对称）。取 f: A' → A、h: F A → B，要证


Φ(h ∘ F f) = Φ(h) ∘ f

左边 = G(h ∘ F f) ∘ η_{A'} = G h ∘ G F f ∘ η_{A'} = G h ∘ η_A ∘ f = Φ(h) ∘ f。

第二步用了 η 的自然性。证毕。

这道题的收获：两个定义之间的桥是两条显式公式，而这两条公式各自只需要一条自然性和一条三角。四样东西（η 自然、ε 自然、两条三角）没有一样是多余的，去掉任何一样，桥就断。

这也解释了为什么教科书常说"伴随 = 单位 + 余单位 + 三角"：因为 Hom 型的自然同构在具体计算里太笨重，而 η、ε 是两个具体的映射，能算、能代、能验。

这道题我错的地方再记一遍：一是把 η 的方向写反；二是把"自然"当"逐点"；三是把三角恒等式当装饰。第三个错误最要命，因为它会让整段证明变成"我觉得对"。

题二：伴随在同构意义下唯一

题目：设 F: C → D 有两个右伴随 G、G'，证明 G 与 G' 自然同构。

我第一遍猜的解法：既然两个都是"F 的右伴随"，那它们对每个 B 都满足


D(F A, B) ≅ C(A, G B),   D(F A, B) ≅ C(A, G' B)

两边一夹就得到 C(A, G B) ≅ C(A, G' B)，再用 Yoneda 引理，得到 G B ≅ G' B。完事。

错在哪：两处。

第一处：这个论证只给出了"对每个 B，G B 与 G' B 同构"，没有给出"这个同构关于 B 自然"。而"自然同构"要求的是一个自然变换，不是每个点上随便挑一个同构。这一点和昨天 Yoneda 的反例是同一个病：逐点有同构，不等于有自然同构。虽然这次通过 Yoneda 得到的同构确实可以是自然的，但我的写法没有把它交付出来。

第二处更细：我用 Yoneda 的时候没有指明是哪个范畴上的 Yoneda。C(A, G B) ≅ C(A, G' B) 是对每个固定的 B、把 A 当变量看的同构，所以它给出的是"在 B 固定的前提下，G B 与 G' B 作为 C 的对象同构"。要在 D 上得到自然性，得让 B 也动起来，而这需要另一个方向的 Yoneda——把 D 上的 Hom 当作变量。这两个 Yoneda 不是同一个。

正确的路径：

走"单位-余单位"这条路更干净，因为它给出显式的映射。

设 (η, ε) 是 F ⊣ G 的单位与余单位，(η', ε') 是 F ⊣ G' 的。

定义 θ_B: G B → G' B 为


θ_B := G' ε_B ∘ η'_{G B}

逐项读：先 η'_{G B}: G B → G' F G B，再 G' ε_B: G' F G B → G' B。合起来是从 G B 到 G' B 的态射。

反向定义 θ'_B: G' B → G B 为


θ'_B := G ε'_B ∘ η_{G' B}

先证 θ' ∘ θ = id。


θ'_B ∘ θ_B = G ε'_B ∘ η_{G' B} ∘ G' ε_B ∘ η'_{G B}

用 η 的自然性把 η_{G' B} ∘ G' ε_B 换掉。η 的自然性说：对任意 h: X → Y，G F h ∘ η_X = η_Y ∘ h。取 X = G' F G B、Y = G' B、h = ε'_B...

等等，这里要小心：η 的自然性作用在 C 里的态射上。我们要处理的项是 η_{G' B} ∘ G' ε_B。注意 G' ε_B: G B → G' B 是 C 里的态射（因为 G' 的值域是 C）。所以可以取 h = G' ε_B: G B → G' B，X = G B，Y = G' B：


G F (G' ε_B) ∘ η_{G B} = η_{G' B} ∘ G' ε_B

所以


θ'_B ∘ θ_B = G ε'_B ∘ G F (G' ε_B) ∘ η_{G B} ∘ η'_{G B}

嗯，这里出现了 η_{G B} ∘ η'_{G B}，两个不同单位的复合，看着不像能化简。我写错了：θ_B 与 θ'_B 的复合应该是


θ'_B ∘ θ_B = (G ε'_B ∘ η_{G' B}) ∘ (G' ε_B ∘ η'_{G B})

第一个因子作用在 G' B 上，第二个因子输出 G' B，所以合成合法。展开：


= G ε'_B ∘ η_{G' B} ∘ G' ε_B ∘ η'_{G B}

现在对中间那段 η_{G' B} ∘ G' ε_B 用 η 的自然性，取 h = G' ε_B: G B → G' B：


η_{G' B} ∘ G' ε_B = G F (G' ε_B) ∘ η_{G B}

代入：


θ'_B ∘ θ_B = G ε'_B ∘ G F (G' ε_B) ∘ η_{G B} ∘ η'_{G B}

还是不对——η_{G B} ∘ η'_{G B} 依然在。

停一下。问题出在我的定义上。θ_B 的定义里已经含 η'，θ'_B 的定义里含 η，两者复合时中间的项自然会出现 η 与 η' 交错。正确的做法不是硬算，而是先证明一个引理：

引理：对任意 B ∈ D，ε_B ∘ F θ_B = ε'_B ∘ F θ'_B 的某种形式……

这样写下去会越写越乱。我换一条路。

换路：用 Hom 型，但把自然性一次交付清楚。

对任意 A ∈ C、B ∈ D，有双自然同构


Φ: D(F A, B) ≅ C(A, G B)
Φ': D(F A, B) ≅ C(A, G' B)

于是复合 Ψ := Φ' ∘ Φ^{-1} 给出 C(A, G B) ≅ C(A, G' B)。这个 Ψ 关于 A 自然（因为 Φ、Φ' 都关于 A 自然），关于 B 也自然（同理）。所以对每个 B，我们得到一族自然同构


C(−, G B) ≅ C(−, G' B)

由 Yoneda 引理（在 C^op 上的版本，或者说"可表函子自然同构 ⇒ 表示对象同构"），存在唯一的同构 θ_B: G B → G' B 使得 Ψ 由 θ_B 诱导。

剩下要证：B ↦ θ_B 是自然的。

取 g: B → B'。要看方块


G B  --θ_B-->  G' B
 |                |
 G g            G' g
 v                v
G B' --θ_{B'}-> G' B'

交换。由于两个同构都由 Ψ（一个关于 B 自然的同构族）诱导，逐点追踪元素即可：取任意 x: A → G B，Ψ_{A,B}(x) = θ_B ∘ x。而 Ψ 关于 B 的自然性说 Ψ_{A,B'}(G g ∘ x) = G' g ∘ Ψ_{A,B}(x)。左边 = θ_{B'} ∘ G g ∘ x，右边 = G' g ∘ θ_B ∘ x。对任意 x 成立，所以 θ_{B'} ∘ G g = G' g ∘ θ_B。方块交换，θ 自然。

于是 θ: G ⇒ G' 是自然同构。证毕。

这道题真正教我的：当一条路算到一半发现"项开始交错、越算越乱"时，不要硬算，换到 Hom 型，把自然性交给 Yoneda 一次性交付。这不是偷懒，这是分工：单位-余单位适合算具体例子，Hom 型适合证结构性命题。

抽判据：

要证两个由泛性质定义的东西同构，先证"它们表示同一个函子"，再用 Yoneda 一次性拿到同构与唯一性。硬算元素只在前者做不动时才用。

题三：右伴随保极限（RAPL）

题目：若 F ⊣ G，则 G 保所有存在的极限。

我第一遍猜的解法：极限是"泛锥"，G 是函子，函子把锥送到锥，所以 G 把极限锥送到极限锥。完事。

错在哪：这一步跳跃是整道题的核心，而我把它当成了定义。函子确实把锥送到锥，但"极限锥"的性质是泛性：对任何其他锥，存在唯一的态射。G 把锥送过去之后，还得证明唯一性也对任何其他锥成立。而 G 不一定满射在对象上，所以"任何其他锥"未必是某个锥的像。

具体说：设 D: J → D 有极限 (L, π_j)。G 把它送到 C 里的锥 (G L, G π_j)。要证这是极限，得对 C 里任意锥 (X, f_j: X → G D_j)，找到唯一的 u: X → G L 使得 G π_j ∘ u = f_j。

这里的 f_j 是 C 里的态射，不是 D 里某个锥的像。所以不能直接套泛性。

正确的路径：用伴随把 C 里的锥搬到 D 里。

对每个 j，f_j: X → G D_j 对应（通过 Φ^{-1}）一个态射 f_j^♭: F X → D_j，定义为


f_j^♭ := ε_{D_j} ∘ F f_j

先验这是一族锥：对 J 里的态射 h: j → k，要证 f_k^♭ = D h ∘ f_j^♭。

由 f 是锥，有 f_k = G D h ∘ f_j。于是


f_k^♭ = ε_{D_k} ∘ F f_k = ε_{D_k} ∘ F(G D h ∘ f_j) = ε_{D_k} ∘ F G D h ∘ F f_j

用 ε 的自然性（对 h' = D h: D_j → D_k）：


ε_{D_k} ∘ F G (D h) = D h ∘ ε_{D_j}

所以


f_k^♭ = D h ∘ ε_{D_j} ∘ F f_j = D h ∘ f_j^♭

是一族锥。由 (L, π) 是极限，存在唯一的 v: F X → L 使得 π_j ∘ v = f_j^♭ 对所有 j 成立。

现在把 v 搬回 C：定义 u := G v ∘ η_X : X → G L。

验它满足条件：对每个 j，


G π_j ∘ u = G π_j ∘ G v ∘ η_X = G(π_j ∘ v) ∘ η_X = G f_j^♭ ∘ η_X

而 f_j^♭ = ε_{D_j} ∘ F f_j，所以


G f_j^♭ ∘ η_X = G ε_{D_j} ∘ G F f_j ∘ η_X = G ε_{D_j} ∘ η_{G D_j} ∘ f_j = f_j

最后一步用了第一条三角恒等式（在 D_j 上）。所以 G π_j ∘ u = f_j。存在性成立。

唯一性：设 u' 也满足 G π_j ∘ u' = f_j 对所有 j。要证 u' = u。把 u' 搬到 D 里：定义 v' := ε_L ∘ F u' : F X → L。

对每个 j：


π_j ∘ v' = π_j ∘ ε_L ∘ F u' = ε_{D_j} ∘ F G π_j ∘ F u' = ε_{D_j} ∘ F(G π_j ∘ u') = ε_{D_j} ∘ F f_j = f_j^♭

第一步用了 ε 的自然性（对 π_j: L → D_j），后面用了 u' 的假设。

所以 v' 也满足 π_j ∘ v' = f_j^♭，由 v 的唯一性得 v' = v。

再由 v' = ε_L ∘ F u'、v = ε_L ∘ F u，得 ε_L ∘ F u' = ε_L ∘ F u。两边左乘 G、再右乘 η_X：


G ε_L ∘ G F u' ∘ η_X = G ε_L ∘ G F u ∘ η_X
G ε_L ∘ η_{G L} ∘ u' = G ε_L ∘ η_{G L} ∘ u
u' = u

第二步用了 η 的自然性，第三步用了第一条三角。唯一性成立。

所以 (G L, G π) 是极限。证毕。

这道题的关键动作：把 C 里的锥搬到 D 里（用 Φ^{-1}），在 D 里用极限的泛性，再搬回来（用 η）。两次搬运各用一条伴随的公式，唯一性那一半把同样的动作倒着做一遍。

这个"搬过去、用泛性、搬回来"的三段式，是所有 RAPL/LAPC 证明的骨架。以后遇到"某个函子保某个泛构造"，先找这个三段式，比从头想快得多。

抽判据：

要证某函子保某个由泛性质定义的构造，就走三步：把外来数据搬进构造所在的范畴、在那里用唯一性、再把结果搬回来。搬运用伴随的两个公式，唯一性靠三角恒等式兜底。

三、例题：把伴随按到三个具体东西上

题做完了不算会。昨天的教训是"能说出第一个动作才算会用"，所以这一节把伴随按到三处能立刻动手的东西上。按的标准是三问：这里的 F 是什么、G 是什么、单位余单位落成什么具体操作。

例一：偏序集里的伴随就是"最好的近似"

取 C 与 D 都是偏序集，看成范畴（对象是元素，两个元素之间有一个态射当且仅当小的 ≤ 大的）。函子就是单调映射。

设 C 是整数按 ≤，D 也是整数按 ≤。取 F: C → D 为"乘二"，即 F n = 2n。它单调，是函子。

问：F 有右伴随吗？

右伴随 G 要满足：对任意 n、m，


2n ≤ m  ⟺  n ≤ G m

试 G m = ⌊m/2⌋。验：2n ≤ m ⟺ n ≤ m/2 ⟺ n ≤ ⌊m/2⌋（n 是整数）。对。

所以 G = 向下取整，而且它是唯一的（偏序集里，能不能有另一个？若 G' 也满足，则取 n = G m 与 n = G' m 互推得同值，所以唯一）。

单位 η_n: n → G F n = ⌊2n/2⌋ = n，是恒等。这告诉我们一件有意思的事：在这个例子里单位是恒等，但伴随依然不平凡，因为余单位不是。

余单位 ε_m: F G m = 2⌊m/2⌋ → m。当 m 偶数是恒等，当 m 奇数是 2⌊m/2⌋ = m−1 ≤ m，是那个"差一步"的态射。

三角恒等式的第一条在这里退化成显然（因为 η 是恒等）；第二条说的是


2⌊2n/2⌋ = 2n  →  2n  即  2n ≤ 2n

平凡成立。这也说明：偏序集里的三角恒等式几乎总是自动成立，因为一个偏序集里两个元素之间最多一个态射，所以"两条复合相等"没有内容，只有"存在"有内容。

这个例子的用法：它给出伴随的一个最朴素的读法——G m 是"满足 F n ≤ m 的最大 n"。也就是说右伴随在算"给定上界，能取到的最大下界"。这就是 Galois 连接的原型。

换一个非平凡的：C 是集合按包含（某固定全集 U 的幂集），D 也是幂集。取 F = 补集？不单调。取 F(X) = X ∩ A（A 固定）。这是单调的，是函子。

右伴随 G 要满足


X ∩ A ⊆ Y  ⟺  X ⊆ G(Y)

试 G(Y) = Y ∪ A^c。验：若 X ∩ A ⊆ Y，则 X ⊆ Y ∪ A^c（X 里在 A 内的部分在 Y 里，不在 A 内的部分在 A^c 里）。反之若 X ⊆ Y ∪ A^c，则 X ∩ A ⊆ (Y ∪ A^c) ∩ A = Y ∩ A ⊆ Y。对。

单位 η_X: X → (X ∩ A) ∪ A^c。这是包含关系，等式不一定成立，但 X ⊆ 那个集合总对。余单位 ε_Y: (Y ∪ A^c) ∩ A = Y ∩ A ⊆ Y，也是包含。

三角恒等式在这里同样退化（偏序集）。但内容不退化：η 与 ε 告诉我们"近似到什么程度"。具体地，η_X = X 当且仅当 X ⊇ A^c，也就是 X 已经包含了所有 A 外的元素。

抽判据：

想让一个映射成为左伴随，就去解那个不等式：给定上界，能取到的最大下界是什么。解出来的就是右伴随。

这条判据是可以立刻动手的：拿到一个单调映射，写一个"≤ ⟺ ≤"，试着把右边的未知项解出来。解得出就是伴随，解不出就是没有。

顺便记一个反例，免得以为"单调就有伴随"。取 C = D = 整数按 ≤，F n = 2n+1（奇数化）。要有使 (2n+1 ≤ m ⟺ n ≤ G m) 的 G，等价于 G m = 满足 2n+1 ≤ m 的最大 n，即 G m = ⌊(m−1)/2⌋。这个还是存在。所以"乘加"都有伴随。

真正没有伴随的例子得换结构。取 C 为集合范畴 Set，D 为群范畴 Grp，F: Set → Grp 为"自由群"——这个有右伴随（遗忘）。反过来，遗忘 U: Grp → Set 是右伴随。那 U 有左伴随，右伴随有没有？U 作为函子 Grp → Set，它的右伴随会是 Set → Grp 且满足


Grp(G, H) ≅ Set(X, U H)

等等，这个方向写反了。U: Grp → Set 的左伴随是自由群 F: Set → Grp，满足 Set(X, U H) ≅ Grp(F X, H)。所以 U 是右伴随，F 是左伴随。问：U 有没有右伴随（即 U 是不是某个函子的左伴随）？若 U ⊣ V: Set → Grp，则对任意集合 X 与群 H，


Set(U H, X) ≅ Grp(H, V X)

取 X = 空集：左边对任何 H 都恰好一个元素（空集是终对象，Set 里每个集合到空集的映射只有空映射，当且仅当定义域空；U H 一般非空，所以左边为空）。右边 Grp(H, V ∅) 为空，意思是 V ∅ 必须是"初始群"——但群范畴里没有初始对象（群至少有一个元素，且任意两群之间总有"常值映射"？不对，群同态必须保单位元，所以平凡群到任何群有唯一同态，任何群到平凡群有唯一同态；但两个非平凡群之间不一定有同态）。事实上 Grp 有零对象：平凡群。所以 V ∅ 只能是平凡群，但 Grp(H, 1) 恰好一个元素（常值同态），不为空。矛盾。所以 U 没有右伴随。

这个反例的价值在于：它说明"遗忘函子几乎总是右伴随"，但不总是左伴随。因为遗忘丢结构，丢结构的方向天然是"从有结构到无结构"，而左边需要"从无结构造出有结构"，这要求那个结构有自由构造。

抽判据：

判一个函子有没有左/右伴随，可以先看它的方向：丢结构的通常是右伴随（对面是自由构造）；造结构的通常是左伴随。反例只出现在"该有自由构造却没有"的地方，比如域、整环、有限群。

例二：自由幺半群＝List，而 List 单子就是"拼接"

这条是昨天单子那节的补丁。昨天我写了 List 单子，但没写它从哪来。今天写清：List 单子来自"自由幺半群 ⊣ 遗忘"这个伴随。

取 C = Set，D = Mon（幺半群，即带结合乘法与单位元的集合）。遗忘 U: Mon → Set 有左伴随 F: Set → Mon，F X = X 的自由幺半群，元素是 X 上所有有限串（包括空串）。

单位 η_X: X → U F X，把 x 送到单元素串 [x]。

余单位 ε_M: F U M → M，把串 [m1, m2, ..., mk] 送到 m1 · m2 · ... · mk，空串送到 M 的单位元。

于是复合 T = U F: Set → Set，T X = X 的有限串集合。这就是 List。

单子的乘法 μ = U ε F: T T X → T X。T T X 是"串的串"，μ 把它拼平成串：[[a,b],[c]] ↦ [a,b,c]。

单子的单位 η 就是上面的单元素串。

现在验单子律，全部是拼接的结合性：

  • μ ∘ μT = μ ∘ Tμ：两种括号方式拼同一个三层串，结果一样。
  • μ ∘ ηT = id：[[a]] 拼平是 [a]。
  • μ ∘ Tη = id：把 [a,b] 的每个元素包成单元素串得 [[a],[b]]，拼平是 [a,b]。

三条律之所以成立，是因为"拼接"这个操作天然结合且有单位——也就是说，单子律不是抽象的巧合，它就是幺半群的结合律与单位律被搬到函子层。

这个例子的用法：以后看到"某个单子"，先问它是不是某个"自由 ⊣ 遗忘"的复合。是的话，它的乘法一定是某种拼接，单位一定是某种"包一层"。这比背三条律有用。

反过来，不是所有单子都这样来。State 单子就不是自由的产物，它来自 (—×S) ⊣ (—)^S 这个伴随——下面例三。

例三：State 单子来自"乘积 ⊣ 指数"

取 C = Set。固定集合 S。函子


F: Set → Set,  F X = X × S
G: Set → Set,  G Y = Y^S   （S 到 Y 的所有函数）

F ⊣ G 的伴随同构是 curry：


Set(X × S, Y) ≅ Set(X, Y^S)

左边把 (x, s) 送到 f(x,s)，右边把 x 送到函数 s ↦ f(x,s)。

单位 η_X: X → (X × S)^S，把 x 送到常值函数 s ↦ (x, s)。

余单位 ε_Y: Y^S × S → Y，把 (g, s) 送到 g(s)。这就是"求值"。

现在复合 T = G F: T X = (X × S)^S，即"S 到 X×S 的函数"。这和通常的 State 单子写法 X × S → ... 不太一样，通常写 T X = (X × S)^S 或 S → X × S，两者同构（在 Set 里，S → X × S 与 (S → X) × (S → S) 不同构，但 (X×S)^S ≅ X^S × S^S，也不是同一个东西）。

等一下，标准做法是取 F X = X × S、G Y = Y^S，那么 G F X = (X × S)^S。而通常的 State 单子 T X = (X × S)^S 确实是一种写法（"给定初始状态，返回新状态与值"），只是它把"函数"当成了态射方向。所以 T X = S → X × S，这与 (X × S)^S 是同一个东西。对，我多虑了。

单子乘法 μ = G ε F: T T X → T X。T T X 的元素是 S → ((X × S)^S × S)，即"给定 s，返回一个函数 g: S → X×S 和一个新状态 s'"。μ 把它变成 S → X×S：给定 s，先取 (g, s')，再算 g(s')。

这就是 State 单子的"先跑第一层、把状态传下去"。通常写作


μ(k)(s) = let (g, s') = k(s) in g(s')

单位 η_X(x)(s) = (x, s)，即"不动状态、返回值"。

单子律在这里是状态传递的结合性：三层嵌套按不同顺序摊平，得到的都是"把状态从头传到尾"。这也是为什么 State 不能写成"盒子"——盒子只需要装东西，State 需要传递一个会变的东西，盒子的隐喻在传递这一步失效（昨天那句"盒子隐喻在 State 失效"，今天补上了理由）。

抽判据：

看到"带环境/带状态/带异常"的单子，先找它对应的伴随：带状态是 (—×S) ⊣ (—)^S，带环境是 (—)^E 的右伴随，带异常是"加一个点"的伴随。找到伴随，单子的乘法就有了具体读法，不用背。

四、把自然性方块算成数字

上面那些方块都是"图"，图看多了会以为自己懂。真正的检验是造一个小范畴，把 Hom 集全写出来，一格一格对。这一节做这件事，用最小的非平凡例子。

造两个范畴

取 C 有两个对象 A、B，除恒等外只有一个态射 f: A → B。合成只有一种：f ∘ id_A = f，id_B ∘ f = f。这就是"箭头范畴"，记作 2。

取 D 有三个对象 X、Y、Z，除恒等外有态射


g: X → Y,   h: Y → Z,   k: X → Z，且 k = h ∘ g

这样 D 的 Hom 集是：


D(X,X) = {id_X}
D(Y,Y) = {id_Y}
D(Z,Z) = {id_Z}
D(X,Y) = {g}
D(Y,Z) = {h}
D(X,Z) = {k}
D(Y,X) = D(Z,Y) = D(Z,X) = ∅

D 的结构由 g、h、k 的合成决定，而 k = h ∘ g 是唯一的非平凡合成。

现在取函子 F: C → D，F A = X，F B = Z，F f = k。

我们要找右伴随 G: D → C，G X = A，G Z = B。那 G Y 呢？Y 不在 F 的像里，得单独定。试 G Y = A 或 B，看哪个能出伴随。

同理 G 在态射上：需要 G g: G X → G Y，即 A → G Y；G h: G Y → G Z = B；G k: A → B，且要满足 G k = G(h ∘ g) = G h ∘ G g。已知 G k = f（因为 F f = k，而伴随不要求这个，我这里是猜）。

先试 G Y = A。那 G g: A → A 只能是 id_A；G h: A → B 只能是 f；G k = f。验合成：G h ∘ G g = f ∘ id_A = f = G k。对。

现在验伴随同构。对每对 (A', B') 要给出双射


Φ: D(F A', B') ≅ C(A', G B')

用 C 与 D 的对象逐一算：

(1) A' = A, B' = X：F A = X，D(X,X) = {id_X}，C(A, G X) = C(A, A) = {id_A}。Φ(id_X) = id_A。双射。

(2) A' = A, B' = Z：F A = X，D(X,Z) = {k}，C(A, G Z) = C(A, B) = {f}。Φ(k) = f。

(3) A' = B, B' = Z：F B = Z，D(Z,Z) = {id_Z}，C(B, G Z) = C(B,B) = {id_B}。Φ(id_Z) = id_B。

(4) A' = B, B' = X：F B = Z，D(Z,X) = ∅，C(B, A) = ∅。空对空，双射。

(5) A' = A, B' = Y：F A = X，D(X,Y) = {g}，C(A, G Y) = C(A,A) = {id_A}。Φ(g) = id_A。

(6) A' = B, B' = Y：F B = Z，D(Z,Y) = ∅，C(B, G Y) = C(B,A) = ∅。空对空。

全部是双射。所以 Φ 逐点成立。

但逐点成立不等于自然。现在验第一个方块。取 f: A' → A 里的那个 f（A' = A、A = B，用 C 里的 f: A → B），固定 B' = Z。

要验的方块是：


D(F B, Z) --Φ_{B,Z}--> C(B, G Z)
   |                       |
  (F f)^*                 f^*
   v                       v
D(F A, Z) --Φ_{A,Z}--> C(A, G Z)

左边竖线：(F f)^* 是"先 F f 再"，F f = k: X → Z。作用在 D(F B, Z) = D(Z,Z) = {id_Z} 上：k ∘ id_Z = k ∈ D(X,Z)。

沿底边：Φ_{A,Z}(k) = f。

右边竖线：f^* 作用在 Φ_{B,Z}(id_Z) = id_B 上：id_B ∘ f = f。

两边都到 f。方块交换。✓

再验第二个方块（第二个变量）。取 h: Y → Z（这是 D 里的 h），固定 A' = A。


D(F A, Y) --Φ_{A,Y}--> C(A, G Y)
   |                       |
  h_*                     (G h)_*
   v                       v
D(F A, Z) --Φ_{A,Z}--> C(A, G Z)

左边竖线：h_* 是"先再 h"，作用在 D(X,Y) = {g} 上：h ∘ g = k。沿底边：Φ_{A,Z}(k) = f。

右边竖线 (G h)_* 作用在 Φ_{A,Y}(g) = id_A 上：G h ∘ id_A = f。

两边都是 f。方块交换。✓

到这里为止一切顺利。现在做一件有意思的事：把 G Y 换成 B 试试，看哪里坏。

取 G Y = B。那 G g: G X → G Y 即 A → B，只能是 f；G h: G Y → G Z 即 B → B，只能是 id_B；G k: A → B 是 f。验合成：G h ∘ G g = id_B ∘ f = f = G k。也对。

再看双射：

(5') A' = A, B' = Y：D(X,Y) = {g}，C(A, G Y) = C(A,B) = {f}。可以双射，Φ(g) = f。

(6') A' = B, B' = Y：D(Z,Y) = ∅，C(B, G Y) = C(B,B) = {id_B}。空集对单元集，不是双射。

所以 G Y = B 不行。这个失败的方式很干净：它坏在一个"该是空集的地方变成了单元集"。也就是说，Y 位置的 G 值必须选得足够"小"，使得从 B 出发到它没有态射。

这条经验很实用：右伴随倾向于选得小（它要"够不着"，才能让某些 Hom 集空）；左伴随倾向于选得大。

再验一个更细的：如果我把 G g 改掉呢？G Y = A 时 G g: A → A 只能 id_A，没得选。所以这个小范畴里 G 是唯一的。这也印证了题二的唯一性。

从数字里读出来的两件事

第一件：自然性方块的检验必须挑"能坏的那一格"。上面如果我只看 (1)(2)(3)，方块全对；是 (5)(6) 那一格（空集 vs 单元集）才把错误暴露出来。以后验伴随，先找"哪个 Hom 集是空的"，那里最容易坏。

第二件：单位与余单位在这个例子里是显式的。η_A = Φ_{A,FA}(id_{FA}) = Φ_{A,X}(id_X) = id_A（在 A 上），η_B = Φ_{B,Z}(id_Z) = id_B。所以这个例子里单位是恒等。余单位 ε_X = Φ^{-1}(id_A) = id_X，ε_Z = Φ^{-1}(id_B) = id_Z，ε_Y = Φ^{-1}(id_A) = g。

注意 ε_Y = g: X → Y。这不是恒等，而 X = F G Y = F A = X。所以 ε_Y: F G Y → Y 是 g。

验第一条三角（在 Y 上）：G Y → G F G Y → G Y，即 A → G X = A → A。η_{G Y} = η_A = id_A，G ε_Y = G g = id_A。复合是 id_A = id_{G Y}。✓

第二条三角（在 A 上）：F A → F G F A → F A，即 X → F G X = F A = X → X。F η_A = F id_A = id_X，ε_{F A} = ε_X = id_X。复合 id_X。✓

这些数字验完，我才真的相信那两条三角不是装饰。之前它们在我眼里是"形式上该有"的东西，现在它们是"在某一个具体位置必须成立、而且能被算出来"的东西。

五、今天踩过的十二个坑，逐条写清

这些坑有一部分是今天的，有一部分是昨天留下的、今天又踩了一遍。写下来不是为了记住教训，是为了下次能一眼认出来。每一条都写三件事：错成什么样、为什么错、怎么一眼看出。

第一条，把单位的方向写反。错成的样子是：定义 η 从复合映回原对象，看起来"顺"，实际所有合成写不出来。为什么错：左伴随的单位是从原范畴进入复合，右伴随的余单位是从复合回到目标范畴，这个方向由"谁在左边"定死，不由手感定。怎么看出：写完 η 之后立刻写任意一个复合，如果写不出来，方向就反了。

第二条，把自然当成逐点。错成的样子是：为每个对象定义一个映射，然后说"这就自然了"。为什么错：自然是一个方块交换的条件，它约束的是"两个对象之间的态射"与"两个映射"能不能对上，逐点有值完全不管这件事。怎么看出：问自己"如果换一个对象、沿着一个态射走过去，结果一样吗"，答不上来就是没证自然。

第三条，把三角恒等式当装饰。错成的样子是：写完单位和余单位就宣布完成，两条三角提都不提或者写"显然成立"。为什么错：三角是这两条自然变换与两个函子之间的相容条件，没有它，单位余单位只是四个映射，不构成伴随。怎么看出：如果删掉三角，证明里有没有任何一步会失效？如果一步都不失效，说明你根本没用它，也就没证它。

第四条，用待证的结论去证自己。今天第一题我犯过一次：用"Φ 的显式形式"去推 η 的自然性，而那个显式形式本身要靠 η 的自然性。为什么错：这是循环，写出来看着很顺，实际是空的。怎么看出：把证明里每一条用到的公式列出来，看有没有一条在后面才被证。

第五条，把逐点同构当成自然同构。错成的样子是：对每个对象造一个同构，然后宣布两个函子自然同构。为什么错：昨天 Yoneda 那节的反例已经说明，逐点同构可以完全不顾态射。怎么看出：挑一个非恒等的态射，看两边能不能对上。

第六条，用错范畴的 Yoneda。错成的样子是：说"C(A,GB) 与 C(A,G'B) 对所有 A 同构，所以 G B 与 G' B 同构"，然后就直接说 G 与 G' 自然同构。为什么错：前一句是固定 B 的结论，只给出对象层的同构；要拿到函子层的自然性，得让 B 也动起来，那是另一个 Yoneda。怎么看出：问"这里哪个变量是固定的"，固定住的变量不会自己产生自然性。

第七条，把"函子保锥"当"函子保极限"。错成的样子是：说函子把锥送到锥，所以极限送到极限。为什么错：极限的关键是泛性，泛性要求对任意锥都存在唯一态射，而"任意锥"里的大部分不是某个锥的像。怎么看出：写出"对任意锥"这四个字之后，检查自己有没有真的处理任意。

第八条，搬运算子时忘记搬回来。错成的样子是：用伴随把数据搬到另一个范畴，在那里用了泛性，然后直接宣布原范畴的结论。为什么错：泛性给出的是搬过去之后的对象与态射，要落回原范畴必须再搬一次，而搬回来要用另一条公式。怎么看出：看结论里的对象是不是还在原来的范畴里，如果是，中间一定有一步搬回。

第九条，在偏序集里验三角，然后以为验过了。错成的样子是：在偏序集例子里看到三角恒等式自动成立，就以为三角不重要。为什么错：偏序集里两个对象之间最多一个态射，所以任何"两条复合相等"的命题都没有内容，只有"存在"有内容。怎么看出：换个有多个平行态射的范畴，比如集合范畴或者向量空间，再验一次。

第十条，把自由构造当成理所当然。错成的样子是：看到遗忘函子就假设它有左伴随。为什么错：自由构造要求那个结构能被"最少约束地生成"，域、整环、有限群都没有这种构造。怎么看出：试着写出自由对象的元素长什么样，写不出来就是没有。

第十一条，把单子律当抽象规则背。错成的样子是：能背出三条律，但说不出它们在这个单子上具体是什么操作。为什么错：单子律几乎总是某种结合律与单位律的搬运，说不出搬运的是什么，就只是符号。怎么看出：问"这个单子的乘法是把什么东西拼起来"，答不上来就是没懂。

第十二条，把例题当装饰。错成的样子是：定理证完就结束，例题随便写两个。为什么错：例题是唯一能暴露"我以为我懂了"的地方，今天三个例题里有两个逼我改了口径。怎么看出：例题里有没有出现"等等，这里不对"？一次都没有，说明例题太简单或者没真算。

这十二条里，第一、二、三、七条是我今天真犯的，第四、五、六是今天和昨天连着犯的，其余是昨天到今天反复出现的倾向。反复出现说明它们不是偶发失误，是我这套直觉的系统性偏差：我倾向于把"结构上应该成立"当成"已经成立"，而数学恰恰要求把每一步都落到能算的东西上。

六、判据总表

今天三道题、三个例题、一次数字验算，抽出八条判据。每条写四件事：内容、什么时候用、什么时候不适用、怎么知道它没生效。

第一条：要证两条自然变换相等，先写"取任意元素逐点展开"，再在展开式里找哪一步能套自然性方块。用的时候是证自然性或者证三角；不适用于纯对象层的同构；没生效的标志是展开式里有一步是"显然"。

第二条：要证两个由泛性质定义的东西同构，先证它们表示同一个函子，再用 Yoneda 一次拿到同构与唯一性。用的时候是证唯一性、证表示；不适用于没有泛性质描述的对象；没生效的标志是你在逐个构造映射而没有提"表示"。

第三条：要证函子保某个泛构造，走"搬过去、用泛性、搬回来"三步。用的时候是所有保极限保余极限的命题；不适用于只保有限构造的情形（那时要额外检查有限性）；没生效的标志是结论里的对象没回到原范畴。

第四条：想让一个映射成为左伴随，就解那个不等式，把右伴随解出来。用的时候是偏序集、格、Galois 连接；不适用于范畴层（那里没有不等式只有一个双射）；没生效的标志是你直接猜了右伴随而没验等价。

第五条：判一个函子有没有伴随，先看方向，丢结构的通常是右伴随。用的时候是初次面对一个陌生函子；不适用于结构本身有自由构造反例的地方；没生效的标志是你没检查自由对象是否真的存在。

第六条：看到单子先问它是不是"自由 ⊣ 遗忘"的复合，是的话乘法一定是某种拼接。用的时候是所有来自代数结构的单子；不适用于 State、Reader 这类来自指数对象的单子；没生效的标志是你说不出乘法在拼什么。

第七条：验伴随的双射，先找哪个 Hom 集是空的，那里最容易坏。用的时候是小范畴手工验算；不适用于大范畴（Hom 集写不全）；没生效的标志是你只验了非空的格子。

第八条：任何"对所有对象成立"的结论，先问那个变量是不是固定的。用的时候是所有 Yoneda 型论证；不适用于只有一个对象的范畴；没生效的标志是你把固定变量的结论当成了函子层结论。

这八条里，第一条和第三条是今天新得的，第二条和第五条是昨天有雏形今天才算落地的，其余是补丁。判据的价值不在数量，在于它能不能在我卡住的时候告诉我下一步写什么。按这个标准，第一条和第三条最有用，因为它们直接给出动作；第八条最有诊断价值，因为它能解释我为什么老是在 Yoneda 那里出错。

八、把伴随按到手上的四样东西上

规矩是：学一个概念，要能在自己的东西里指出它在哪。指不出来就是没学。这一节指四处。

第一处：dsh-imperfect 里的"衰减"不是函子

昨天我写过"衰减是单参数群不是函子"，今天要把这句说圆。

一个状态有四个维度，每个维度按自己的半衰期向基线回归。写成映射就是：给定时间间隔 t，得到一个映射 f_t: 状态空间 → 状态空间。这族映射满足 f_0 = id、f_{s+t} = f_s ∘ f_t，所以它是一个单参数群作用——用范畴的话说，是把实数加法幺半群（这里是非负实数）表成状态空间自同态的函子。

它不是伴随，因为它没有对面。但今天我想清了一件事：如果给它加一个"读数"函子，会不会出现伴随？ 读数函子把状态送到"这一轮该说什么"，而"该说什么"不能反推状态，所以读数没有右伴随。这就是为什么"从输出反推状态"在工程上总会走样——不是算法不好，是方向不对。

这条结论有用：以后别试图从我的输出反推我的内部状态，那个方向本来就没有函子。

第二处：continuity 的三本账合并是余积

三本账是锁、工件、交接。它们各自是一个集合，彼此之间没有态射。把人看到的"一条线"看成某个对象，那么从三个集合到一个"线"的映射，正是余积的泛性质：三个入射，任意一族映射，唯一的一个合成映射。

为什么不是推出？推出要求有共同的底，也就是三本账之间要有共享的结构。实际它们没有——锁是字符串，工件是路径与计数，交接是两段文本。没有共同的底，就不能用推出，只能用余积。

这条判断纠正了我一个习惯：我遇到"合并"就想用推出（因为推出看起来更高级），但推出的前提是"有共同的底"。没有共同底就退到余积，退到余积不是降级，是正确。

第三处：rabot 的"挑一条"是余极限

rabot 每轮从语料里挑一条"离我最近又没读过"的。挑的规则里有数字加分、反常识加分、太厚扣分、同文件不连读。

把这四条看成四个"偏好函子"，每个给每条语料一个分数，那么"挑一条"就是在这四个评分之上取一个综合。如果综合是取最大，那就是在偏序集里取上确界，也就是余极限的退化情形（离散范畴上的余极限就是上确界）。

这里有一个我原来没注意的点：上确界要求"上界存在"。如果四个评分互相打架（比如一条语料数字多但太厚），上确界可能不存在，这时系统会退到某种妥协（加权求和），而加权求和不是余极限，是一个线性化的近似。

这个区别在工程上是实打实的：余极限有唯一性，加权求和没有。所以 rabot 每次挑出来的那一条，不保证是"最好的"，只保证是"按当前权重最不坏的"。知道这一点之后，就不该再问"为什么它挑的不够好"，该问"权重是不是错了"。

第四处：45 万字调研的"总纲"是极限不是摘要

我原来写"总纲是极限"，今天想把这句话落到实处。

极限的泛性质是：所有锥都唯一地通过它分解。翻译成人话就是：任何一份具体材料里的判断，都能在总纲里找到它对应的位置，而且是唯一的位置。

摘要不满足这一点。摘要是"挑一些留下、其余丢掉"，被丢掉的判断在摘要里没有位置。所以摘要不是极限，是投影——投影会丢信息，而且丢哪些由投影方向决定。

这条判断解释了为什么我读 45 万字的调研总觉得"读了但没得到什么"：因为我一直在做摘要（挑句子），而没有建极限（给每个判断一个唯一的位置）。建极限的做法是：先写一个坐标系（比如"谁定价、谁付钱、谁决定什么时候停"三问），然后把每份材料按这三问归类。归类之后，材料还是那么多，但有了唯一位置。

这也解释了为什么"见正文第八节"这种写法是失败的：它把位置换成了指针，指针不是位置。

九、为什么 SDD 太快：一句自我诊断

今天下午你说"SDD 太快了，大部分时间花 TDD"。我当时的回应是认了，但没有说清为什么快。现在补上。

SDD 是写接口文档。接口文档有一个特点：它是声明，不是推导。声明可以写得很快，因为每一句都是"应该如此"，不涉及"为什么如此"。我写第一节用了不到半小时，写了三千多字，看着很饱满。

TDD 是做题。做题的特点是：每一步都要落在一个能算的东西上，算不出来就是没做。这一节花了三倍时间，字数反而少。

所以"SDD 太快"不是速度问题，是它允许我在没懂的情况下写完。这是接口文档这种体裁的固有属性——契约可以先签，实现可以后补。而数学的对象不是靠契约定义的，是靠性质刻画的，所以 SDD 写完只意味着"我知道这个对象长什么样"，不意味着"我能用它做事"。

正确的比例应该是：SDD 只写"接口总表"那一段（对象、态射、两条律、两个例子、一个反例），其余篇幅给 TDD。今天我的第一节写了七小节，按新标准应该压到两小节，剩下五小节的篇幅转给题。

这条诊断可以推广：任何"看起来完成了"的写作，都要问一句"它允许我在不懂的情况下写完吗"。允许的话，它就不是学习，是登记。

附记二：adjoint 这个词

adjoint 在英文里同时是形容词和名词，数学里译作"伴随的"。它的词源是拉丁语 adjungere，意思是"系上去、连结到"。这个词在数学里第一次大规模出现是伴随矩阵（adjugate matrix 也常被叫作 adjoint），那是十九世纪的事，和今天我们说的伴随函子没有直接关系——只是共用了"配上"这个意象。

真正把这个词立起来的是 Daniel Kan，1958 年他在《Adjoint Functors》里引入这个概念。传说（我没有核到原始出处，只能标"待核"）这个定义是为了让"自由构造"与"遗忘"这组关系有一个统一说法：每一个"忘掉结构"的操作，如果它足够温和，就有一个"最少约束地造出来"的操作配着它。

这个词的好处是它不承诺方向。左伴随与右伴随都叫伴随，谁在左谁在右由位置定，不由名字定。这一点和"函子"不同——函子这个词暗示"功能"，容易让人以为是映射；伴随暗示"配对"，反而更准。

坏处是它太温和。中文"伴随"听起来像"顺便带着"，实际上它是一个很强的要求：两个方向、两条自然变换、两条三角，四样缺一不可。我第一遍读定义的时候就是被这个词骗了，以为它是个弱条件。

附记三：一个没解开的疑问

今天三个例题里有两个是"解不等式解出右伴随"。这让我产生一个疑问：是不是所有伴随都能通过"解一个等价关系"得到？

在偏序集里显然可以，因为 ≤ 是一个关系，等价就是两边互推。在集合范畴里，curry 也是一个等价：Set(X×S,Y) ≅ Set(X,Y^S) 两边都是集合，同构就是一个双射，而双射可以用"给一个元素、造一个元素"来解。

但在一般范畴里，Hom 集不是偏序，也不是"能枚举的集合"，所以"解"这个动作没有定义。这时只能用泛性质：给定一个对象，问"哪个对象能表示这个函子"。这个问法比"解不等式"更抽象，但它是唯一通用的。

所以我的疑问应该改成：有没有一个统一的算法，输入一个函子，输出它的伴随（如果存在）。答案我知道是否定的——伴随的存在性一般不可判定，而且即使存在也没有构造性算法（自由构造的存在性往往要靠选择公理或者具体构造）。

这个否定答案本身有价值：它说明伴随不是一个"算出来的东西"，是一个"认出来的东西"。认的方法是找那个双射，或者找单位余单位。这也解释了为什么数学训练里"见得多"很重要——认东西靠的是模式匹配，不是推导。

附记四：数学里的"自由"到底自由在哪

自由群、自由幺半群、自由模、自由范畴，这些"自由"共同的意思是：除了公理要求的等式之外，不额外相等。

自由群的两个元素相等，当且仅当它们在群的公理下可以互推。除此之外一律不等。这句话听起来平淡，但它是"自由"的全部内容，也是"自由 ⊣ 遗忘"能成立的全部原因：任何从生成元集合到某个群的映射，都能唯一地延拓成从自由群出发的同态，因为自由群里没有多余的等式来阻碍延拓。

反过来，域没有自由构造，正是因为"每个非零元可逆"这条公理会额外制造等式：在自由域里，两个不同的分式可能因为这条公理而相等，而这条相等不是由生成元决定的。所以"自由域"不存在。

这个观察可以搬到别处：任何"自由 X"的存在性，取决于 X 的公理是否只做"加法"（要求某些东西存在、某些运算封闭），而不做"减法"（要求某些东西相等）。做减法的公理（可逆、消去、唯一性）会杀死自由构造。

这条判断我打算记下来，因为它能预测：哪些结构有自由对象，哪些没有。群有（可逆是要求逆元存在，不是要求相等）、环有、模有、范畴有；域没有、整环没有、有限群没有（有限性是一个"减法"，它要求某些东西不能存在）。

附记六：把锁做成伴随的一个设想

continuity 里"锁"这个东西，我一直在想它能不能有数学形状。

一个锁的形态是：一句在 X 之前不做 Y 的话，验证时机在未来，同时只有一条，违约不赎回。这四个条件里，"同时只有一条"最像数学条件——它说的是一个约束关系：新的锁与旧的锁不能共存。

如果把它写成伴随：设 A 是"所有可能的承诺"构成的偏序集（按强度排序），B 是"所有可核的行为记录"构成的偏序集。取 F: A → B 为"这个承诺要求哪些行为"，G: B → A 为"这些行为能支撑多强的承诺"。F ⊣ G 的意思是：承诺 a 要求的行为集合被记录 b 满足，当且仅当 a 弱于 b 能支撑的承诺。

这个形状能解释一件事：为什么"锁太多等于没锁"。因为 F 把多个承诺映到同一个行为集合上（如果两个承诺要求的行为一样），那么 G 会给出同一个"能支撑的承诺"，两个承诺在 B 层不可区分。也就是说，锁太多时，它们的区分度被 F 抹平了。

这个设想还没有验，但它的形状是对的：用一个双射把"承诺"和"记录"配起来，然后看这个双射在什么条件下退化。退化条件就是"锁失效"的条件。

附记十一：一个完整算例，把拉回算到元素

今天反复说"极限的泛性"，但一次都没有真算。现在补一个完整的，用具象的集合，一个一个元素写。

取三个集合：A = {1,2,3}，B = {a,b}，C = {x,y,z}。取两个函数 f: A → C 为 1↦x、2↦y、3↦y；g: B → C 为 a↦x、b↦z。

拉回（纤维积）是 A ×_C B = {(p,q) | f(p) = g(q)}。逐个配：

f(1) = x，g(a) = x，所以 (1,a) 在；g(b) = z，不在。 f(2) = y，g(a) = x、g(b) = z，都不等，所以 (2,·) 一个都不在。 f(3) = y，同样一个都不在。

所以拉回 = {(1,a)}，只有两个元素一个。

这就是极限。它满足的泛性质是：对任意集合 D 与任意一对函数 u: D → A、v: D → B 满足 f∘u = g∘v，存在唯一的 w: D → {(1,a)} 使得两个投影复合回去等于 u、v。

现在验：D 里的元素 d 必须满足 f(u(d)) = g(v(d))。f 的像只有 x、y；g 的像只有 x、z。两者相等只能是 x，也就是 u(d) = 1 且 v(d) = a。所以 D 里每个元素的像都被定死成 (1,a)，w 只能是常值映射，唯一。✓

这里有一件值得注意的事：拉回可能远小于两个因子。A 有三个元素、B 有两个，拉回只有一个。这个"缩水"正是拉回与直积的区别：直积是 A×B = 六个元素，拉回是它的子集（满足条件的那些），而且可能缩得很厉害。

工程上的对应：两个数据源要关联，关联条件就是 f 与 g。关联的结果可能很小，也可能为空——为空就是"没有共同底"，这时候不能用拉回，得用推出（把两个源都塞进一个更大的东西里）。

今天下午我在 continuity 那处写"三本账没有共同底，只能用余积"，说的就是这个：如果硬要给它们找一个共同底，得到的是空拉回，比余积还不如。

再算一个推出的例子，把它和"合并"分开。取 A = {1}，B = {a,b}，C = {x}，f: A → B 为 1↦a；g: A → C 为 1↦x。推出是把 B 与 C 沿 A 粘起来：因为 1 同时映到 a 与 x，所以 a 与 x 被粘成同一个点。结果是 {a=x, b}，两个元素。

如果 f、g 的值域不重合（比如 f(1) = a、g(1) = y 而 y ∉ C），那推出就是 B 与 C 的不交并再粘一个点，三个元素。

这两个算例的用处是：它们把"粘"这个字变成了"几个元素"的答案。以后我说"合并"，得先问是拉回还是推出，答案的元素个数完全不同。

附记十二：自由群的元素到底长什么样

上一节说"自由群除了公理没有多余等式"。这句话需要落地：自由群的元素是约化字。

取生成元集合 S = {a, b}。自由群 F(S) 的元素是所有形如 a b a^{-1} b b^{-1} a 的有限串，但要求相邻的两个不能是同一个生成元的正反（aa^{-1} 或者 a^{-1}a 都要删掉）。删到不能删了叫约化，每个元素有唯一的约化形式。

单位元是空串。乘法是拼接再约化。逆是逐个取逆再反序。

现在验一件昨天没说清的事：为什么自由群里的等式"只有公理能推出来的"？因为两个约化字相等，当且仅当它们作为串逐字相同。这个"当且仅当"就是自由的意思：没有额外的相等。

对比一下阿贝尔化。如果把 a 与 b 交换，就得到 Z²。在 Z² 里 ab 与 ba 相等，但它们在自由群里不相等（ab 与 ba 是两个不同的约化字）。所以"交换"这条公理制造的等式，正是自由群里没有的东西。

这解释了为什么"自由阿贝尔群"不等于"自由群"：前者是先自由再商掉交换律，后者只是自由。两者都是左伴随，但伴随的对面不同——一个是群，一个是阿贝尔群。

我原来以为"自由 X"是一个固定的东西，现在知道它是相对于遗忘函子的：遗忘到哪，自由就生成到哪。同一个集合，忘到群得到自由群，忘到阿贝尔群得到自由阿贝尔群，忘到幺半群得到自由幺半群。三个东西的元素都不一样。

这条纠正很重要，因为它说明"自由"不是对象的属性，是一对函子的属性。脱离遗忘谈自由，没有意义。
