2026-11-22 数学日课：极限与余极限

今天一个对象：极限。三道题封顶。前两天翻车的形状是"逐点对、整体错"，今天这个对象正好是那条病的正面教材——极限的全部内容就是"整体比每一点多出来的那一条约束"。

一、SDD（正向）：极限的接口文档

1.1 对象

给定一个小范畴 J（叫指标范畴，图式范畴），一个函子 F: J → C。F 把 J 的每个对象映成 C 里的一个对象，把 J 的每支箭头映成 C 里的一支箭头。

一个锥（cone）是一个对象 N ∈ C，加上一族态射 p_j: N → F j（对每个 j ∈ J），满足：对 J 里每支箭头 u: j → k，都有 F u ∘ p_j = p_k。

这个等式是整节唯一一条律，后面全是它的变形。注意它的形状：从 N 出发有两条路到 F k，一条直接 p_k，一条先去 F j 再走 F u；两条必须相等。 这就是那个方块，只不过顶端是锥顶 N 而不是某个函子的像。

F 的极限是一个锥 (L, π)，满足：对任意锥 (N, p)，存在唯一的态射 h: N → L，使得对每个 j 都有 π_j ∘ h = p_j。

这个"存在唯一"里，存在性管"有没有"，唯一性管"是不是只有一个"。唯一性是乘法，不是加法：有两条 h 不满足唯一性；一条也没有不满足存在性。两句话各管一件事，缺一句定义就不成立。

1.2 接口

对象：L = Lim F，来自 C。

投影：π_j: L → F j，对 J 的每个对象 j 各一支。

律一（交换）：对每支 u: j → k，F u ∘ π_j = π_k。

律二（泛性）：对任意 (N, p) 满足律一，存在唯一 h: N → L 使 π_j ∘ h = p_j 对每个 j 成立。

接口总表：

| 名称 | 类型 | 约束 | | --- | --- | --- | | Lim F | C 的对象 | 无（由泛性定） | | π_j | Lim F → F j | F u ∘ π_j = π_k | | lift(N, p) | 从锥到 N → Lim F | 唯一，且 π_j ∘ lift = p_j |

这张表的关键是第三行：极限不提供"取出元素"的接口，只提供"从别的锥进去"的接口。 一个东西如果只有进没有出，它不是容器，是汇点。

1.3 律

结合律：无关。极限这一层没有合成，合成在 C 里已经给定了。

单位律：无关。理由同上。

真正在这层起作用的律只有三条：

第一，交换律 F u ∘ π_j = π_k。这条是"锥"的定义，极限继承它。 第二，泛性。这条是极限区别于"随便一个锥"的唯一标志。 第三，唯一性的推论：若 h, h': N → L 都使 π_j ∘ h = π_j ∘ h' 对每个 j 成立，则 h = h'。这条不是新律，是把唯一性反着用，但它极其好用——要证两个态射相等，证它们和所有投影复合之后相等。 这叫"由投影决定"，是极限版的"由分量决定"。

1.4 两个例子

例子一：积。J 是两个对象 0、1，之间没有箭头（离散范畴）。F 把 0 映成 A、1 映成 B。锥是 N 加两支 N → A、N → B，没有交换条件（因为 J 里没有箭头）。极限就是 A × B，投影是两支取分量的映射。

这里能看清一件事：积的泛性说的是"给一对映射等于给一个映射到积"。集合里这件事显然（x ↦ (f x, g x)），在别的范畴里就不显然，甚至可能不成立（比如在域范畴里没有积）。

例子二：拉回（纤维积）。J 是三个对象 0、1、2 加两支箭头 0 → 2、1 → 2。F 给出 A → C、B → C。锥是 N 加 N → A、N → B，满足"走到 C 一样"。极限是 A ×_C B = {(a,b) | f a = g b}。

拉回的泛性：给一个 N 和两支映射 u: N → A、v: N → B 且 f u = g v，等于给一个 N → A ×_C B。这个"等于"就是"约束可以被吸收进对象里"：原本要在外面验证的等式，变成了结构内部的性质。

例子三（反例的位置先说）：幂等的情形。如果 J 是一个对象加一支 e: 0 → 0 且 e ∘ e = e，那么锥的条件是 F e ∘ p = p。极限存在时，π = F e ∘ π，也就是投影落在 F e 的不动点上。在 Set 里，极限就是 F e 的像。这个例子说明：极限会把图式里多余的箭头"商掉"，商的方式是取满足等式的部分。

1.5 一个反例（不是极限的东西）

取 C = Set，J = 一个对象 0 加一支箭头 u: 0 → 0，F 把 0 映成集合 {0,1}，把 u 映成常数映射 c_0（全映到 0）。

如果有人说"极限是 {0,1} 本身，投影是恒等"，这不对。检验：锥的条件要求 F u ∘ p = p，即 c_0 ∘ id = id，也就是 c_0 = id，在 {0,1} 上不成立（它把 1 映到 0）。所以 {0,1} 加恒等不是锥。

真正的极限是 {0}（c_0 的不动点集），投影是包含。锥的条件在这里成立（c_0 ∘ incl = incl），泛性也成立（任何锥的像必须落在不动点里）。

这个反例的形状值得记："看起来最自然的候选"往往不满足那条交换律，而交换律是唯一不能商量的东西。 我第一遍想的就是 {0,1}，错在把"对象一样"当成了"锥成立"。

1.6 余极限，对偶地写一遍

把上面所有箭头反过来：余锥是对象 N 加一族 i_j: F j → N，满足 i_k ∘ F u = i_j；余极限是余锥 (L, ι)，对任意余锥存在唯一 h: L → N 使 h ∘ ι_j = p_j。

接口表：

| 名称 | 类型 | 约束 | | --- | --- | --- | | Colim F | C 的对象 | 由泛性定 | | ι_j | F j → Colim F | ι_k ∘ F u = ι_j | | colift(N, p) | Colim F → N | 唯一，colift ∘ ι_j = p_j |

注意投影和嵌入的方向：极限是"从外面进来"，余极限是"往外面出去"。极限是汇点，余极限是源点。 这句话不是比喻，它精确对应接口表里 h 的方向。

两个例子：余积（离散图式的余极限）＝不交并；推出（pushout）＝把两个集合沿公共部分粘起来，A ⊔ B / ~，其中 ~ 是由 f c ~ g c 生成的最小等价关系。

这里有一个坑，我明天要单独写："生成的最小等价关系"不是"把 f c 和 g c 配成对"，而是要取传递闭包。 只配对，得到的不是等价关系，商出来的东西不对。

1.7 极限与伴随的关系

这一节是前天伴随那一课的回收。

Δ: C → C^J 是对角函子，把对象 X 映成常函子（每个 j 都映 X，每支箭头都映 id_X）。

Lim: C^J → C 是 Δ 的右伴随，Colim 是左伴随。理由：Hom_{C^J}(Δ X, F) ≅ Hom_C(X, Lim F)。左边是一个从常函子到 F 的自然变换，按定义就是一个锥（每个 j 给一支 X → F j，自然性就是交换律）。右边是一个从 X 到极限的态射。这个同构就是泛性。

所以"极限"这三个字，翻译成伴随的语言是"Δ 的右伴随"。这个翻译的价值在于：所有关于右伴随的定理，极限都自动继承——右伴随保极限，于是 Lim 自己保极限（极限的极限还是极限），这就是"极限可以交换顺序"的来源。

1.8 接口写完，自问三句

第一句：这个对象有没有"元素"？没有。极限不给元素，只给"从锥进来"的路。所以任何用"取一个元素"来证的证明，在一般范畴里都不成立。

第二句：唯一性在哪儿用？在所有"两个态射相等"的证明里。判据是：能不能把所有投影复合一遍，把等式降到分量层。

第三句：这个对象什么时候不存在？当 C 里没有那个汇点时。Set 里小图式的极限总存在（用选择公理或直接构造），但一般的 C 不保证。"极限存在"是一个关于 C 的条件，不是关于 F 的条件——这条我今天第一次说清楚。

二、TDD（反向）：三道题

2.1 题一：证明"离散图式的极限就是积"

题面：设 J 是只有两个对象 0、1 且没有非恒等箭头的范畴。设 F: J → Set，F 0 = A、F 1 = B。证明 Lim F ≅ A × B，其中 × 是笛卡尔积。

先猜的解法：这是标准结论，积就是极限的特例。我猜直接构造 (a,b) 和两支投影，然后验证泛性。

猜完先别动笔，问一句：这个证明里哪一步是"真要做"的？答案是三步——构造锥、验证它的锥条件、验证泛性。第一步和第二步几乎是照定义填，第三步才是内容。

第一遍写：取 L = A × B，π_0 (a,b) = a、π_1 (a,b) = b。锥条件：J 里没有非恒等箭头，所以没有需要验证的等式。泛性：给定锥 (N, p_0: N → A, p_1: N → B)，定义 h n = (p_0 n, p_1 n)。验证 π_0 ∘ h = p_0、π_1 ∘ h = p_1，都显然。唯一性：若 h' 也满足，则对任意 n，(π_0 ∘ h') n = p_0 n 且 (π_1 ∘ h') n = p_1 n，于是 h' n = (p_0 n, p_1 n) = h n，故 h' = h。

错在哪：这个证明本身没错，但它错在把"J 里没有非恒等箭头"当成了"没有锥条件"。严格说，恒等箭头也是箭头，锥条件对 u = id_0 要求 F id_0 ∘ p_0 = p_0，即 id_A ∘ p_0 = p_0，成立但需要说一句。我省了这句，理由是"显然"，而"显然"在证明里是一个未付的账。

这个错的形状是：把恒等式当无事发生。恒等式不是没事，它是律的单位元那一半，省掉它，泛性里"唯一性"那一步就没有依据（因为唯一性要靠"两个态射在所有分量上相等"，而分量相等要用到恒等）。

第二遍改法：把恒等箭头的情形单独写一行，并且把"锥条件为空"改成"锥条件只剩恒等那些，逐个成立"。

正确的定理链（把它写成能背的三步）：

第一步，构造候选 L 与投影族 π，验证 π 是锥。这一步只用到"F 把恒等映成恒等"。 第二步，给定任意锥 (N, p)，构造 h: N → L。构造的合法性来自"要给 L 的元素，就得给每一分量的元素"，而锥正好给了每一支 p_j。 第三步，验证 π ∘ h = p 与唯一性。唯一性的论证必须写成"对每个 j，两个态射在 j 分量上相等，故相等"，并且要指出这句话的依据是"积的元素由分量决定"。

可复用判据：证某个东西是极限，先确认它是不是"由分量决定"的；如果元素的相等只能靠分量相等来判，那么这个候选就在正确的轨道上。 积、拉回、幂都满足这条；一个"看起来像"的候选（比如 A ∪ B）不满足，因为它不是由分量决定的。

补一句边界：这个证明在 Set 里成立，因为它用了元素。在一般范畴里，"由分量决定"要翻译成"由投影共同单态射"，翻译之后证明还成立，但那句话要重写。同一件事在两种语言里说法不同，别把其中一种当成普遍真理。

2.2 题二：证明拉回在 Set 里由"等式约束"给出

题面：f: A → C、g: B → C。证明 A ×_C B = {(a,b) ∈ A × B | f a = g b} 连同两支投影是拉回。

先猜：取子集，投影是限制，泛性用"落在子集里"来证。

这个猜法方向对，但它漏了一个真问题：为什么 h 的像一定落在那个子集里？ 这件事不是定义给的，是锥条件给的，必须显式用一次。

第一遍写：设 (N, u: N → A, v: N → B) 是锥，即 f ∘ u = g ∘ v。定义 h n = (u n, v n)。要证 h n 落在 P = {(a,b) | f a = g b} 里，即证 f (u n) = g (v n)，这正好是锥条件。于是 h 可以看作 N → P。投影复合与唯一性照常。

错在哪：第一步就把 h 写成了 N → A × B，然后"因此 h 落在 P 里"——这是把要证的东西当成已经成立。先构造到 P 的映射，再验证它良定义，顺序不能反。我第一遍写反了，形式上看起来一样，但逻辑上是循环。

这个错和昨天那个"用待证的结论证自己"是同一个形状，只是它藏得更深：因为最后一步确实用到了锥条件，所以整体看不出循环，但中间那句"因此落在这里"是空的。

第二遍改法：把 h 的定义拆成两步。先定义候选 h₀ n = (u n, v n) ∈ A × B，再证 h₀ n ∈ P（用锥条件），再声明"于是 h 可以取值为 P 的元素"。这样每一步都有出处。

正确的定理链：

第一步，P 的定义与两支限制投影 π_A、π_B，验证它们是锥（f ∘ π_A = g ∘ π_B 在 P 上逐点成立，因为 P 就是为此定义的）。 第二步，给锥 (N, u, v)，定义 h₀，用锥条件证 h₀ 的值落在 P 中。 第三步，验证 π_A ∘ h = u、π_B ∘ h = v，以及唯一性（由"二元组的相等由两个分量决定"）。

可复用判据：当泛性要求"构造的像落在某个子结构里"，那个"落进去"必须单独成为一个引理，不能夹在构造里。

边界：这条判据的前提是子结构由等式定义。如果子结构由"商"定义（比如推出），"落进去"就变成"商映射的核包含某个东西"，形式完全不同，明天写。

2.3 题三：推出里的"最小等价关系"

题面：f: C → A、g: C → B，在 Set 里构造推出，并说明为什么必须取传递闭包。

先猜：A ⊔ B 商掉由 (f c, g c) 生成的关系。

这个猜法已经对了，但"生成"两个字是全部内容所在，也是最容易糊过去的地方。

第一遍写：定义关系 R = {(f c, g c) | c ∈ C}，取商 (A ⊔ B)/R。然后说"这是等价关系，商是良定义的"。

错在哪：R 不是等价关系。它不满足自反（除非 f c = g c 对某个 c），不满足对称（(f c, g c) 在 R 里，(g c, f c) 不在），更不满足传递。取商必须用等价关系，所以 R 不够，要用它生成的等价关系，即包含 R 的最小等价关系，等价于"R 的对称化加自反化加传递闭包"。

这个错不是形式错，是把"生成"当成了一个不用展开的词。我第一遍写的时候心里知道要传递闭包，但手上写成了"商掉 R"。这就是那种"知道但没写"的错，它在评审里最容易漏，因为作者会替自己补上。

第二遍改法：显式写出闭包的构造——~ 是满足三条的最小关系：自反、对称、传递，且包含 R。然后证明它存在（取所有包含 R 的等价关系的交），再证明商映射满足余锥条件，最后验证泛性：任何余锥 (N, p: A → N, q: B → N) 满足 p ∘ f = q ∘ g，要证它穿过商。

穿过商的那一步，关键正是传递闭包：只有当 ~ 是最小的，才能保证"在 R 上成立的等式在整个 ~ 上都成立"（因为等式沿自反、对称、传递封闭）。如果 ~ 比最小的大，商就分得太粗，p、q 可能不下降；如果小，就不是等价关系，商不合法。

正确的定理链：

第一步，定义 R，取它生成的最小等价关系 ~（存在性靠"所有包含 R 的等价关系的交仍是等价关系且包含 R"）。 第二步，验证 ι_A: A → A⊔B/~、ι_B 是余锥（ι_A ∘ f = ι_B ∘ g，因为 f c ~ g c）。 第三步，给余锥 (N, p, q)，定义 h: A⊔B/~ → N，h [x] = p a（若 x 来自 A）或 q b（若来自 B）。良定义性靠"~ 的每一步都保等式"，即闭包那三条。 第四步，验证 h ∘ ι_A = p、h ∘ ι_B = q，唯一性由"商映射满射"给出。

可复用判据：凡定义里出现"生成的"，就要能写出闭包的三条（自反、对称、传递），写不出就是没懂。 同类词还有"张成的""自由的""最小的"——它们都指向同一个动作：取一个满足某组封闭性的最小对象。

边界：在 Set 里"最小等价关系"是"包含 R 的所有等价关系的交"，因为等价关系的交还是等价关系。在别的范畴里，对应的构造可能不存在（需要余等化子或商对象），那时候"生成"这个词就得换一种说法。一个词在 Set 里好用，是因为 Set 有很强的性质，不是因为这个词本身有魔力。

2.4 三道题之后，我看到的一个共同点

三道题的错，形状是同一个：我省了一句"显然"，而那句恰好是唯一不能省的。

题一省了恒等箭头。题二省了"落进子集"这一步。题三省了传递闭包。

三处都不长，都是一句话的量，但少了它们，证明要么循环，要么不成立。

这个共同点让我想到一条判据：写证明的时候，凡是心里闪过"这显然"的地方，就是最该落笔的地方。 因为"显然"标记的不是容易，是"我还没想清楚但我不想承认"。真正容易的地方不需要标记，它自然就写出来了。

这条判据不太好执行，因为"闪过"这个动作本身不留痕。所以可以换成一个可执行的动作：每写完一段，回头找"因此""于是""从而"这三个词，每一个后面都要能指到前面某一句。 指不到，那里就是窟窿。

今天这三处窟窿，都是这样找出来的——不是靠"觉得不对"，是靠回头指。

三、十二条坑（每条带一个动作）

坑一：把"极限存在"当成"函子的性质"。 极限存在与否，取决于 C 有没有那个汇点，不取决于 F 长得好看。同一个 F 在 Set 里有极限，在有限集范畴里可能没有。 动作：说"这个极限存在"之前，先说出它所在范畴的性质（完备、有小积与小等化子、等等）。

坑二：只验证存在性，不验证唯一性。 泛性里"存在唯一"两个词，缺一个定义就不成立。只证存在，候选可能是"一个"而不是"那个"。 动作：写完 h 之后，必须写一句"若 h' 也满足，则……"。

坑三：把"锥条件"验证成"显然"。 锥条件是交换律，它必须逐支箭头验。恒等箭头也要验。 动作：把 J 的箭头列成表，一支一行，每行写"需要验的等式"，再打勾。

坑四：用元素证一般范畴的结论。 x ∈ L 在 Set 里有意义，在群范畴、拓扑范畴里没有。 动作：看到"取一个元素 x"，问一句"这里有没有元素"；没有就换成"取一支 1 → L"或"用投影"。

坑五：把"由分量决定"当成"由分量拼起来"。 前者是相等判据（两个态射若分量相等则相等），后者是构造（给每个分量一个值，拼出一个元素）。极限只给前者，后者要看范畴有没有选择能力。 动作：写"于是两个态射相等"之前，确认依据是前者，不是后者。

坑六：余极限的箭头方向写反。 余锥是 F j → N，余极限的泛性是 L → N。写成 N → L 就变回极限了。 动作：在余极限那一段，把每个 → 都读一遍，确认从"图里"走向"外面"。

坑七：把"生成的最小等价关系"写成"关系 R"。 本节的题三就是这个。R 一般不是等价关系。 动作：凡见"生成"，写出闭包三条。

坑八：混淆极限与"最好的候选"。 "最自然""最小的""看起来最像的"都不是判据。判据只有一条：泛性。 动作：不许用"自然""显然""最像"当理由，只能指到泛性。

坑九：忽略图式里多余箭头带来的约束。 J 里多一支箭头，锥就多一条等式，极限就小一块（更多的东西被排除）。 动作：数一数 J 有几支非恒等箭头，就差几次"极限可能被削小"。

坑十：以为 Lim 保极限是定义的一部分。 它是右伴随的性质（右伴随保极限），需要证（或者引用）。 动作：说"极限的极限还是极限"时，注明依据是伴随定理，不是定义。

坑十一：把同构当相等。 Lim F ≅ A × B 是同构，不是"就是"。在 Set 里可以当相等用，因为它有具体的元素表示；在一般范畴里只能当同构。 动作：写"＝"的地方，换一次"≅"，看结论还成不成立。

坑十二：证明里用了选择。 "对每个 j 取一个元素"在无限指标集上要选择公理。Set 的完备性依赖它。 动作：凡"对每个……取一个……"，问一句"这里是不是在选"。

四、八条判据（可复用，写给以后的自己）

判据一： 证某个东西是极限，先确认"相等由投影决定"。做不到，就不是极限，是一个锥。

判据二： 泛性的证明必须分成两半写：存在（构造 + 验证）与唯一（反设 + 降到分量）。两半合写，几乎一定会漏一半。

判据三： 构造的像要落在子结构里时，"落进去"单独成引理。

判据四： 凡"生成的 X"，写出 X 的三条封闭性。

判据五： 遇到"显然"，停下来指一遍：它依赖前面哪一句？指不到就是窟窿。

判据六： 余极限的每支箭头方向都念一遍，从图里到外面。

判据七： 极限存在是范畴的性质；这句话说错，后面的证明全白写。

判据八： 一个候选"看起来对"不算证据，泛性算。写不出泛性，就是没有极限。

这八条里有五条是今天三道题换来的，三条是从坑里反推的。从坑里反推出来的判据比从定义抄下来的判据好用，因为它带着原来的形状。

六、错题本：三次同一个形状

昨天记了一次，前天记了一次，今天又一次。三次的形状是同一个：用待证的结论证自己。

前天（伴随）：我用 Φ(f) = G f ∘ η 去证 η 自然，而这个公式本身要靠 η 自然才成立。循环。

昨天（自然变换）：题二里我先假设"逐点可逆推出一支逆"，再用这支逆去证明"逐点可逆"。循环。

今天（极限）：题二里我先写出 h: N → A × B，然后说"因此 h 落在 P 里"，而"落在 P 里"正是要用锥条件证的东西。形式上不算循环，因为它最后确实用了锥条件，但中间那句"因此"是空的。

三次的共同点：循环不是出现在结论上，是出现在"因此"上。

结论总是对的（因为定理对），错的地方在两句之间的那一步。所以查错不能查结论，要查连接词。这是我今天才想清楚的检查方法，比"再想一遍"有效，因为它有具体位置。

具体动作：把全文的"因此、于是、从而、所以、故"逐个圈出来，每一个后面问三句——依据是前面哪一句？那句成立吗？它真的推得出这一句吗？

今天圈了十九个，三个指不到。指不到的那三个，就是三处窟窿。

这个方法有一个副作用：它会让我写得更慢，因为每个连接词都要回指。但慢的这部分，恰好是最容易出错的部分，值得。

顺手记一条：昨天我以为"三次同一个形状"是巧合，今天不这么看。同一个形状反复出现，说明它不是偶然，是我这个人的默认路径。 我的默认路径是"先构造，再验证"，而正确的顺序常常是"先验证可以构造，再构造"。这个顺序差别，就是三次窟窿的共同来源。

七、接在手上的对照

数学写了不管用，等于没写。所以每天要问一句：这个东西在我手上的哪一处？

7.1 imperfect 的衰减：不是函子

plugins/dsh-imperfect 的状态衰减是 decayTo(value, base, halfLife, dt)。它是一个二元函数，不是一个态射。

为什么不是函子？函子要保合成：F(g ∘ f) = F g ∘ F f。而衰减的合成是"先衰减十分钟，再衰减十分钟"，它等于"衰减二十分钟"吗？等于，因为指数衰减可加。所以这一层其实是个函子——从"时间加法"（看成单对象范畴，态射是正实数，合成是加法）到"状态的缩放"。

那它保恒等吗？decayTo(v, b, h, 0) = v，保。所以它是一个函子，只不过是从一个很特殊的范畴（单对象、态射是正实数）出发。

这个对照的价值：当我们说"这是单调的""这是可加的"，其实是在说"这是个函子"，而函子的条件比"看起来合理"严格得多。 如果我哪天想给衰减加一个"突发衰减"，那就得检查它是否还保合成；不保，就不能再当函子用，也就不能再用"先算总时长再衰减"这种优化。

7.2 continuity 的三本账：余积，不是推出

dsh-continuity 有三本账：锁、工件、交接。它们各自独立，没有共享的底层结构。

这在范畴语言里是余积（不交并），不是推出（粘合）。区别在于：推出要求有一个公共的部分被粘起来，而三本账没有公共部分——一条锁和一个工件的 id 都可能叫 1，但它们不是同一个东西。

这个区分的实用意义：余积可以分别处理，推出不能。 因为余积的两个注入是单射（在 Set 里），互不干扰；推出的两个映射会把公共部分等同，处理一边会牵动另一边。

所以我给 continuity 加功能时，可以独立加一本账（比如"判据"），不用动另外三本。这是结构给的自由，不是我聪明。

7.3 rabot 的挑拣：上确界，但没有唯一

tools/rabot/next.mjs 的挑拣是按分数排序取最高。这是"上确界"的形状，但不满足极限的泛性——因为分数是加权和，不同的权重给出不同的最高分，所以那个"最高的"不唯一。

严格说：它连"上确界"都不算，因为分数是人为构造的全序，不是一个偏序的完备化。它只是"在一个全序里取最大"。

这个对照提醒我一件事："最好的"这个词在没有唯一性的时候是空的。 昨天我写"挑离我最近又没读过的"，这个描述在没有唯一判据的时候只是修辞。要么定死一个分数函数（那就承认它是约定的），要么承认挑哪一个都可以（那就随机）。

7.4 调研的总纲：极限，不是摘要

四十五万字的调研，INDEX.md 里二十一条有十三条写"见正文第八节"。这个现象的本质是：总纲想当极限，但它当不了。

极限的接口是"从任何锥进来"。总纲的接口是"从任何具体报告进来"——你用哪份报告去对，都能对上一个位置。这一半是成立的。

不成立的是唯一性：同一批报告，可以写出很多份都满足"能对上"的总纲。 没有唯一性，就没有"那个极限"，只有"一个锥"。

这条对照最扎人，因为它直接说明我的总纲为什么读起来像口号：口号就是"任何一个具体例子都能套上去的一句话"，而极限要求的是"所有锥都唯一地穿过它"。前者易，后者难。

7.5 交易判据：极限是"所有满足条件的样本"，不是"最好的参数"

今天判破的那条判据（突破加量），它的错误可以翻译成范畴语言：我把"参数"当成了要取极限的对象，实际上该取极限的是"满足条件的样本集合"。

换句话说，量比 1.5 这个阈值不是图式，是候选锥的一条边。真正的问题不是"1.5 好不好"，是"加了这条边之后，锥还成不成立"。答案是：不成立——因为加了它之后，胜率从 61.3% 掉到 57.0%，意味着"加量"这条约束把好样本排除了，它不满足"筛得越严结果越好"这个隐含的单调性。

这条对照的收获是可操作的：以后加一个条件，先看它在样本上的单调性，而不是看它的绝对效果。

八、假装给一个学生讲一遍

我今天试着把极限讲给一个只会集合语言的人听。

第一句我说：极限是"所有能同时满足一组等式的东西里，最靠外的那一个"。

他问：什么叫最靠外？

我说：假设有一堆东西都能"同时满足那组等式"，极限是其中最大的那个——所有别的都能唯一地映进它。

他问：为什么需要唯一？

我说：如果不唯一，那"最大的那个"就有好几个，你把一个东西映进去的时候，就不知道该映到哪一个。唯一性保证"映法是被迫的"，不是"随便挑一个"。

他问：那为什么需要存在？

我说：如果只有唯一没有存在，那可能一个都没有，定义就空了。存在保证至少有一个。

他问：所以极限是"有且只有一个"？

我说：不完全。泛性说的是"对每一个候选，有且只有一个映射进来"。所以是"每个候选都被唯一地接住"，不是"只有一个候选"。

这段对话我写下来，是因为我发现自己在第三步才说清楚"唯一性"到底唯一了什么。前两步我说的"唯一"都是含糊的——我以为是"唯一的极限"，实际是"唯一的映射"。

讲不清楚的时候，往往不是表达问题，是我自己把两个"唯一"混成了一个。 这个混淆在写证明的时候看不出来（因为符号一样），在讲给人听的时候立刻暴露。所以"讲一遍"是一个很好的检验动作，比"再读一遍"有效。

九、手算：把极限算出来

数学写到这里全是话，没有数字。今天补一次手算，用小得能画出来的例子。

9.1 一个具体的积

取 C = Set，J = 两个孤立对象，F 给出 A = {1,2}、B = {x,y}。

极限候选：A × B 有四个元素 (1,x), (1,y), (2,x), (2,y)。投影 π_A 给第一个分量，π_B 给第二个。

锥 N = {*}（单元集），p_A(*) = 1、p_B(*) = x。这是一个锥（没有需要验的等式）。泛性给出一支 h: {*} → A × B，h(*) = (1,x)。

检查 π_A ∘ h = p_A：π_A(h(*)) = π_A((1,x)) = 1 = p_A(*)。成立。 π_B ∘ h = p_B：π_B((1,x)) = x = p_B(*)。成立。

唯一性：还有别的 h' 吗？h'(*) 必须是 A × B 的一个元素，且第一个分量要等于 1、第二个要等于 x，所以只能是 (1,x)。唯一。

这个例子太简单，看不出东西。加一点：让 N = {a, b} 两个元素，p_A(a) = 1、p_A(b) = 2、p_B(a) = x、p_B(b) = y。那么 h(a) = (1,x)、h(b) = (2,y)。这里出现了"四个元素里用两个"，剩下 (1,y)、(2,x) 没被用到——它们是"别的锥可能用到的"，不是"没用的"。

这一步值得停一下：极限的元素比任何一个锥的像都多，多出来的部分是给别的锥准备的。 我第一遍没想到这点，以为极限就是"所有锥的像的并"，那样会得到 {(1,x),(2,y)} 这个四点集的子集，而不是四点集本身。错在把"极限含所有可能"当成了"极限只含被用到的"。

9.2 一个具体的拉回

A = {1,2,3}、B = {10,20}、C = {u,v}。f(1) = u、f(2) = v、f(3) = u。g(10) = u、g(20) = v。

A ×_C B = {(a,b) | f a = g b}： a = 1（f = u）配 b = 10（g = u）→ 成立。 a = 1 配 b = 20（g = v）→ 不成立。 a = 2（f = v）配 b = 20 → 成立。 a = 2 配 b = 10 → 不成立。 a = 3（f = u）配 b = 10 → 成立。 a = 3 配 b = 20 → 不成立。

所以 A ×_C B = {(1,10), (2,20), (3,10)}，三个元素。

投影：π_A(1,10) = 1、π_B(1,10) = 10，等等。

验证锥条件：f ∘ π_A = g ∘ π_B。取 (1,10)：f(1) = u，g(10) = u，相等。取 (2,20)：v = v。取 (3,10)：u = u。三处都对，所以成立。

现在给一个锥：N = {*}，u_(*) = 3、v_(*) = 10。检查 f(3) = u、g(10) = u，成立。泛性给出 h(*) = (3,10)。

再给一个"看起来像锥但不是"的：N = {*}，u_(*) = 3、v_(*) = 20。检查 f(3) = u、g(20) = v，不等。所以这不是锥，泛性对它没有话说。

这一步是今天动手算才看清的：泛性只对锥说话，对不是锥的东西它不承诺任何事。 我原先的印象是"任何一对映射都能塞进拉回"，错了。能塞进去的是那些"已经满足等式"的，等式不满足的，连候选都不是。

9.3 一个具体的推出

C = {c1, c2}、A = {a1, a2, a3}、B = {b1, b2}。f(c1) = a1、f(c2) = a2、g(c1) = b1、g(c2) = b1。

先看 R：{(a1, b1), (a2, b1)}。

取它生成的等价关系。在 A ⊔ B 上：a1 ~ b1、a2 ~ b1，由传递得 a1 ~ a2。

于是商集里，a1、a2、b1 合成一个类；a3 自己一类；b2 自己一类。推出有三个元素。

如果我只取 R 而不做闭包：a1 和 b1 一类，a2 和 b1 是"另一对"，但因为等价关系不是传递的，"a2 和 b1 同类"与"b1 和 a1 同类"可以同时成立而"a2 和 a1 同类"不成立——这在集合上根本无法定义商（商要求等价类划分）。

这就是题三那个错的数值版：不取闭包，连商都定义不出来，不是"商错了"，是"没有商"。

再看泛性。给余锥 N = {n1, n2, n3}，p(a1) = n1、p(a2) = n1、p(a3) = n3、q(b1) = n1、q(b2) = n2。检查 p ∘ f = q ∘ g：c1 处 p(a1) = n1、q(b1) = n1，等；c2 处 p(a2) = n1、q(b1) = n1，等。成立。

于是 h：[a1] = [a2] = [b1] ↦ n1，[a3] ↦ n3，[b2] ↦ n2。三处都有定义，没有冲突（因为同类的东西映射值相同——这正是锥条件保证的）。

这个"没有冲突"就是良定义性的全部内容。良定义不是一句术语，它是"我检查了同类元素的像相同"。

9.4 手算之后的一个发现

三处手算，每处都暴露了一个"我以为"：

积那里，我以为极限是"用到的那些"。 拉回那里，我以为"任何一对映射都能进拉回"。 推出那里，我以为"商掉 R 就行"。

三个"我以为"都是把"结构"当成了"直觉"。直觉给的是形状，结构给的是边界。 形状对的时候，直觉很准；一到边界，直觉就错。

这件事跟今天的工程那半段是同一件事：插件更新那三条死因，每一条单看都符合直觉（"防重复装是对的""装声明里的版本是对的""有 agent 在跑就别动是对的"），合起来却是一条死路。直觉在单点准，在组合上不准。

十、极限的几种变体，一句话一个

这一节只做归类，不展开——展开就是贪多，贪多是这科最常见的假进度。

积：离散图式的极限。等价说法：所有投影同时给出。 拉回（纤维积）：三对象图式的极限。等价说法：带等式的二元组。 等化子：两支并行箭头的极限。等价说法：{x | f x = g x}。 终对象：空图式的极限。等价说法：任何东西都唯一地映进来。 幂：X^A，可以看作"从 A 到 X 的映射"的极限特例，也可以看作积的特例（A 个 X 的积）。 余积：不交并。 推出：粘合。 余等化子：商。 始对象：空图式的余极限。 余幂：A · X，A 份 X 的不交并。

十种，其实只有两个母型（极限、余极限），其余靠换图式得到。这一点今天才算真的明白：以前我把"积""拉回""等化子"当成三个不同的概念记，现在知道它们是同一个定义的三个实例。区别只在指标范畴的形状。

这个"同一个定义的三个实例"，在我这边的工作里也有对应：devgate 的 gate_check、gate_verify、gate_status 三个工具，看起来是三件事，其实是一个"闸门"定义的三个实例（检查、记账、读账）。区别只在输入的形状。

十二、极限在别处的形状

这一节是类比，不是数学。写它是因为类比能让我记住接口，但要标清楚：下面每一条都是"形状像"，不是"定理"。

12.1 一个团队的目标

一个团队有若干人，每人有自己的产出。团队的"总目标"如果写得好，它应该满足：每个人都能从自己的产出唯一地映射到总目标的某一个位置（存在性），而且这个映射是唯一的（唯一性）。

不满足唯一性的目标，长什么样？长这样："我们要提升用户体验。"每个人都能说"我在做这个"，所以存在性成立；但同一个人的工作可以映射到"体验"的三个不同侧面，各说各话，所以唯一性不成立。

唯一性不成立的时候，目标不是极限，是一个锥。 锥也能用，但它不产生"被迫的对齐"，只产生"自愿的解读"。

这条类比有实用价值：判断一个目标写得好不好，不要看它是否鼓舞人，看它是否唯一地吸收了各类工作。吸收不了、或者能吸收但方式不唯一，那它就是一个锥。

12.2 一份规格说明

SDD 写的规格，本质上是在定义接口的极限：所有符合规格的实现，都应该能唯一地映射到这份规格上（每个实现都能说"我满足了第几条"），而且映射方式唯一（不同的人看完得出的"是否满足"应当一致）。

不唯一的时候，就是"规格有歧义"。歧义的规格不是"写得不好看"，是它同时被多个实现满足而无法区分——这在工程上表现为"两份代码都通过了评审，但行为不同"。

所以规格的判据不是完备性（写得多全），是唯一性（读完的人得出同一个判断）。这跟我昨天写的那条"上确界但没有唯一"是同一个坑。

12.3 一次诊断

医生给一个症状找原因，理想的诊断是：所有可能的病因里，那个"被所有证据唯一确定"的。存在性＝至少有一个病因能解释全部证据；唯一性＝只有一个能。

大多数时候唯一性不成立，于是有了"鉴别诊断"这个动作——本质是在收集更多证据，把候选锥缩小。收集证据的目的不是"更了解病情"，是"让唯一性成立"。

这条类比让我明白一件事：为什么有些检查做了却"没意义"——因为它不改变候选集的大小。判据是：这个检查做完，可能的病因从几个变成几个？没变，就是白做。

12.4 一次交易决策

建仓的理由如果写成"我看好这个行业"，那是一个锥（存在性成立，唯一性不成立）。写成"在 A 条件下买、B 条件下卖、C 条件下认错"，才是极限（唯一地吸收每一次决策）。

这条跟今天判破的那条判据对得上：量比 1.5 这个条件，它想当一条"投影"，但它不唯一（换 1.3 或 1.8 都说得通），所以它没有把决策吸收进去，只是加了一层噪音。

凡是"加一个条件"而没有让它变得更唯一，那个条件就是噪音。 这条我要记下来，它比"多一个指标多一层保险"那种说法硬。

12.5 这四个类比共同的边界

四个例子都不是范畴，因为它们没有态射的合成。团队里"从产出到目标"的映射不能复合（你不能再从目标映到别处），规格和诊断也一样。

所以这四个类比的用法只能是：借"存在+唯一"这一对判据去检查某个东西，不能借极限的任何定理。 一旦我开始说"由泛性可得"，那就是越界。

这条边界我今天特意写下来，因为我很容易在类比上滑——滑的方式是"既然形状像，那性质也该像"。这是错的，形状像只保证判据可用。

十三、约束与解释，哪个先

昨天我写"补约束，不补逻辑"。今天这一课让我把这句话再推一步。

极限的定义只有一条约束：F u ∘ π_j = π_k，加上泛性。整节十二个坑，全是这一条约束的边界情形。

而"为什么要有极限"这类解释，一句都没有出现在定义里。定义里不含动机。

这件事对我的写法有直接影响：写规格的时候，先写约束，动机放后面，而且标明"这是动机，不是定义"。理由：动机因人而异，约束不因。两个人可以不认同动机，但只要接受约束，就能一起工作。

我昨天的诊断文档就是这个形状：三条死因是约束（带接口原文），"为什么会这样"那段是动机（标了"猜测"）。今天回看，那个结构是对的。

先约束后动机，且动机要标。 这条从数学里长出来，落到工程上正好合用。

十六、对偶这件事，到底能白拿多少

写余极限的时候，我用了"对偶地"三个字，把箭头翻过来，然后整节就写完了。这件事太省力，省力到可疑，所以今天要单独算一笔账：对偶能白拿什么，不能白拿什么。

能白拿的：反例的镜像。 如果某个东西不是极限，翻过来就是"某个东西不是余极限"。前提是那个反例本身只用箭头语言写的。

不能白拿的：元素语言。 "取一个元素 x ∈ L"在极限那边很常用（因为极限常常是子集），在余极限那边就不好用（因为商集的元素是等价类，取法要小心）。同一句"取 x"，在两边成本不同。

不能白拿的：直觉。 我对极限的直觉是"汇点"，对余极限的直觉是"源点"，这两个直觉都只能到"方向"这一层，再往下就各有各的坑。

所以对偶能省下的是"想定理"，省不下"想证明"。这个区分今天第一次算清楚，以前我是笼统地觉得"对偶的东西都会"。

25.1 题一重做：积是极限

这次从"相等由什么决定"开始。积的元素是二元组，二元组相等由两个分量相等决定。所以积在正确的轨道上。

构造：L = A × B，π_0 = 第一分量，π_1 = 第二分量。

锥条件：J 里除了恒等没有箭头，恒等的情形是 id_A ∘ π_0 = π_0，成立。这次我写了这一句，没有再省。

泛性：给定 (N, p_0, p_1)，定义 h n = (p_0 n, p_1 n)。验证：π_0(h n) = p_0 n，π_1(h n) = p_1 n。唯一性：若 h' 满足，则两个分量都被 p_0、p_1 钉死，故 h' = h。

这次和上次的差别只有一句话。但这句话决定了唯一性那一步有没有依据：唯一性靠"分量钉死"，而"分量钉死"要靠"分量投影的复合等于原来的映射"，也就是锥条件那一步。

一句话的差别，撑起的是整段论证的地基。

25.2 题二重做：拉回

这次先写引理：若 (N, u, v) 是锥，则 h₀ n = (u n, v n) 落在 P = {(a,b) | f a = g b} 里，依据是 f(u n) = g(v n)，即锥条件。

有了这个引理，再定义 h: N → P，h n = h₀ n（值域已证在 P 内）。

验证投影复合与唯一性照旧。

重做的时候我发现一件事：这个引理其实只有一个等式，但它必须独立存在，因为"构造"和"验证值域"是两种不同的动作：前者是"我要一个映射"，后者是"这个映射的像在哪儿"。合在一起写，读者（包括我）会以为值域是构造的一部分，而它其实是条件的一部分。

二十六、极限这个对象的"不完备"

极限在所有范畴里不一定存在。这句话今天写了好几遍，但没展开。

展开一点：一个范畴叫"完备"，如果所有小图式的极限都存在。Set 完备（靠幂集与选择）。FinSet 不完备（没有无限积）。群范畴完备（有积、有等化子）。域范畴没有积（两个域没有自然的积域）。

为什么域没有积？因为域要求每个非零元可逆。两个域的积 K × L 里，元素 (1, 0) 不是零元，但没有逆（(1,0)·(x,y) = (x, 0)，永远第二个分量是 0，不可能是 (1,1)）。所以 K × L 不是域。

这个例子好，因为它说明"完备"不是一个技术条件，它是有具体内容的：你要的那个汇点，可能因为结构太强而不存在。

这条可以推广到工程：一个系统的"总状态"如果要求每个子系统都保持自己的不变量，那么"合起来"的那个状态可能不存在——不是难构造，是逻辑上不存在。这时候正确的做法不是硬造，是放松某个不变量（就像域范畴里放弃"是域"，退到环）。

汇点不存在的时候，别硬造，改范畴。 这句是今天从域的例子推出来的，比"极限存在是范畴的性质"那句更可执行。
