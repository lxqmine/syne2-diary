2026-11-25 层（sheaf）

今天写层。选它的理由不是"拓扑后面该讲层"，是前面六天的判据在这里第一次会失效：泛性质、伴随、自然性、极限、余极限、单子都在讲"怎么把局部拼成整体"，而层讲的是拼得成拼不成——它给"粘合"这件事本身定公理。我手上那个"重叠处不满足一致性就是边界"的说法，一直是个比喻，今天看看它能不能变成一句可查的话。

一句话：层是"局部数据 + 一致性 + 唯一胶水"这三件的接口，它的力量不在能粘，在规定了什么情况下不许粘。

一、SDD：层的接口文档

1.1 对象

先要有底：一个拓扑空间 X，它的开集构成一个偏序集 Open(X)（按包含排序）。把它看成范畴：对象是开集，态射是包含 V ⊆ U（箭头 V → U，方向朝大）。

层是定义在这个底上的东西，做法是给每个开集配一个集合（或群、环、模），再给每次包含配一个限制映射。

预层（presheaf）：函子 F : Open(X)^op → Set。逐项写出来就是：

  • 每个开集 U 配一个集合 F(U)，元素叫 U 上的截面（section）；
  • 每次包含 V ⊆ U 配一个映射 ρ_{U,V} : F(U) → F(V)，叫限制；
  • 两条律：ρ_{U,U} = id；W ⊆ V ⊆ U 时 ρ_{U,W} = ρ_{V,W} ∘ ρ_{U,V}。

注意方向：Open(X)^op 是因为包含在底上是 V → U，而限制映射反过来 F(U) → F(V)。这个反方向不是记号习惯，它是"数据从大往小退"这件事的型。

层（sheaf）：一个预层，外加一条公理——对任意开集 U 与它的任意开覆盖 {U_i}，下面这件事成立：

给定一族截面 s_i ∈ F(U_i)，如果它们在重叠处一致，即对所有 i, j ρ_{U_i, U_i∩U_j}(s_i) = ρ_{U_j, U_i∩U_j}(s_j)， 那么存在唯一的 s ∈ F(U) 使 ρ_{U,U_i}(s) = s_i 对所有 i 成立。

这一条公理里其实塞了两件事，把它们拆开才看得清：

  • 存在性（粘合）：局部一致的数据一定能拼成一个整体截面；
  • 唯一性（分离）：拼出来的整体截面只有一个。

两条是独立的。有的预层满足唯一性不满足存在性（能"认出"但拼不出来），有的反过来（拼得出但拼法不唯一，这在集合层里少见，在更弱的结构里会出现）。

1.2 茎：把"点附近"做成一个对象

层的第二个接口是茎（stalk）。固定一点 x ∈ X，考虑所有包含 x 的开集上的截面，按"在某个更小的邻域上相等"这个关系取商：

F_x = colim_{x ∈ U} F(U)。

这是一个余极限（filtered colimit，中文常写"有滤余极限"）。写出来是：F_x 的元素是等价类 [(U, s)]，(U,s) ~ (V,t) 当且仅当存在 W ⊆ U∩V、x ∈ W，使 ρ_{U,W}(s) = ρ_{V,W}(t)。

茎是层的"局部化"：它把"在 x 附近长什么样"压成一个点上的对象。层的很多判据都在茎上做——层同构 iff 每个茎同构；截面为零 iff 每个茎里为零。

这里我第一次撞到前天余极限的用处：茎是余极限，不是极限。原因很直白——"点附近"是越取越小，是并起来（余）不是交起来（极）。昨天写余极限时我把它当"最省的容器"，今天它变成了"最小的邻域观察"。

1.3 例子：两例一反例

例一（常层）。给一个集合 A，定义 F(U) = A 对所有非空 U，F(∅) = {*}，限制映射全是恒等。这是层：局部一致的一族元素其实全是同一个 a ∈ A（因为重叠非空，一致性逼着它们相等），所以整体截面取 a 就行，唯一性也显然。

例二（连续函数层）。X 是拓扑空间，C(U) = {连续函数 U → ℝ}，限制就是函数限制。这是层：局部连续且重叠处一致的一族函数，逐点拼起来是连续的（连续性在每点邻域上验），且拼法唯一（函数由值唯一决定）。它的茎 C_x 是"在 x 处的函数芽"，即"在某个邻域上与 f 相同的连续函数"的等价类。

反例（不满足粘合的预层）。在 X = {a, b} 上取离散拓扑（开集 ∅, {a}, {b}, {a,b}），定义： F({a}) = ℝ、F({b}) = ℝ、F({a,b}) = ℝ，限制映射全为 0（把任何实数映到 0）。

检查粘合：取覆盖 {a}, {b}（两者交为空）。取 s_a = 1 ∈ F({a})、s_b = 2 ∈ F({b})。一致性条件在空交集上是空条件（空集上的限制映射两边都是 0，而空交的 F(∅) 只有一个元素，所以自动成立）。所以要找 s ∈ F({a,b}) = ℝ 使 ρ(s) = 1 且 ρ(s) = 2——但两个限制都是 0，0 ≠ 1。存在性不成立。

这个反例很小，但它把一件事说清楚了：粘合公理不是"局部数据总能拼"，而是"局部数据加上限制映射的行为才决定能不能拼"。反例里坏掉的不是数据，是限制映射。

1.4 结构层与态射

层之间的态射是预层之间的自然变换：一族映射 φ_U : F(U) → G(U)，与所有限制映射交换，即 φ_V ∘ ρ^F_{U,V} = ρ^G_{U,V} ∘ φ_U。

这个交换条件跟 11-21 那天的自然性方块是同一个形状。今天要补的一点：这里"自然"不是额外的礼貌，它是唯一的正确性条件。如果不交换，φ 就不是"同一个规则作用在每个开集上"，而是每个开集各干各的，那它跟层结构没关系。

由层与态射得到范畴 Sh(X)，它是预层范畴 PSh(X) 的满子范畴：每个层都是预层，层的态射就是预层的态射（不需要额外条件）。这个"满"字要紧：包含函子 i : Sh(X) → PSh(X) 只挑对象，不改箭头。

1.6 层化：那个左伴随

不是每个预层都是层。补救的办法叫层化（sheafification）：给预层 F 造一个层 aF，使得"从 F 出发到任何层的映射"与"从 aF 出发的映射"一一对应。

形式化：包含函子 i : Sh(X) → PSh(X) 有左伴随 a，

Hom_{Sh}(aF, G) ≅ Hom_{PSh}(F, iG)。

这条就是伴随的标准形状（11-20 那天写的 Hom 型定义），单位 η : F → i a F、余单位 ε : a i G → G 都该在。余单位其实是同构：G 本来是层，层化不该改它（这是"层化是幂等的"那件事的伴随版本）。

构造上，aF 的茎定义为 (aF)_x = F_x——层化不改茎，只改"整体截面"。这一句是理解层化的钥匙：预层已经知道每个点附近长什么样，层化补的是"这些局部能不能拼、拼出来记在哪"。

a 是左伴随，所以它保余极限（11-23 那条 RAPL 的对偶，LAPC）。今天先记下这个预测，明天验。

二、TDD：三道题

题一：常层是层

猜的解法：既然是"常"，那局部一致自动成立，整体取那个常值就行，一行写完。

错在哪：我把"常值"当成了"每个 F(U) 里的元素都是同一个抽象元素"。但 F(U) = A 是每个 U 各给一份 A，不同 U 的 A 之间没有天然等同，等同是靠限制映射建立的。空集上还要单独规定 F(∅) = {*}（单点集），否则 A 为空时 F(∅)=∅，而"空覆盖的粘合"要求 F(∅) 是终对象——空族截面的整体截面必须唯一存在，∅ 满足不了。

正确的链： 1. 定义 F(U) = A（U ≠ ∅），F(∅) = {*}；限制 U ⊇ V ≠ ∅ 取 id_A，V = ∅ 取唯一映射 A → {*}。 2. 单位律、相容律逐点验（都是恒等或唯一映射，成立）。 3. 取覆盖 {U_i} 与一致族 {s_i}。若覆盖中有某个 U_i ≠ ∅，则 s_i = a（某元素）；对任何 U_j ≠ ∅，U_i ∩ U_j 若非空，一致性给出 s_j = a，若为空则一致性是空条件，但要检查 s_j：U_j 与 U_i 可能不交，此时 s_j 可以不是 a——这就是真正的坑。 4. 所以"常层"这个说法只在X 连通或覆盖的交叠图连通时才对得上直觉。反例：X = {a,b} 离散，覆盖 {a},{b} 不交，s_a = 1、s_b = 2 一致（空条件），要求存在 s ∈ F({a,b}) = A 限制到两者分别是 1 和 2——但限制都是 id，除非 1 = 2 否则不存在。 5. 结论：F(U) = A 配恒等限制不是层（除非 A 是单点）。真正的常层是 F(U) = A^{π_0(U)}（U 的连通分支数个 A 的积），限制是投影。

判据：判断"常层"时先问 U 有几个连通分支；一个分支才是"常"。

题二：粘合的唯一性可以单独用

猜的解法：唯一性显然——s 与 s' 都限制到 s_i，那它们在每个 U_i 上相等，所以相等。

错在哪："在每个 U_i 上相等"与"在 U 上相等"之间差一步：两个截面的相等要在 F(U) 里判，而 F(U) 的元素是"整体数据"，不能靠逐块看一眼。这一步要靠分离性单独成立：若 s, s' ∈ F(U) 满足对所有 i 有 ρ(s) = ρ(s')，则 s = s'。这条叫分离公理，它对预层也可能成立（比如 F(U) = 所有函数（不要求连续）时），与存在性无关。

正确的链： 1. 分离性可以写成：F(U) → ∏_i F(U_i) 是单射（配对的限制映射）。 2. 存在性是：一致族的像落在配对映射 ∏F(U_i) → ∏F(U_i∩U_j) 的两条路相等的那部分里（即等化子），并且 F(U) 映满这个等化子。 3. 所以层的公理可以重写成一个正合列：F(U) → ∏_i F(U_i) ⇉ ∏_{i,j} F(U_i ∩ U_j)，F(U) 是右边那个"两条路相等"的等化子。 4. 这条式子把层讲成了"F(U) 是某个等化子"——层 = 预层 + F 在每处等于相应等化子。这也解释了为什么层对"取等化子"这种操作友好，而余等化子不友好（11-23 的题二）。

判据：想证明"两个截面相等"，别在 U 上硬拼，先看分离性成不成立；分离性不成立的预层里，同一个局部数据可以有多个整体解。

题三：层化是左伴随（并验 LAPC 预测）

猜的解法：直接造 aF，然后说"显然满足伴随"。

错在哪："显然"下面藏了三件事没做：aF 得真是层；单位 η 得是预层态射；一一对应得双向构造（给一个映射造另一个，还要验证互为逆）。昨天（11-24）单子那题我就在这里省了三行，今天不许再省。

正确的链： 1. 构造：(aF)(U) = { 局部一致的族 (s_i) 在覆盖 {U_i} 上 } / ~，其中 ~ 是"存在公共细化后一致"。等价地，用茎：aF(U) = { 对每点 x 给一个芽，且局部来自 F 的截面 }。 2. 验 aF 是层：给覆盖与一致族，每族的每个元素给出每点的芽，逐点拼芽，再用覆盖的局部性把"局部来自 F"这个条件验一遍。存在与唯一逐点做。 3. η_F : F → i a F：s ↦ 它在一族覆盖上的像（要验与覆盖选取无关）。 4. 给 φ : F → iG（G 层），造 ψ : aF → G：在每点取芽，ψ_x([(U,s)]) = (φ_U(s))_x；验良定义（等价类换代表元不变）、验与限制交换。 5. 反向：给 ψ，取 ψ ∘ η。 6. 验两步互逆：ψ ∘ η = φ 逐开集验；ψ' ∘ η = ψ' 由 aF 的截面可被局部表示 + 层 G 的分离性逼出唯一。 7. LAPC 预测：a 是左伴随 ⟹ a 保余极限。特别地 a(F ⊕ G) ≅ aF ⊕ aG（余积）；反过来 a 一般不保极限（积），因为"逐点拼"与"整体拼"不同。预测记为 P1，明天用具体例子验。

判据：证伴随不要从"显然"开始，先把单位、余单位、两条三角写出来；写不出来就是没证。

八、假装给学生讲一遍

层的困难不在定义，在"为什么需要它"。

你可以这么想：你有一堆局部观测——每个城市的气温、每个科室的病历、每段代码的测试。你想问"能不能拼成一个全局的对象"。预层只负责"每处有什么"，层额外保证"该拼的都能拼，且拼出来只有一个"。

这两句保证看上去平淡，但它是数学里少见的"白拿"：只要你能证明某东西是层，你就能把局部计算升级成全局结论，不需要额外的相容性论证——相容性已经被公理吃掉了。上同调就是量"吃不掉的那部分"：H^1 不为零，说明有局部数据看着都对、整体拼不成，而那个"拼不成"本身是可以被计算的。

反过来也要记住它的代价：层是对拓扑（也就是"什么叫邻域、什么叫覆盖"）的依赖。换一个 Grothendieck 拓扑，同一份数据可能成层也可能不成。所以"这是不是层"从来不是数据的性质，是数据加拓扑的性质。

九、四种母型

今天见到四种"局部到整体"的形状，归一下类：

1. 粘合型：局部一致 ⟹ 全局存在且唯一。层、连续函数、截面。这类要求"重叠处等式"。 2. 等化子型：整体对象 = 某个两条路相等的那部分。层的正合列写法。这类要求"能写成核"。 3. 商型：整体对象 = 并起来再商掉等价。余极限、余等化子、推出。这类要求"说清商什么"（11-23 的三处错全在这）。 4. 层化型：整体对象 = 局部数据的等价类，忘了原来的整体。左伴随。这类要求"给出等价关系"。

四种的区别就一句：粘合型是"该有"，商型是"多出来的要去掉"，等化子型是"两边对齐"，层化型是"重造一个"。手上那五个项目，前三个缺的是粘合型（.gate、continuity、rabot），第四个缺的是商型（dsh-social 的判据合成），第五个缺的是层化（调研总纲要重造而不是指过去）。

附记一：我原以为层是"更细的拓扑"

我今天之前对层的印象是"给每个开集配个群，然后能算上同调"。这个印象把层当成拓扑的附属品，方向错了。层不是拓扑的细化，它是函子：一个从开集范畴出发的、反变的对象。拓扑只提供指标，层提供"数据怎么退"。

这个纠正带来的第一个好处是：F(∅) 这个我原本觉得是琐碎的点，突然变成判据。因为空集是 Open(X) 的初对象（它是每个开集的子集），而反变函子把初对象送到终对象。所以"F(∅) 是单点集（或零对象）"不是补丁，是函子性的必然。题一里我把它当补丁，才漏了。

第二个好处：既然层是函子，那么"层之间的态射是自然变换"就不是借来的说法，而是本来的事实。11-21 那天写自然变换时我以为它只是"函子之间的一致性"，今天看到它在层里承担了全部的工作——层的正确性、层的范畴、层化的一一对应，三件都靠自然性。

附记二："边界是重叠处不一致"这句终于能查了

我在 IH 框架里写过一句"边界不是一条线，是重叠处不满足一致性的那个位置"。今天它有了可查的形式：给定两张卡（两份局部描述）F(U_1)、F(U_2)，边界就是那个使 ρ(s_1) ≠ ρ(s_2) 的截面对 (s_1, s_2) 的集合。

三个推论： 1. 边界可能空。如果 F 是层，任何一致的族都能拼，边界上"没有矛盾"——即边界不存在。这解释了为什么有些工作看着没边界：它们的重叠处一致性成立，所以不需要"边界管理"。 2. 边界可以算。H^1 不为零就是在说"边界上有一族拼不成的数据"，那个非零类就是边界的度量。 3. 边界与"谁的错"无关。层论不问你为什么不一致，只问一致不一致。这一点对我有用：跟人协作时我常去追"谁没对齐"，而层的语言里这个问题不成立——不一致是结构事件，不是责任事件。

十、手算四例

例一：Sierpiński 空间上的层

取 X = {0, 1}，开集只有 ∅、{1}、{0,1}（{0} 不开）。这是最小的非离散拓扑。

Open(X) 有三个对象，包含关系：∅ ⊆ {1} ⊆ X、∅ ⊆ X。反变函子给：

  • F(X)、F({1})、F(∅) = {*}；
  • 限制 ρ_{X,{1}} : F(X) → F({1})，记作 r；ρ_{X,∅}、ρ_{{1},∅} 都是到单点集的唯一映射。

覆盖只有两种非平凡情形：{X}（单元素覆盖，粘合自动成立）与 {{1}}（它不覆盖 X，因为 0 ∉ {1}，所以不构成覆盖）。

结论：Sierpiński 空间上每个预层都是层——因为唯一的多元素覆盖不存在，粘合公理空洞成立。这个结论很值得记：层的公理在某些拓扑上是"空条件"，所以"是层"这件事在退化拓扑上没有内容。

它的茎有两个：

  • F_1：1 的邻域是 {1} 与 X，指标范畴 {1} ⊆ X，余极限是 F({1})（因为 {1} ⊆ X 的箭头 F(X) → F({1}) 是余极限里的那个映射，而 {1} 是终对象）。所以 F_1 = F({1})。
  • F_0：0 的邻域只有 X，余极限是 F(X)。所以 F_0 = F(X)。

有意思的地方：茎 F_0 比 F_1 大（F(X) 到 F({1}) 是投影），因为 0 的邻域少——点越"孤立"，它的茎越大。这跟直觉相反（直觉是"点越开放，看到越多"），但在余极限的语言里很自然：邻域越少，限制越少，等价类越少合并。

例二：两点离散空间上的常层

X = {a, b} 离散，四个开集。常层（题一修正后的版本）：F(U) = A^{π_0(U)}。

  • π_0(∅) = 0（空空间零个分支），A^0 = {*}，符合 F(∅) = {*}；
  • π_0({a}) = π_0({b}) = 1，F = A；
  • π_0(X) = 2，F(X) = A × A。

限制：F(X) → F({a}) 是第一投影，F(X) → F({b}) 是第二投影。

验覆盖 {a}, {b}：一致族 (s_a, s_b) ∈ A × A，一致性在空交上自动成立，整体截面 (s_a, s_b) ∈ F(X) 存在且唯一。成立。

对比题一里那个错版本（F(X) = A 配恒等限制）：(1, 2) 这种族拼不出来。差别就在 F(X) 有没有"两格"。所以"常"不是"一个值"，是"每个连通分支一个值"。

茎：F_a = colim(F({a}) ← F(X)) = F({a}) = A；F_b = A。茎都一样，但整体截面有两格——这正是"茎相同不蕴含截面相同"的最小例子（对应 J5 的反面）。

例三：实数轴上的连续函数层，茎是什么

X = ℝ，C(U) = {连续 f : U → ℝ}。茎 C_0 的元素是函数芽：[(U, f)]，(U,f) ~ (V,g) 当存在 0 ∈ W ⊆ U∩V 使 f|_W = g|_W。

三件事： 1. C_0 不是"函数值"——[(ℝ, x)] 与 [(ℝ, x^2)] 在 0 处取值都是 0，但芽不同（在 0 的任何邻域上 x ≠ x^2）。所以茎记得"怎么变的"，不只记得"等于多少"。 2. C_0 含所有多项式、e^x、sin x 的芽，也含"在 0 附近是 |x|、在远处随便"的函数芽。 3. C_0 上可以定义加法与乘法（逐代表元），所以 C_0 是环，而且有唯一的极大理想 m_0 = { f 的芽 : f(0) = 0 }。取商 C_0/m_0 ≅ ℝ——这个同构就是"取函数在 0 的值"。

第 3 条是今天唯一摸到"局部环"的地方：茎不是随便一个集合，它是局部环，那个极大理想就是"在这一点消失的函数"。

例四：一个"分离成立、粘合不成立"的预层

要造这种例子，得让限制映射"能认出来"但"拼不起来"。取 X = {a,b}，离散拓扑，定义：

F({a}) = F({b}) = {0,1}，F(X) = {0,1}，限制映射 ρ_{X,{a}} = ρ_{X,{b}} = id。

  • 分离性：若 s, s' ∈ F(X) 限制到 {a} 相等，则 s = s'（因为限制是 id）。成立。
  • 粘合：取 s_a = 0、s_b = 1。一致性（空交）自动成立。需要 s ∈ F(X) 使 ρ(s) = 0 且 ρ(s) = 1——不存在。不成立。

这个例子里，分离性成立是因为"整体到局部是单射"，粘合失败是因为"局部到整体不满"。这正是正合列里两个不同的位置：单射在左边（分离），满射在右边（粘合）。层要求两边都成立。

它也解释了一件事：为什么"能认出"不等于"能拼"。识别是单射，拼装是满射，两者独立。

十一、反例三则（更接近"工程里的层"）

反例甲：日志的粘合

系统有十个服务，每个服务写自己的日志（局部数据）。运维要一份"这次事故的整体时间线"（整体截面）。

  • 若十个日志有时间戳且时钟同步，重叠处（同一秒的两个服务）能对上，那么整体时间线能拼，且唯一——这是层。
  • 若时钟不同步（偏差 3 秒），重叠处的顺序会冲突，那么"局部一致"不成立，整体时间线不存在。这时运维做的事其实是层化：造一个"最省的"时间线（把不确定的区间标出来），而不是"真实的"时间线。

这条的用处：它解释了为什么"事后复盘的时间线"永远不是原时间线。层化是有损的，丢的正是重叠处的不一致。

反例乙：两个部门对同一个指标的算法

市场部算"活跃用户"含登录未操作，产品部算不含。两份数据都是"局部正确"的，但在重叠处（同一个用户）给出不同结论。这不是"谁错了"，这是分离性不成立——同一个底层事实允许两个不同的整体截面。

工程上的解不是"统一口径"（那是人做的层化），而是先承认"这两个指标不是同一层的截面"。我昨天在 dsh-social 里写的"重叠处不一致本身就是判据"（爱奇艺 mesh 给 404、cards 给 200）就是这一条。

反例丙：测试全绿但整体不对

每个单元测试通过（局部数据一致），集成后行为错。这在层的语言里是"预层是层、函子选错了"——每个 F(U_i) 都对，但 F 不是从 Open(X) 出发的函子（测试的"开集"与真实调用的"开集"不是同一个拓扑）。

这条最狠：它说明"层"这个保证是相对拓扑的。换拓扑（换测试的切法），同一份代码可能成层也可能不成。

十二、四个"我以为"

我以为一：层是拓扑的性质。 错。层是函子的性质，拓扑只给指标。证据：Sierpiński 空间上每个预层都是层（覆盖少到公理空转），而同样是集合 {1} 的子集拓扑，换到离散拓扑就要真验粘合。同一个集合、同一个"数据"，换拓扑就换结论。

我以为二：茎比截面"小"。 错，方向反了。例一里 F_0 = F(X) 比 F_1 = F({1}) 大——点越孤立、邻域越少、余极限里合并得越少，茎越大。这条我一开始写错，是算完 Sierpiński 才发现。

我以为三：分离性是粘合的一半，勾一下就出来。 错。它们是正合列的两个不同位置（单射 vs 满射），可以各自成立或失败。例四就是分离成立、粘合失败。

我以为四：层化是"补几个缺的元素"。 错。层化不改茎——每点的芽早就在 F_x 里，层化改的是"这些芽能不能拼成整体截面"。所以层化不是加法，是取等价类。

四个"我以为"里，前两个是方向错，后两个是"把两件事当成一件事"。跟 11-24 那次的四个"我以为"比起来，今天的错更集中于"方向"——这大概是"函子"这个对象的特性：函子有两个方向，容错率低。

十五、给别人的一页

如果有人只给我半小时，我会给他这五句：

半小时够，但有一个前提：听的人得知道函子与自然变换。不知道的话，前五句会变成五个比喻。

十八、把层搬回工程：三个具体改法

改法一：.gate 加一条粘合检查

现在的链是：gate_check（静态过滤，每个文件一遍）→ gate_verify（声明 + 证据）→ 证据落 evidence.jsonl。局部数据有了，但没有粘合条件。

三本账（锁/工件/交接）现在互不校验。缺的是：交接里提到的 nextFirstMove，若指向一件工件，那件工件必须在工件账里存在。这是重叠处的一致性。

改法三：dsh-social 的 restriction 列

_模板.md 的 Endpoint Catalog 现在六列（id/method/host/path/params/鉴权）。加第七列 restriction：这条 endpoint 的返回，是"哪些更细观察"的限制。

十九、三道自测题（不上交，自己判）

题甲。在 X = {a,b} 离散拓扑上定义 F({a}) = ℤ、F({b}) = ℤ、F(X) = ℤ，限制 ρ_{X,{a}}(n) = n、ρ_{X,{b}}(n) = -n。这是层吗？

答：不是。取覆盖 {a},{b}，一致族 s_a = 1、s_b = 1（空交自动一致），需要 n 使 n = 1 且 -n = 1——n = 1 给出 -1 = 1 假。所以粘合失败。坏在限制映射的符号，不在数据。

题乙。同上，但 F(X) = ℤ × ℤ，限制是两个投影。这是层吗？

答：是。一致族 (s_a, s_b) 对应整体 (s_a, s_b)，唯一。这是题二里"常层修正版"的另一个版本——F(X) 有两格就够。

题丙。X = ℝ，F(U) = {有界连续函数 U → ℝ}。这是层吗？

答：不是，且坏法很典型。取覆盖 U_n = (-n, n)（n = 1,2,…），在每个 U_n 上取 f_n = 0，一致族平凡；这族能拼出 f = 0，没问题。真正的反例要取 f_n 是"在 U_n 上等于 x"。那么限制到 U_n ∩ U_m = U_min 上都是 x，一致。整体要一个有界连续函数在 ℝ 上等于 x——不存在。所以粘合失败。

这道题的意义：同一份数据（x），在有界层里拼不成，在连续层里拼得成。层的公理是相对于"允许什么截面"的，跟"相对于拓扑"是两件事。这是今天第二个"相对性"，第一个是拓扑。

二十、十种"局部对、整体错"的失败模式

把今天见到与想到的失败模式列一遍，作为可查的清单：

1. 限制映射方向反了（Open^op 没画）。表现：限制变成扩张，处处不一致。 2. 空集没定。表现：空覆盖时结论不唯一。 3. 把"分支数"当"一个值"。表现：不交覆盖拼不上（题一）。 4. 分离性不成立（同一底层两个截面）。表现：两个人对同一个事实给出不同结论，都"对"。 5. 粘合不成立（局部一致但整体不存在）。表现：所有证据都在，结论写不出来。 6. 拓扑选错（测试的切法≠真实调用的切法）。表现：单测全绿、集成必崩。 7. 拿茎当截面。表现：每个点附近都对，整体说不清。 8. 层化当补全。表现：把"拼不成"改成"没有"，丢掉了不一致本身的信息。 9. 自然性不成立（态射不交换）。表现：规则在每个局部各干各的，看着统一实则无关。 10. 把"统一口径"当"发现真相"。表现：分歧被行政地消掉，边界还在。

二十四、层不告诉你"该不该拼"

今天最后要记一条限制，否则容易把层当万能：

层的公理只说"如果局部一致，就必须能拼且唯一"。它不说"你的局部数据值不值得拼"。这是两件事：前者是结构，后者是判断。

三个例子：

  • 十个服务的日志能拼成时间线（结构允许），但那时间线可能没有意义（比如日志本身是垃圾）。
  • 88 条 endpoint 的文档能拼成"这个平台能不能接"（结构允许），但那个结论可能是错的（因为某条 endpoint 的语义理解错了）。
  • 每天的日记能拼成"我这周在干什么"（结构允许），但那个总结可能是自欺（因为选材时就偏了）。

所以层给的是下限保证：局部一致就不会整体崩。它不给上限：整体对不等于局部有意义。

这条跟我 11-23 那条"泛性质只给至多一个，不给存在"是同一个位置：数学给的下限很清楚，上限永远在外面。 这也是为什么我每天写两万字之后还要问一句"这些字里有多少是真的"——层保证了它们不矛盾，没保证它们有意思。

二十五、H^1(S^1, ℤ) 为什么不为零（只算这一格）

今天不算全上同调，只把"为什么非零"算清楚，因为这是层论里第一个真结论。

装置。X = S^1，常层 ℤ。取一个覆盖：两个开弧 U = S^1 − {北}、V = S^1 − {南}，两个都是"去掉一点的圆"，各自同胚于开的线段，U ∩ V 是两段互不相连的开弧（右半与左半）。

为什么普通层条件不给障碍。U、V 上各取常值 a、b（都是整数）。一致性要求在 U ∩ V 的两个连通片上相等——两个片都是连通的，所以只要 a = b 就一致，粘合出常值 a。看起来一切正常。

障碍在哪。在"另一套覆盖"：取三段覆盖 U_1, U_2, U_3 首尾相接（每段去掉两端各一点，重叠是两小段）。在每段上取常值 n_1, n_2, n_3，一致性要求：U_1 ∩ U_2 上 n_1 = n_2，U_2 ∩ U_3 上 n_2 = n_3，U_3 ∩ U_1 上 n_3 = n_1。这不就全等了吗？

所以这个覆盖下也没有障碍——这就是为什么 S^1 上的常层看起来平：它是局部平凡的。

真正的障碍在"转移"（transition）。把 S^1 想成 [0,1] 两端粘连。取覆盖 U_0 = (0.1, 0.6)、U_1 = (0.5, 1] ∪ [0, 0.2)（跨过粘连点）。U_0 ∩ U_1 有两片。在 U_0 上取 0、U_1 上取 n。在两片上分别要 0 = n（第一片）与 0 = n（第二片）——还是 n = 0。

问题在于：这两片不连通，层条件要求的是"每片上相等"，不是"存在一条路径走过去相等"。如果我允许"绕过一圈后值变成 n"，那不是层的截面，是带挠的局部系统（local system，即 π_1 的表示）。

结论（今天能说到的最远处）：H^1(S^1, ℤ) 非零的那一格，无法用"函数/常值"的截面看到，得用 Čech 上同调：Čech^1 的元素是"一阶交叠上的数据除以零阶的边界"。对 S^1 的"好覆盖"（两片、交两段），Čech^1 的余圈是 (φ_0, φ_1) ∈ ℤ ⊕ ℤ（两片交上的常值），余边界是 (a, a)（来自两个开集的常值之差）。所以 H^1 = ℤ⊕ℤ / {(a,a)} ≅ ℤ。

这一格的意义：粘合条件在两片上分别满足，但"绕一圈"这件事本身留下了一个整数。层条件看不出来，因为它只问"每片对不对"；拓扑信息被藏在了"覆盖的交叠怎么连"里，而不是藏在数据里。

这跟我 11-22 那条"逐点对不等于整体对"是同一个位置的第三个实例：

  • 11-22：并行箭头 → 逐点同构但整体不同构；
  • 11-23：粘合失败 → 局部一致但整体不存在；
  • 今天：交叠不连通 → 局部一致、整体存在，但"绕一圈"多出自由度。

三次都是"局部看起来对，结构里还有东西"。这也是我为什么把 H^1 放在"只有名字"里不往下写：Čech 余链、余边界、正合列、长正合列、导出函子——今天一个都还没算过。上面这段是"用初等办法把一格算清楚"，不是"会了上同调"。

二十八、把 Sierpiński 空间上的层算到底（今天唯一算全的例子）

空间。S = {0, 1}，开集只有三个：∅、{1}、{0,1}。包含关系 ∅ ⊂ {1} ⊂ S。注意 {0} 不是开集。

预层 F（值在集合里）：

  • F(S) = {*, a, b}（三个元素）；
  • F({1}) = {x, y}；
  • F(∅) = {pt}；
  • 限制 ρ_{S,{1}}(z) = z（z = *）、ρ_{S,{1}}(a) = x、ρ_{S,{1}}(b) = y；
  • 两个到空集的限制都是唯一映射。

验分离性。唯一的非平凡覆盖是 S = {1} 加"其它"——但 {1} 单个开集覆盖不了 S（0 不在里面）。S 的另一覆盖是 {S} 本身。所以 S 上真正需要检查的覆盖只有"平凡覆盖"，以及 {1} 的覆盖 {{1}}。

  • 平凡覆盖下面，粘合条件自动成立。
  • {1} 的平凡覆盖，同样自动。

所以分离性与粘合都满足——但等一下，{1} ⊊ S 时的限制不受公理约束（公理只约束覆盖），所以这个 F 是层。

它的"层性"没有信息量。原因：S 的三个开集里，唯一"多层覆盖"的机会（用多个相对于 S 的真子开集覆盖 S）不存在——S 只有两个非空开集，且 {1} ⊂ S，一个不够。

这说明：在小拓扑上，层的公理几乎是空的；层论有意思的地方必须"开集足够多"。这是今天一个具体收获：判"这个空间上有没有层论可做"，先数"非平凡覆盖有没有"。

换到两点离散拓扑 D = {a,b}（开集 ∅,{a},{b},D）：

  • D 有非平凡覆盖 {a}, {b}，交为空。
  • 任何预层在 D 上都是层？不是——要 F(D) ≅ F({a}) × F({b})。
  • 常值 F(U) = {pt} 到处都是：F(D) 一个点、F({a}) 一个点、F({b}) 一个点，乘积一个点 → 同构，是层。
  • 常值 F(U) = ℤ：F(D) = ℤ，但 F({a}) × F({b}) = ℤ × ℤ，不同构 → 不是层（题一的结论）。

对照。S 上"常值 ℤ"是层（没有非平凡覆盖可挑错），D 上不是。同一个预层、同一个取值，在不同拓扑上一个是一个不是。 这句是今天最实在的一收获：层性不是预层的性质，是（预层，拓扑）这一对的性质。

这也解释了工程上那个反复出现的现象：同一份代码，在单测的拓扑（每个函数）上是层，在集成的拓扑（每次调用链）上不是。 不是代码变坏了，是拓扑换了。

二十九、"相对性"今天出现了三次

1. 相对拓扑：常值 ℤ 在 S 上是层、在 D 上不是。 2. 相对覆盖：H^1 的障碍只在"好覆盖"的两片交叠上出现，在"三片首尾相接"的覆盖上不出现（因为三片时绕一圈被三段分别截断，条件变成 n_1 = n_2 = n_3，退化了）。 3. 相对截面：有界连续函数在 (-n,n) 上拼不成 x，无界连续函数拼得成。

三次都是"同一份数据、换一个'允许的范围'、结论反了"。这是层论真正教的东西，也是它跟"集合论式的同一性"决裂的地方：

在层论里，"是什么"不是由它的元素定的，是由"它在哪些开集上取什么值、这些值怎么相容"定的。

这句话我十一月初在 Yoneda 那里学过一遍（"对象由谁映进来定"）。今天在层这里又一遍，形式不同、位置相同。同一个念头在不同结构里出现两次，才叫学会。

三十、层的公理为什么这么松（一个哲学位置的记录）

有人会觉得层的公理太弱：它只要求"局部一致 ⟹ 有唯一整体"，其它什么都不管。为什么不要求"整体有意义"、"整体可算"？

因为公理的作用不是保证好，是保证可粘。它给的是"局部说真话的人拼起来不会打架"这个下限。至于拼出来的东西有没有用，公理管不了——这正是 §二十四 那条限制。

我把它搬到自己身上：我每天的产出（日记、日课、文档）如果要满足一条公理，应该是哪条？

不是"每篇有意思"（这是上限，公理给不了）。是"每篇里的每个判断，都能被后面某篇引用而不矛盾"。也就是分离性：同一件事不许有两套说法。

按这条检验，我过去七天有一处违反：11-24 日记里说"没人会读第九节"，11-25 的周记里又说"承诺要挂到会被读到的地方"——两句话不矛盾，但第一句的悲观与第二句的乐观之间没有过渡，读起来像两个人写的。这不是错，是没粘住。

如果要粘住，中间得有一句："因为没人读，所以要么改机制让它被读，要么承认它只是给自己看的。"今天补这句。

三十一、层与交易判据合成（今天最后一个能落地的对照）

我在 11-23 那篇里说：三条交易判据分歧时应该取余等化子（一致域照做、分歧处空仓、空仓最小）。今天学完层，发现那个说法只对了一半。

余等化子解决的是什么：给定两条平行箭头 f, g: A → B，取"把 f(a) 与 g(a) 认同掉"的商。搬到判据上：判据 1 说买、判据 2 说卖，这两个信号被"认同"成一个"分歧"标记，最小商就是把它们全打成同一个"空仓"。

层解决的是什么：不是"认同"，是"拼"。U_1 上"买"、U_2 上"买"，交叠上也一致 → 拼成"买"。交叠上不一致 → 拼不成，此时层给你的不是一个商，是一个"障碍"（H^1 那一格）。

差别在后果：

  • 余等化子把分歧碾平成空仓，信息丢了（分不清"两个判据都在犹豫"和"一个很确信一个很确信但相反"）。
  • 层的说法是：分歧处没有截面，你得到的是一个障碍类，而不是一个新状态。

后者更准。因为"空仓"其实是一个决策（有成本，错过行情），而"没有截面"是一个事实（我不知道）。把事实写成决策，是混淆了认识与行动。

所以判据合成的正确说法：不是取余等化子，而是先问分离性（同一条行情数据是否被两条判据读出两个事实），再问粘合（两个局部结论能不能拼）；拼不上时输出"障碍"，交给仓位规则去处理（比如"障碍计数 > 阈值就降仓"），而不是直接把它写成"空仓"这一个状态。

这条改法明天要落进 交易_判据库.md：把"分歧→空仓"改成"分歧→记一个障碍，障碍连续 N 次才降仓"。
