一、理论：副属和弦（secondary dominant）

1.1 它是什么

在主调 C 大调里，G7 是属和弦，它解决到 C。现在把别的和弦临时当成主：比如把 Dm 临时当主，那它的属就是 A7；把 G 临时当主，它的属就是 D7。这些"别人的属"就叫副属和弦，记作 V7/x，x 是被临时主化的那个和弦。

接口写法（像给函数写签名）：


V7/x : 输入 = 一个调内的目标和弦 x
       输出 = 一个属七和弦，其根音在 x 根音上方纯五度
       副作用 = 让听者的"调性预期"临时指向 x
       后置条件 = 必须解决到 x

所以 C 大调里常见的三个：

| 记法 | 实际和弦 | 解决到 | 临时主化的级数 | |---|---|---|---| | V7/V | D7（D–F♯–A–C） | G | 五级 | | V7/ii | A7（A–C♯–E–G） | Dm | 二级 | | V7/vi | E7（E–G♯–B–D） | Am | 六级 |

注意它们都带调外音（D7 的 F♯、A7 的 C♯、E7 的 G♯），这就是"临时主化"的物理标记——一个音就把调性撕开一道口子。

1.2 它约束了什么

三条约束，缺一条就不成立：

约束一：目标必须是调内和弦。 V7/x 里的 x 得是 C 大调自己的一级和弦（Dm、Em、F、G、Am），否则不是"副属"，是"转调"或"借用和弦"。V7/bII（把 ♭II 当主）在 C 里就属于那不勒斯和弦的用法，不叫副属。

约束二：必须解决。 副属的导音（D7 的 F♯）必须上行到 G，七音（C）必须下行到 B。这两条是属七的固有倾向，副属只是把它们搬到别处。不解决的副属不是副属，是色彩和弦。

约束三：解决之后不能立刻回主。 如果 D7 → G → C 三拍连着走，G 只当了半拍的"主"，临时主化就变成路过。要让副属起作用，得在目标上停一下（至少一小节的一半），让耳朵承认"这里暂时是 G 的天下"。

1.3 两条律

律一（解决律）：V7/x 之后的强拍必须是 x，或者 x 的替代（x 的三度转位、x 的七和弦）。 违反这条，副属就退化成半音装饰。

律二（先立后破律）：x 必须在副属之前已经出现过一次。 这条是我自己总结的，没在教科书里看到过——但它能解释一件事：为什么 A7 接 Dm 在 Dm 第一次出现时会显得"硬"，而第二次出现时显得"顺"。因为副属借的是"记忆里的主"，不是"逻辑上的主"。第一次没记忆可借，只能硬转。

1.4 两个例子

例一：D7 → G → C。 这是最标准的 V7/V。D7 的 F♯ 上行到 G，G 停两拍，然后 G7 → C 回来。整条链是"临时主化五级，再回一级"，耳朵听到的是"出去一趟又回来"。

例二：A7 → Dm → G7 → C。 V7/ii 接 ii，然后走常规 ii–V–I。这里 A7 的 C♯ 上行到 D，Dm 停一拍半。这条链的好处是 Dm 本来就是 ii，副属只是把它"提亮"了一下，不需要额外解释。

1.5 一个反例

D7 → C。 跳过了 G，直接回主。这不是 V7/V，因为它的目标（G）根本没出现。听感上它更像"♭VII 的变体"或者"蓝调里的降七"，功能上属于色彩而不是副属。判据很简单：把中间那一级拿掉，副属的身份就没了。

四、把副属和它的三个近邻分开

副属最容易被当成别的东西，因为它们在谱面上长得像。今天花点篇幅分清，否则"用了副属"这句自评就是空的。

4.1 与"借用和弦"的区别

借用和弦（borrowed chord）是从同主音小调借的：C 大调借 c 小调的 ♭III（E♭）、♭VI（A♭）、♭VII（B♭）。它的判据是"这个和弦属于另一个调"，不带方向性——借来就走，不指向任何目标。

副属的判据恰好相反：它一定指向某个具体目标和弦。D7 在 C 里没有"D7 这个和弦好用"的说法，只有"它要去 G"的说法。所以：

  • 借用的关键词是"颜色"（借来染色）；
  • 副属的关键词是"箭头"（指向目标）。

一个可操作的检验：把副属后面的和弦删掉，副属就站不住了；把借用后面的和弦删掉，借用还能当色彩停在半空（虽然别扭，但身份不丢）。

4.2 与"转调"的区别

转调是换了中心，副属是临时指一下。判据有三条：

1. 时长：副属的目标通常不超过两小节，转调要更久； 2. 回不回来：副属之后必然回原调（或用原调的属接住），转调之后不回来； 3. 调号与音阶：副属只引入一两个调外音（导音、临时升高的三音），转调会系统性改变音阶成员。

有个中间态需要提一下：副属链。比如 A7 → D7 → G7 → C（V7/ii → V7/V → V7 → I），三个副属串起来，每一步都临时主化下一个。这种写法已经很像转调（连续四个调外音），但因为它最终回到 C，仍然算"扩展的副属"而不是转调。这是流行乐与爵士里最常见的套路，也是"听起来很高级但说不清哪里高级"的真身。

4.3 与"副下属"的区别

把副属的下属也搬过来，就是副下属：ii7/x → V7/x → x。C 大调里对 Dm 的副下属是 Em7（ii7/ii），完整链是 Em7 → A7 → Dm。

判据：副下属必须配副属一起用，单独用无效。Em7 单独出现只是 iii，没有任何指向；它只有在 A7 → Dm 前面才有"副属的下属"身份。这条律和律二同源：身份来自关系，不来自和弦本身。

4.4 三个常见错误

错误一：副属的目标是七和弦。 写 D7 → G7 → C，说这是 V7/V。其实 G7 已经是属了，D7 指向它，功能上仍然成立，但它已经不是"临时主化五级"而是"属的属"——记法该写 V7/V7 或者干脆承认这是副属链的一环。教科书把这种叫"扩展属"，我倾向直接用"指向属的属"，别绕。

错误二：副属解决到替代和弦，却按副属算。 D7 → Em（deceptive），F♯ 上行到 G 然后落 E——听起来能成立，但 Em 不是 G 的替代（Em 是 iii，不是 G 的转位）。这属于"副属的欺骗解决"，功能上是异常解决，要单独标。

错误三：在同一个强拍上换和弦。 副属的解决必须落在强拍或次强拍，否则听不出"落地"。写在弱拍上，副属就变成了经过和弦，功能全部塌掉。

五、今天这条理论能用在什么地方

三处，按可用性排序。

第一，写旋律的时候，用它给重复段落加变量。 同一个副歌出现三次，第三次把 IV 前面插一个 V7/IV（C 大调里是 C7），整段立刻有"要往前走"的感觉。这比改旋律省力，也比加配器便宜。

第二，听别人作品时，用它判断"这段为什么显得有推进"。 大部分流行歌的"高级感"来自两处：副属与副下属链、以及低音线的级进。前者能靠记法认出来，后者要靠耳朵。

第三，听到"突然变亮"的地方，先用副属假设去验。 如果那个和弦带调外导音且后面紧接一个调内和弦，八成是副属；如果不带调外音，去查是不是关系大调（vi 的三度关系）或借用。

八、补一节：记法上的取舍

既然记法是这门语言的名字，就把今天用到的几个写法定下来，免得以后自己看自己写的谱看不明白。

主调记法用功能级数，不用绝对音名。 写 V7/ii 比写 A7 好，因为前者换调到别的调也成立，后者一换调就废。绝对音名只在写谱时用。

副属的目标写级数，不写和弦质量。 ii 就是 ii，不必写 iim。因为副属指向的是"那个位置"，不是"那个和弦的具体排列"。小三和弦还是属七和弦，是排列问题，不影响副属的身份。

遇到"指向属的属"，写成 V7/V7 并加脚注。 不硬塞进副属的框里，因为这个框会撑破：V7/V 是"临时主化五级"，V7/V7 是"临时主化属"，后者指向的仍然是主调的核心（属），只是绕了一层。分开写，后面讨论扩展属的时候不容易混。

不用罗马数字写成上标。 纯文本环境下 V⁷/ii 常常渲染不出来，写成 V7/ii 更保险。这条是工程考虑，不是理论考虑，但它决定了文档能不能被别人直接复制走——能复制走的记法才是活记法。

每个副属后面标一个数字，表示目标停留的拍数。 比如 V7/ii → ii (4) 表示目标停了四拍。这个数字比任何形容词都更能说明"临时主化"到底成不成立：停一拍是路过，停四拍才叫到达。今晚我自己的谱里，A7 后面的 Dm 只停了两拍，写下来才发现——这就是为什么它听着"硬"。
